# anki Patterns

## 提交约定

基于当前提交历史，消息风格为简短英文描述。推荐后续采用以下格式：

- `add: <主题>` — 新增算法主题或题目
- `fix: <描述>` — 修正题解或代码错误
- `docs: <描述>` — 文档和配图更新

## 代码架构

```
/
├── README.md              # 仓库概述与目录导航
├── CLAUDE.md              # Claude Code 指导文件
├── 算法/                   # 算法笔记根目录
│   └── <主题>/             # 主题目录（中文命名，如 动态规划）
│       ├── *.md            # 题解笔记（中文撰写，含 Java 代码块）
│       └── image*.png      # 配图（image.png, image 1.png...）
```

## 工作流

### 新增算法主题

1. 在 `算法/` 下创建中文主题目录（如 `算法/回溯/`）
2. 创建笔记 `.md` 文件，按 H2 标题分题
3. 将配图放入同目录，命名为 `image.png`、`image N.png`
4. 更新 README.md 目录索引
5. `git add` 整个主题目录并提交

### 修改已有题解

1. 直接编辑对应 `.md` 文件中的代码块或文字
2. 如需替换配图，保持原文件名不变（或新增 `image N.png` 并更新引用）
3. 注意 markdown 图片引用中空格需转义为 `%20`

## 笔记格式规范

每道题遵循：题干 → 配图 → 解法代码

- 题干和讲解使用中文
- 代码块标注为 Java
- 短配图放置在学习卡片关键步骤处
