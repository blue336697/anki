> 直接贴百科的，简单了解下即可，重要的是思想，是[冒泡排序](https://zhida.zhihu.com/search?content_id=102174570&content_type=Article&match_order=1&q=%E5%86%92%E6%B3%A1%E6%8E%92%E5%BA%8F&zhida_source=entity)的升级版（思想很像）。
> 
> 
> > 快速排序由[C. A. R. Hoare](https://zhida.zhihu.com/search?content_id=102174570&content_type=Article&match_order=1&q=C.+A.+R.+Hoare&zhida_source=entity)在1962年提出。它的基本思想是:通过一趟排序将要排序的数据分割成独立的两部分，其中一部分的所有数据都比另外一部分的所有数据都要小，然后再按此方法对这两部分数据分别进行快速排序，整个排序过程可以[递归](https://link.zhihu.com/?target=https%3A//baike.so.com/doc/5725016-5937752.html)进行，以此达到整个数据变成有序序列。
> > 

```java
class Solution {
    private final static Random RANDOM = new Random(System.currentTimeMillis());
    public int[] sortArray(int[] nums) {
        quickSort(nums, 0, nums.length-1);
        return nums;
    }

    public void quickSort(int[] arr, int left, int right){
        if(left >= right)
            return;
        //以每次是随机数，然后跟左边的第一个数进行交换，这样可以分的更广一点
        int randomIndex = RANDOM.nextInt(right - left + 1) + left;
        swap(arr, left, randomIndex);

        int i = left, j = right;
        //以每次数组的第一个为基准
        while(i < j){
            //注意一定要先从右往左扫描
            while(i < j && arr[left] <= arr[j])
                j--;
            while(i < j && arr[left] >= arr[i])
                i++;

            swap(arr, i, j);
        }
        //这里填left，j或left，i都可以，因为最后i，j指向同一个位置，
        //这个位置就是left的最终位置
        swap(arr, left, i);
        //最基准最后位置的左右两个数组进行进行递归排序
        quickSort(arr, left, i - 1);
        quickSort(arr, i + 1, right);
    }

    public void swap(int[] arr, int i, int j){
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

- 算法：树的最大宽度

```java
/**
  * 二叉树的最大宽度
  * 优先队列，进行层序遍历，记录每个节点在满二叉树中的序号
  * 在满二叉树中，当前节点的序号为k，
  * 那么其左孩子和右孩子的序号分别为2k、2k+1
  */
class Solution {
    class Node {
        TreeNode treeNode;
        long index;
        Node() {}
        Node(TreeNode node, long index) {
            this.index = index;
            this.treeNode = node;
        }
    }

    public int widthOfBinaryTree(TreeNode root) {
        Deque<Node> pq = new LinkedList<>();
        //将根节点放入
        pq.offer(new Node(root, 1));
        long ans = 0;
        //while循环过每一层
        while (!pq.isEmpty()) {
            int size = pq.size();
            // 注意：right可能会越界，这里使用long
            long left = pq.peek().index, right = pq.peek().index; 
            //每轮for循环就是对当前层的每个节点的标记  
            for (int k = 0; k < size; k++) {
                Node node = pq.poll();
                //左边界
                left = Math.min(left, node.index);
                //右边界
                right = Math.max(right, node.index);
                ans = Math.max(ans, right - left + 1);
                if (node.treeNode.left != null) pq.offer(new Node(node.treeNode.left, 2 * node.index));
                if (node.treeNode.right != null) pq.offer(new Node(node.treeNode.right, 2 * node.index + 1));
            }
        }
        return (int) ans;
    }
}
```

```java
    public int lengthOfLongestSubstring(String s) {
        HashMap<Character, Integer> map = new HashMap<>();
        int max = 0, start = 0;
        for (int end = 0; end < s.length(); end++) {
            char ch = s.charAt(end);
            if (map.containsKey(ch)){
                //如果重复的字符出现了，那么start会得到更新
                start = Math.max(map.get(ch)+1,start);
            }
            //如果不是重复的字符则会一直+1，start的更新体现在max会一直处于当前无重复的最大值
            max = Math.max(max,end - start + 1);
            map.put(ch,end);
        }
        return max;
    }
```

> 类的加载：加载——》链接（验证&准备&解析）——》初始化
> 
- 加载类的结构，比如order.class的class对象在堆，数据结构在元空间
- 链接-验证：验证语法树、语义、字节码、符号引用等，这个阶段一般与加载一起进行
- 链接-准备：对所有静态变量默认初始化，之后对编译器常量（static final：基本类型+String）会做显式初始化，就是代码写的赋值逻辑，根据ConstantValue属性直接覆盖初始值
- 链接-解析：将符号引用转变为直接引用，就是给你具体的内存地址，这个一般会在初始化后进行
- 初始化（<client>()）：JVM生成的初始化方法，但如何类中没有下面
    - 这时候就会给不是编译器常量（**方法计算、new、装箱、集合构造**）进行显示赋值，要么是静态成员变量初始化要么是静态代码块
    - 如果没有任何一个上面提到的静态引用类型的或者存在但没有显式赋值就不会生成初始化的JVM方法
- 由父及子：无论类初始化还是对象创建，始终“父类先、子类后”。
- 静态先行：在一次“主动使用”触发时，先执行静态初始化（static 字段赋值/静态代码块），再执行实例初始化（实例字段赋值/实例代码块/构造器）。

- 代码块要区分两类：
    - 静态代码块/静态字段显式赋值：在“类初始化阶段”一次性执行（父类先、子类后），这些赋值与静态块被编译进 <clinit>。

1. 面向对象过程中有哪些设计原则？
    - 开闭原则：一个类应该对修改关闭，对扩张开放，避免修改已经稳定的类，而是对类进行扩张
    - 单一职责：类的功能职责应该单一，不要把太多职责放到类中。
    - 依赖倒置原则：高层模块不应该依赖低层模块，它们都应该依赖抽象。抽象不应该依赖于细节，细节应该依赖于抽象。
    - 接口隔离原则：客户端不应该依赖那些它不需要的接口。一旦一个接口太大，则需要将它分割成一些更细小的接口，使用该接口的客户端仅需知道与之相关的方法即可。
    - 里氏替换原则：一个父类可以出现的地方，子类必定可以出现。
    - 迪米特法则：即最小知识原则，每一个对象都对其他对象保持最小了解。
    - 合成复用原则：尽量使用对象组合，而不是继承来达到复用的目的。

```java
import java.util.Objects;

public class OrderedHashMap<K, V> {
    // 哈希桶（数组），默认大小16
    private Node<K, V>[] table;
    private int size; // 实际存储的键值对数量
    // 双向链表的头（第一个插入的节点）和尾（最后一个插入的节点）
    private Node<K, V> head;
    private Node<K, V> tail;

    // 节点结构
    static class Node<K, V> {
        K key;
        V value;
        Node<K, V> next; // 哈希桶内的链表指针（解决冲突）
        Node<K, V> prev; // 双向链表前驱
        Node<K, V> nextSeq; // 双向链表后继

        Node(K key, V value) {
            this.key = key;
            this.value = value;
        }
    }

    @SuppressWarnings("unchecked")
    public OrderedHashMap() {
        table = (Node<K, V>[]) new Node[16];
        size = 0;
        // 初始化哨兵节点（简化边界处理）
        head = new Node<>(null, null);
        tail = new Node<>(null, null);
        head.nextSeq = tail;
        tail.prev = head;
    }

    // 计算哈希值（简化版）
    private int hash(K key) {
        return Objects.hashCode(key) % table.length;
    }

    // 插入键值对
    public void put(K key, V value) {
        int index = hash(key);
        Node<K, V> curr = table[index];

        // 检查是否已存在该key
        while (curr != null) {
            if (Objects.equals(curr.key, key)) {
                curr.value = value; // 更新值，不改变顺序
                return;
            }
            curr = curr.next;
        }

        // 新增节点：插入哈希桶和双向链表尾部
        Node<K, V> newNode = new Node<>(key, value);
        // 插入哈希桶（头插法，简化实现）
        newNode.next = table[index];
        table[index] = newNode;
        // 插入双向链表尾部（tail的前面）
        newNode.prev = tail.prev;
        newNode.nextSeq = tail;
        tail.prev.nextSeq = newNode;
        tail.prev = newNode;

        size++;
    }

    // 获取值
    public V get(K key) {
        int index = hash(key);
        Node<K, V> curr = table[index];

        // 遍历哈希桶查找key
        while (curr != null) {
            if (Objects.equals(curr.key, key)) {
                return curr.value;
            }
            curr = curr.next;
        }
        return null; // 未找到
    }

    // 按插入顺序遍历并打印
    public void traverse() {
        Node<K, V> curr = head.nextSeq;
        while (curr != tail) {
            System.out.println(curr.key + " -> " + curr.value);
            curr = curr.nextSeq;
        }
    }

    // 测试
    public static void main(String[] args) {
        OrderedHashMap<String, Integer> map = new OrderedHashMap<>();
        map.put("a", 1);
        map.put("b", 2);
        map.put("c", 3);
        
        System.out.println("get 'b': " + map.get("b")); // 输出 2
        System.out.println("遍历顺序：");
        map.traverse(); // 输出 a->1, b->2, c->3（与插入顺序一致）
    }
}
```
