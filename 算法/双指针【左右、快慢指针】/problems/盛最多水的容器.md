# 盛最多水的容器

## 题干
给定 n 个非负整数表示高度，每个柱子宽度为1。找出两条线，与x轴一起构成容器，使容器能容纳最多的水。
![image 4.png](image%204.png)

## 指针策略
左右指针 i=0, j=n-1 对撞。
每次移动{{c1::较矮一侧}}的指针：height[i] < height[j] → {{c1::i++}}，否则 {{c1::j--}}
面积 = {{c1::min(height[i],height[j]) * (j-i)}}
原理：容量由短板决定，移动长板不可能增大面积

## 复杂度
时间：{{c1::O(n)}} — 一次遍历
空间：{{c1::O(1)}}

## 题解(双指针)
每次移动短板，计算当前面积并更新最大值。
```java
class Solution {
    public int maxArea(int[] height) {
        if(height == null)
            return 0;
        int i = 0, j = height.length - 1, maxRes = 0;
        while(i < j){
            maxRes = height[i] < height[j]
                ? Math.max(maxRes, (j - i) * height[i++])
                : Math.max(maxRes, (j - i) * height[j--]);
        }
        return maxRes;
    }
}
```
