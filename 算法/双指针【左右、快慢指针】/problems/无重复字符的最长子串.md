# 无重复字符的最长子串

## 题干
给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度。
![image 10.png](image%2010.png)

## 指针策略
滑动窗口：start={{c1::窗口左边界}}，end={{c1::遍历指针（窗口右边界）}}
遇到重复字符 ch → start = {{c1::max(map.get(ch)+1, start)}}（跳过重复位置）
每次更新 max = {{c1::max(max, end-start+1)}}
用 HashMap 或 int[128] 记录字符上次出现位置

## 复杂度
时间：{{c1::O(n)}} — 一次遍历
空间：{{c1::O(128)}} — 字符集大小

## 题解(滑动窗口)
用int[128]记录字符上次出现位置，start只会向前跳不会后退。
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        Arrays.fill(last, -1);
        int res = 0, start = 0;
        for(int end = 0; end < s.length(); end++){
            int idx = s.charAt(end);
            start = Math.max(start, last[idx] + 1);
            res = Math.max(res, end - start + 1);
            last[idx] = end;
        }
        return res;
    }
}
```
