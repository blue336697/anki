# 合并两个有序数组

## 题干
给定两个有序整数数组 nums1 和 nums2，将 nums2 合并到 nums1 中，使 nums1 成为一个有序数组。nums1 有足够空间容纳 nums2。

## 指针策略
从后往前合并，三个指针：
i = {{c1::nums1末尾（m+n-1）}}，m--和n--分别指向两个数组{{c1::最后一个有效元素}}
比较 nums1[m] 和 nums2[n]，大的放到 {{c1::nums1[i--]}}
结束条件：{{c1::n < 0}}（nums2全部放完）

## 复杂度
时间：{{c1::O(m+n)}} — 每个元素处理一次
空间：{{c1::O(1)}}

## 题解(逆向双指针)
从后往前放，避免覆盖nums1未处理元素。每次挑大的放入末尾。
```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = nums1.length - 1;
        m--; n--;
        while(n >= 0){
            if(m >= 0 && nums1[m] > nums2[n])
                nums1[i--] = nums1[m--];
            else
                nums1[i--] = nums2[n--];
        }
    }
}
```
