# 反转字符串

## 题干
编写一个函数，其作用是将输入的字符串反转过来。输入以字符数组 char[] 形式给出。

## 指针策略
左右指针 i=0, j=n-1 对撞。
每次 swap(s[i], s[j])，然后 {{c1::i++, j--}}
终止条件：{{c1::i < j}}

## 复杂度
时间：{{c1::O(n)}} — 一次遍历，n/2次交换
空间：{{c1::O(1)}}

## 题解(对撞指针)
经典对撞指针，原地反转字符数组。
```java
class Solution {
    public void reverseString(char[] s) {
        int i = 0, j = s.length - 1;
        char temp;
        while(i < j){
            temp = s[i];
            s[i] = s[j];
            s[j] = temp;
            i++;
            j--;
        }
    }
}
```
