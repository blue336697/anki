# 最长有效括号

## 题干
给你一个只包含 ( 和 ) 的字符串，找出最长有效（格式正确且连续）括号子串的长度。
![image 1.png](image%201.png)

## 复杂度
时间：{{c1::O(n)}} — 一次遍历
空间：{{c1::O(n)}} — 栈空间

## 关键技巧
栈底存的是"最后一个未被匹配的右括号的索引"，作为有效子串的起始边界。
初始化push(-1)是核心技巧：将-1视为虚拟的"未匹配右括号"，处理从头开始的有效子串。
每次匹配成功时，i - stack.peek() 就是当前有效子串长度。

## 题解(栈存下标)
栈底始终是最后一个无法匹配的)位置。遇到)时弹栈后计算 i-stack.peek()。

```java
class Solution {
    public int longestValidParentheses(String s) {
        if (s == "")
            return 0;
        int len = s.length();
        Deque<Integer> stack = new LinkedList<>();
        stack.push(-1);
        int res = 0;
        for (int i = 0; i < len; i++) {
            if (s.charAt(i) == '(')
                stack.push(i);
            else {
                stack.pop();
                if (stack.isEmpty())
                    stack.push(i);
                else
                    res = Math.max(res, i - stack.peek());
            }
        }
        return res;
    }
}
```

## 策略
栈存下标法：栈底始终保持{{c1::最后一个未匹配的右括号下标}}（初始为-1）。
遇到 ( ：将其{{c1::下标入栈}}。
遇到 ) ：先{{c1::pop()}}，若栈为空则push当前下标（新的分割点），否则计算长度={{c1::i - stack.peek()}}。
