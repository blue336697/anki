# 有效的括号

## 题干
给定一个只包括 (、)、[、]、{、} 的字符串 s，判断字符串是否有效。
有效条件：1. 左括号必须用相同类型的右括号闭合；2. 左括号必须以正确的顺序闭合。

## 复杂度
时间：{{c1::O(n)}} — 一次遍历
空间：{{c1::O(n)}} — 最坏全部字符入栈

## 关键技巧
两种写法：
1. Map存括号映射（通用但稍冗长）
2. 左括号直接push对应的右括号（巧妙：匹配时只需 ch==stack.pop()）
边界优化：奇数长度直接返回false，因为括号不可能配对成功。

## 题解(技巧版)
左括号push对应右括号，右括号直接pop比较。无需Map查表。

```java
class Solution {
    public boolean isValid(String s) {
        if (s == null)
            return false;
        int len = s.length();
        Deque<Character> stack = new LinkedList<>();
        for (char ch : s.toCharArray()) {
            if (ch == '(')
                stack.push(')');
            else if (ch == '[')
                stack.push(']');
            else if (ch == '{')
                stack.push('}');
            else if (stack.isEmpty() || ch != stack.pop())
                return false;
        }
        return stack.isEmpty();
    }
}
```

## 策略
栈解法：遍历字符串，左括号{{c1::入栈}}，右括号与{{c1::栈顶}}匹配。
优化技巧：遇到左括号时直接{{c1::push对应的右括号}}，匹配时只需判断 ch==stack.pop() 即可。
最终栈为空 → {{c1::完全匹配}}，返回true。
