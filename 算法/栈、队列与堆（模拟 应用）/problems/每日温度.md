# 每日温度

## 题干
给定一个整数数组 temperatures，表示每天的温度。返回一个数组 answer，其中 answer[i] 表示对于第i天，下一个更高温度出现在几天后。如果之后都不会升高，answer[i] = 0。

## 复杂度
时间：{{c1::O(n)}} — 每个元素最多入栈出栈一次
空间：{{c1::O(n)}} — 栈空间

## 关键技巧
单调递减栈的经典应用。
核心：栈中存的是下标，栈内对应温度严格递减，当前元素大于栈顶时即为栈顶元素的下一个更高温度。
数组默认初始化为0，未找到更高温度的元素自然保持0。

## 题解(单调栈)
栈内温度递减，遇到更高温度时弹出并计算天数差。默认值为0（数组初始化）。

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        Stack<Integer> stack = new Stack<>();
        int[] res = new int[temperatures.length];
        for (int i = 0; i < res.length; i++) {
            while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
                int temp = stack.pop();
                res[temp] = i - temp;
            }
            stack.push(i);
        }
        return res;
    }
}
```

## 策略
单调递减栈：栈内存储{{c1::下标}}，对应温度从栈底到栈顶{{c1::递减}}。
遍历时，若当前温度 > 栈顶温度，说明找到了{{c1::更高温度}}。
此时弹出栈顶，结果 = {{c1::i - stack.pop()}}（天数差）。
处理完后将当前下标入栈。
