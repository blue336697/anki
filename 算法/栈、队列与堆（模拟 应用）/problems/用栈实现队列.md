# 用栈实现队列
<!-- aliases: 用两个栈实现队列 -->

## 题干
仅使用两个栈实现一个先进先出队列。

- LeetCode 232 接口：`push`、`pop`、`peek`、`empty`
- 剑指 Offer CQueue 接口：`appendTail`、`deleteHead`，空队列删除时返回 `-1`

两个接口考查的是同一个数据结构，不应作为两道独立算法题重复复习。

## 复杂度
入队：{{c1::O(1)}}
出队/查看队首：单次最坏 {{c1::O(n)}}，连续操作的均摊复杂度 {{c1::O(1)}}
空间：{{c1::O(n)}}

## 关键技巧
设 `in` 为入队栈、`out` 为出队栈：

1. 新元素始终压入 `in`
2. 出队或查看队首时，如果 `out` 非空，直接读取 `out` 栈顶
3. 只有 `out` 为空时，才把 `in` 的全部元素逐个弹出并压入 `out`

一次整体搬运会把顺序反转，使最早进入 `in` 的元素来到 `out` 栈顶。不能在每次出队时都来回搬运，否则会失去均摊 O(1)。

Java 中优先使用 `ArrayDeque` 实现栈；`Stack` 是遗留的同步容器，`LinkedList` 还要为每个节点承担额外对象和指针开销。

## 题解(LeetCode 232 API)
`moveIfNeeded` 集中维护惰性搬运条件。题目保证 `pop`、`peek` 只在非空队列上调用。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void moveIfNeeded() {
        if (!out.isEmpty()) {
            return;
        }
        while (!in.isEmpty()) {
            out.push(in.pop());
        }
    }
}
```

## 题解(剑指 Offer CQueue API)
接口名和空队列约定不同，但底层状态及搬运时机完全相同。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class CQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public void appendTail(int value) {
        in.push(value);
    }

    public int deleteHead() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());
            }
        }
        if (out.isEmpty()) {
            return -1;
        }
        return out.pop();
    }
}
```

## 策略
入队栈负责{{c1::接收所有新元素}}，出队栈负责{{c1::提供队首元素}}。
只有当出队栈{{c1::为空}}时，才把入队栈全部倒入出队栈。
每个元素至多经历{{c1::一次入队栈到出队栈的搬运}}，所以一组操作的总时间为 O(m)，单次均摊 O(1)。
