# 滑动窗口最大值

## 题干
给定一个整数数组 nums 和一个大小为 k 的滑动窗口，窗口从数组最左侧移动到最右侧。每次只能看到窗口内的 k 个数字。返回每个窗口中的最大值。
![image.png](image.png)

## 复杂度
时间：{{c1::O(n)}} — 每个元素入队出队各一次
空间：{{c1::O(k)}} — 队列最多k个元素

## 关键技巧
单调递减队列是本题的核心数据结构。
队列中存的是数组下标而非数值，便于判断窗口边界。
队首是最大值，队尾维护递减约束。每个元素至多入队出队一次 = O(n)。
与单调栈的区别：双端队列可以同时从两端操作。

## 题解(单调队列)
队列存下标。队尾维护递减：新元素>=队尾时弹出。队首超出窗口左边界时弹出。

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length < 2)
            return nums;
        int[] res = new int[nums.length - k + 1];
        Deque<Integer> window = new LinkedList<>();
        for (int i = 0; i < nums.length; i++) {
            while (!window.isEmpty() && nums[window.peekLast()] <= nums[i])
                window.pollLast();
            window.addLast(i);
            if (window.peek() <= i - k)
                window.poll();
            if (i + 1 >= k)
                res[i - k + 1] = nums[window.peek()];
        }
        return res;
    }
}
```

## 策略
单调递减队列（Deque）：队列从队首到队尾{{c1::递减}}（队首最大）。
入队：新元素与队尾比较，若队尾{{c1::<=}}新元素则弹出队尾，直到满足递减。
出队：队首元素下标{{c1::不在窗口内}}（<= i-k）时从队首弹出。
队首始终是当前窗口的{{c1::最大值}}。
