# 中位数维护（数据流与滑动窗口）
<!-- aliases: 数据流的中位数, 滑动窗口中位数 -->
<!-- tags: source::leetcode source::字节 pattern::双堆 pattern::延迟删除 -->

## 题干
中位数是有序序列中间的值；元素数量为偶数时，取中间两个数的平均值。本知识实体包含两个递进问题：

1. 数据流中位数：支持 `addNum` 和 `findMedian`
2. 滑动窗口中位数：窗口右移时既要加入新元素，也要删除离开窗口的旧元素

前者只需双堆平衡；后者还必须解决 `PriorityQueue` 无法 O(log k) 删除任意指定值的问题。

## 双堆不变量
大根堆 `small` 保存{{c1::较小的一半元素}}，堆顶是较小一半的最大值。
小根堆 `large` 保存{{c1::较大的一半元素}}，堆顶是较大一半的最小值。

始终维护：

- `smallSize == largeSize`，或 `smallSize == largeSize + 1`
- `small` 中的每个有效元素都 `<= large` 中的每个有效元素

奇数个元素时中位数是 `small.peek()`；偶数时是两堆顶之和除以 2.0。相加前先转 `long`，避免两个 int 堆顶求和溢出。

## 数据流复杂度
`addNum`：{{c1::O(log n)}} — 一次入堆及至多常数次跨堆移动。
`findMedian`：{{c1::O(1)}} — 读取一个或两个堆顶。
空间：{{c1::O(n)}} — 所有数据都保存在两个堆中。

## 题解(数据流双堆)
按值与 `small.peek()` 比较决定初始入堆位置，再统一恢复大小不变量。

```java
import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    private final PriorityQueue<Integer> small =
            new PriorityQueue<>(Collections.reverseOrder());
    private final PriorityQueue<Integer> large = new PriorityQueue<>();

    public void addNum(int value) {
        if (small.isEmpty() || value <= small.peek()) {
            small.offer(value);
        } else {
            large.offer(value);
        }
        rebalance();
    }

    public double findMedian() {
        if (small.size() > large.size()) {
            return small.peek();
        }
        return ((long) small.peek() + large.peek()) / 2.0;
    }

    private void rebalance() {
        if (small.size() > large.size() + 1) {
            large.offer(small.poll());
        } else if (small.size() < large.size()) {
            small.offer(large.poll());
        }
    }
}
```

## 滑动窗口为什么需要延迟删除
Java `PriorityQueue.remove(value)` 需要线性查找，直接使用会使总时间退化为 O(nk)。

延迟删除的做法：

1. `delayed[value]` 记录该值有多少个实例已经离开窗口、但仍物理滞留在堆中
2. 删除时只把对应堆的{{c1::逻辑有效大小}}减一，不立即在堆内部查找
3. 只有当失效元素来到堆顶时，`prune` 才真正 `poll`

因此 `small.size()`/`large.size()` 是物理大小，可能包含失效元素；平衡必须使用单独维护的 `smallSize`/`largeSize`。

## 延迟删除的归属判断
移除值 `value` 时，以当前有效的 `small.peek()` 为分界：

- `value <= small.peek()`：把 `smallSize` 减一
- 否则把 `largeSize` 减一

重复值可能同时存在于两堆，但只要按分界减少一侧的逻辑计数，延迟表最终会在某个同值实例到达堆顶时抵消，结果仍正确。

## 滑动窗口复杂度
每个元素入堆一次，并最终至多被真正弹出一次；每次堆操作 O(log k)。
时间：{{c1::O(n log k)}}。
空间：{{c1::O(k)}} — 两个堆与延迟删除表的有效规模均受窗口控制。

## 题解(滑动窗口双堆+延迟删除)
```java
import java.util.Collections;
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    public double[] medianSlidingWindow(int[] nums, int k) {
        DualHeap dualHeap = new DualHeap(k);
        double[] answer = new double[nums.length - k + 1];

        for (int index = 0; index < nums.length; index++) {
            dualHeap.add(nums[index]);
            if (index >= k) {
                dualHeap.remove(nums[index - k]);
            }
            if (index >= k - 1) {
                answer[index - k + 1] = dualHeap.median();
            }
        }
        return answer;
    }

    private static class DualHeap {
        private final PriorityQueue<Integer> small =
                new PriorityQueue<>(Collections.reverseOrder());
        private final PriorityQueue<Integer> large = new PriorityQueue<>();
        private final Map<Integer, Integer> delayed = new HashMap<>();
        private final int windowSize;
        private int smallSize;
        private int largeSize;

        private DualHeap(int windowSize) {
            this.windowSize = windowSize;
        }

        private void add(int value) {
            if (small.isEmpty() || value <= small.peek()) {
                small.offer(value);
                smallSize++;
            } else {
                large.offer(value);
                largeSize++;
            }
            rebalance();
        }

        private void remove(int value) {
            delayed.merge(value, 1, Integer::sum);
            if (value <= small.peek()) {
                smallSize--;
                if (value == small.peek()) {
                    prune(small);
                }
            } else {
                largeSize--;
                if (!large.isEmpty() && value == large.peek()) {
                    prune(large);
                }
            }
            rebalance();
        }

        private double median() {
            if ((windowSize & 1) == 1) {
                return small.peek();
            }
            return ((long) small.peek() + large.peek()) / 2.0;
        }

        private void rebalance() {
            if (smallSize > largeSize + 1) {
                large.offer(small.poll());
                smallSize--;
                largeSize++;
                prune(small);
            } else if (smallSize < largeSize) {
                small.offer(large.poll());
                smallSize++;
                largeSize--;
                prune(large);
            }
        }

        private void prune(PriorityQueue<Integer> heap) {
            while (!heap.isEmpty()) {
                int value = heap.peek();
                int count = delayed.getOrDefault(value, 0);
                if (count == 0) {
                    break;
                }
                heap.poll();
                if (count == 1) {
                    delayed.remove(value);
                } else {
                    delayed.put(value, count - 1);
                }
            }
        }
    }
}
```
