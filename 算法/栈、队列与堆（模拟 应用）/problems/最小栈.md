# 最小栈

## 题干
设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。
![image 2.png](image%202.png)

## 复杂度
所有操作：时间{{c1::O(1)}}
空间：{{c1::O(n)}} — 两个栈

## 关键技巧
核心：用辅助栈同步维护每个状态下的最小值。
初始化push Integer.MAX_VALUE 确保第一次比较不出错。
可优化：只在minStack中push<=当前min的值来节省空间，但pop时需要额外判断。

## 题解(辅助栈)
minStack与xStack同步push/pop，minStack栈顶始终是当前所有元素的最小值。

```java
class MinStack {
    Deque<Integer> xStack;
    Deque<Integer> minStack;

    public MinStack() {
        xStack = new LinkedList<Integer>();
        minStack = new LinkedList<Integer>();
        minStack.push(Integer.MAX_VALUE);
    }

    public void push(int x) {
        xStack.push(x);
        minStack.push(Math.min(minStack.peek(), x));
    }

    public void pop() {
        xStack.pop();
        minStack.pop();
    }

    public int top() {
        return xStack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

## 策略
辅助栈法：维护两个栈——{{c1::数据栈 xStack}} 和 {{c1::最小值栈 minStack}}。
push时：数据栈直接push；minStack push{{c1::min(minStack.peek(), x)}}。
pop时：两个栈{{c1::同时pop}}。getMin() 返回 minStack.peek()。
