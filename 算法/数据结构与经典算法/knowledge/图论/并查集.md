并查集的两个关键优化是什么？	两个优化：1. 路径压缩：find 时把沿途节点直接挂到根节点，降低后续查询成本；2. 按秩/按大小合并：union 时让小树挂到大树下面，避免树退化成链。两者一起使用后，单次操作均摊复杂度近似 O(1)，严格说是 O(alpha(n))。[[img:union_find_path_compression.svg]]	算法 数据结构经典算法 图论 并查集 优化	图论-并查集	Hard
并查集 Java 模板怎么写？	模板：<br><pre><code class="language-java">class UnionFind {<br>    int[] parent, size;<br>    UnionFind(int n) {<br>        parent = new int[n]; size = new int[n];<br>        for (int i = 0; i &lt; n; i++) { parent[i] = i; size[i] = 1; }<br>    }<br>    int find(int x) {<br>        if (parent[x] != x) parent[x] = find(parent[x]);<br>        return parent[x];<br>    }<br>    boolean union(int a, int b) {<br>        int ra = find(a), rb = find(b);<br>        if (ra == rb) return false;<br>        if (size[ra] &lt; size[rb]) { int t = ra; ra = rb; rb = t; }<br>        parent[rb] = ra; size[ra] += size[rb];<br>        return true;<br>    }<br>}</code></pre>union 返回 false 通常表示这条边会形成环。	算法 数据结构经典算法 图论 并查集 模板	图论-并查集	Hard

并查集不适合哪些场景？	普通并查集擅长“合并”，不擅长“删除边/拆分集合”；也不保留路径信息，不能直接回答两点之间具体路径或最短路。若需要有向依赖顺序，用拓扑排序；若需要最短路径，用 BFS/Dijkstra；若需要支持删除连通性，要考虑更复杂的动态连通性结构。	算法 数据结构经典算法 图论 并查集 边界	图论-并查集	Medium
