# 搜索插入位置

## 题干
给定一个排序数组和一个目标值，在数组中找到目标值并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

## 复杂度
时间：{{c1::O(log n)}} — 二分查找
空间：{{c1::O(1)}}

## 关键技巧
二分查找变体：找第一个 >= target 的位置。
当 nums[mid]==target 时不直接返回，继续向左搜索更左边界。
res 初始化为 nums.length，覆盖 target 大于所有元素的情况。

## 题解(二分)
寻找第一个 >= target 的索引。res 初始化为 nums.length，覆盖 target 大于所有元素的情况。

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        int res = nums.length;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (nums[mid] >= target) {
                res = mid;
                right = mid - 1;
            } else
                left = mid + 1;
        }
        return res;
    }
}
```
