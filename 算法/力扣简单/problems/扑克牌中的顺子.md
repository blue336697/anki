# 扑克牌中的顺子

## 题干
从若干副扑克牌中随机抽 5 张牌，判断是不是一个顺子。A=1, J=11, Q=12, K=13，大小王(0)可以看成任意数字。

## 复杂度
时间：{{c1::O(n log n)}} — 排序开销（n=5 可视为 O(1)）
空间：{{c1::O(1)}}

## 关键技巧
顺子条件：除了大小王(0)外，无重复牌 + max-min < 5。
更简洁：排序后，统计 0 的个数，然后遍历非 0 部分，相邻差值 diff-1 就是需要的大小王数量。
只要 0 够用（zeroNum >= 需要的填补量）就是顺子。

## 题解(排序+计数)
排序后统计大小王数量，然后检查相邻牌差值，用大小王填补 gap。

```java
class Solution {
    public boolean isStraight(int[] nums) {
        int n = nums.length;
        int i = 0, j = 1, zeroNum = 0;
        Arrays.sort(nums);

        while (zeroNum < n) {
            if (nums[zeroNum] == 0)
                zeroNum++;
            else
                break;
        }
        i = zeroNum; j = zeroNum + 1;
        while (j < n) {
            int difference = nums[j] - nums[i];
            if (difference == 1) {
                i++; j++;
            } else if (difference - zeroNum >= 2)
                return false;
            else if (difference == 0)
                return false;
            else if (difference == zeroNum + 1) {
                i++; j++;
                zeroNum = 0;
            } else
                return true;
        }
        return true;
    }
}
```
