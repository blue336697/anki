# 排列硬币

## 题干
你总共有 n 枚硬币，需要将它们摆成一个阶梯形状，第 k 行恰好有 k 枚硬币。返回可形成完整阶梯行的总行数。

## 复杂度
二分法：时间 {{c1::O(log n)}}，空间 {{c1::O(1)}}

## 关键技巧
等差数列前 k 项和：Sk = k*(k+1)/2。
二分查找「小于等于 target 的最大行数」，找到满足 S_mid <= n 的最大 mid。
注意用 long 防止 mid*(mid+1)/2 溢出。

## 题解(二分查找)
前 k 行硬币总数 = k*(k+1)/2，二分查找满足 S_mid <= n 的最大 mid。

```java
class Solution {
    public int arrangeCoins(int n) {
        long left = 0, right = 10000000;
        long res = 0;
        while (left <= right) {
            long mid = (left + right) / 2;
            if (mid + (mid * (mid - 1)) / 2 <= n) {
                res = mid;
                left = mid + 1;
            } else
                right = mid - 1;
        }
        return (int)res;
    }
}
```
