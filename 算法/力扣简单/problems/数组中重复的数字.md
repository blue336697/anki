# 数组中重复的数字

## 题干
在一个长度为 n 的数组 nums 里的所有数字都在 0 ~ n-1 的范围内。找出数组中任意一个重复的数字。

## 复杂度
时间：{{c1::O(n)}} — 每个元素最多交换两次
空间：{{c1::O(1)}} — 原地交换

## 关键技巧
原地哈希核心：数字范围 0~n-1，每个数字的值 = 它应该在的索引。
若 nums[i]==i 说明归位，i++ 继续；否则与 nums[nums[i]] 交换。
交换时发现 nums[nums[i]] == nums[i] 说明重复。每个数最多被交换 2 次。

## 题解(原地Hash)
将每个数字放到其值对应的索引位置，若目标位置已有相同值则找到重复。

```java
class Solution {
    public int findRepeatNumber(int[] nums) {
        int temp = -1;
        for (int i = 0; i < nums.length;) {
            if (nums[i] == i) {
                i++;
                continue;
            }
            if (nums[nums[i]] != nums[i]) {
                temp = nums[nums[i]];
                nums[nums[i]] = nums[i];
                nums[i] = temp;
            } else
                return nums[i];
        }
        return -1;
    }
}
```
