# 缺失数字

## 题干
给定一个包含 [0, n] 中 n 个数的数组 nums，找出 [0, n] 中没有出现在数组中的那个数。

## 复杂度
数学法：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}
异或法：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}

## 关键技巧
多种解法：
1. 数学法：sum(0..n) - sum(nums) = 缺失数，注意防溢出用 long
2. 异或法：x ^ x = 0，将 0~n 和数组所有元素异或，剩下的即缺失数
3. 原地哈希：将数字放到对应索引，第一个不匹配的位置即缺失数

## 题解(异或)
先对 0~n 全部异或，再异或数组中所有数，成对的消掉，剩下就是缺失的。

```java
class Solution {
    public int missingNumber(int[] nums) {
        int n = nums.length;
        int ans = 0;
        for (int i = 0; i <= n; i++) ans ^= i;
        for (int i : nums) ans ^= i;
        return ans;
    }
}
```

## 题解(数学法)
0~n 的等差数列和减去数组元素和，差值即缺失数。

```java
class Solution {
    public int missingNumber(int[] nums) {
        int n = nums.length;
        int cur = 0, sum = n * (n + 1) / 2;
        for (int i : nums) cur += i;
        return sum - cur;
    }
}
```
