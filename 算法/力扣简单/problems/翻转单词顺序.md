# 翻转单词顺序

## 题干
输入一个英文句子，翻转句子中单词的顺序，但单词内字符的顺序不变。标点符号和普通字母一样处理。

## 复杂度
时间：{{c1::O(n)}} — 拆分 + 遍历
空间：{{c1::O(n)}} — 字符串数组

## 题解
按空格 split，倒序遍历数组，跳过空串（连续空格产生），单词间补一个空格。

```java
class Solution {
    public String reverseWords(String s) {
        String[] strArr = s.split(" ");
        String str = "";
        for (int i = strArr.length - 1; i >= 0; i--) {
            if (strArr[i].equals(""))
                continue;
            if (i == strArr.length - 1) {
                str = str + strArr[i];
                continue;
            } else if (i == 0) {
                str = str + " " + strArr[i];
                break;
            }
            str = str + " " + strArr[i];
        }
        return str;
    }
}
```
