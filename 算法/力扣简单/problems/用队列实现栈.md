# 用队列实现栈

## 题干
请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（push、top、pop 和 empty）。实现 MyStack 类。

## 复杂度
push：{{c1::O(1)}}
pop：{{c1::O(1)}}
top：{{c1::O(1)}}
空间：{{c1::O(n)}} — 均使用 Deque 双端队列实现

## 题解(Deque)
Deque 双端队列的 push/pop/peek 均在队首操作，天然实现了栈的后入先出。

```java
class MyStack {
    Deque<Integer> stack1;

    public MyStack() {
        stack1 = new LinkedList<>();
    }

    public void push(int x) {
        stack1.push(x);
    }

    public int pop() {
        return stack1.pop();
    }

    public int top() {
        return stack1.peek();
    }

    public boolean empty() {
        if (stack1.size() == 0) {
            return true;
        }
        return false;
    }
}
```
