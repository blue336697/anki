# 替换空格

## 题干
请实现一个函数，把字符串 s 中的每个空格替换成 "%20"。

## 复杂度
时间：{{c1::O(n)}} — 遍历字符串
空间：{{c1::O(n)}} — StringBuilder

## 关键技巧
最简单：s.replace(" ", "%20")。
面试可写遍历版本：遍历 char 数组，遇空格 append("%20")，否则 append(c)。

## 题解
遍历每个字符，空格替换为 %20，其他字符直接追加。或直接用 s.replace()。

```java
class Solution {
    public String replaceSpace(String s) {
        return s.replace(" ", "%20");
    }
}
```
