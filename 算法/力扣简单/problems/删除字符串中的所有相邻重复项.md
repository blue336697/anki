# 删除字符串中的所有相邻重复项

## 题干
给出由小写字母组成的字符串 S，重复项删除操作会选择两个相邻且相同的字母并删除它们。反复执行删除操作，直到无法继续删除。返回最终字符串。
![34457_xmKgrAtYScw8L302.png](34457_xmKgrAtYScw8L302.png)

## 复杂度
栈法：时间 {{c1::O(n)}}，空间 {{c1::O(n)}}
原地数组：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}

## 关键技巧
原地数组优化：用 index 指针模拟栈，char[] 数组自身当栈。
index=-1 代表空栈，匹配则 index--，不匹配则 chs[++index]=chs[i]。
最终 new String(chs, 0, index+1) 即为结果，空间 O(1)。

## 题解(栈)
当前字符与栈顶相同则弹出(消除一对)，否则入栈。最后栈中剩余字符逆序拼接。

```java
class Solution {
    public String removeDuplicates(String s) {
        StringBuilder sb = new StringBuilder();
        Stack<Character> stack = new Stack();
        int i = 0;
        while (i < s.length()) {
            char ch = s.charAt(i);
            if (stack.isEmpty() || ch != stack.peek()) {
                stack.push(s.charAt(i));
                i++;
            } else {
                stack.pop();
                i++;
            }
        }
        while (!stack.isEmpty())
            sb.append(stack.pop());
        return sb.reverse().toString();
    }
}
```

## 题解(原地数组)
用 char[] 自身当栈，index 指针模拟栈顶。匹配则 index--，不匹配则覆盖写入。

```java
class Solution {
    public String removeDuplicates(String s) {
        int index = -1;
        char[] chs = s.toCharArray();
        for (int i = 0; i < chs.length; i++) {
            if (index >= 0 && chs[index] == chs[i])
                index--;
            else {
                index++;
                chs[index] = chs[i];
            }
        }
        return String.copyValueOf(chs, 0, index + 1);
    }
}
```
