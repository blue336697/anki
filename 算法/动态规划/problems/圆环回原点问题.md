# 圆环回原点问题

## 题干
题干：在一个长度为 `m` 的圆环上（位置编号 `0..m-1`），从 0 出发走 `n` 步，每一步可以顺时针或逆时针移动 1 格，问最终回到 0 的方案数。

## 定义状态
dp[i][j] = {{c1::走 i 步到达位置 j 的方案数}}
> 两维：步数 × 位置

## 转移方程
dp[i][j] = dp[i-1][{{c1::(j-1+len)%len}}] + dp[i-1][{{c2::(j+1)%len}}]
> 从左右邻居走来，取模处理环形

## 初始化
dp[0][0] = {{c1::1}}（走 0 步在 0 位置有 1 种方案）
> 其他 dp[0][*] = 0

## 计算顺序
i 从 1 到 n，j 从 0 到 len-1。dp[i][j] 依赖 dp[i-1][*]。

## 返回结果
返回 dp[n][0]（走 n 步后回到 0 的方案数）。

## 复杂度
- 时间 O(n×len)：dp[i][j]表示走i步位于位置j的方案数，i从1到n，j从0到len-1 → n×len个状态，每状态O(1)转移 → O(n×len)<br>- 空间 O(len)：第i步只依赖第i-1步，用两个长度为len的数组交替 → O(len)

## 题解
从左右邻居走来的方案数之和。取模处理环形：(j-1+len)%len 防负索引。
```java
class Solution {
    public int climbStairs(int n) {
        int length = 10;
        int[][] dp = new int[n + 1][length];
        dp[0][0] = 1;
        for (int i = 1; i &lt; dp.length; i++)
            for (int j = 0; j &lt; dp[0].length; j++) {
                dp[i][j] = dp[i - 1][(j - 1 + length) % length]
                         + dp[i - 1][(j + 1) % length];
            }
        return dp[n][0];
    }
}
```
