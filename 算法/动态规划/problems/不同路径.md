# 不同路径

## 题干
题干：一个机器人位于 `m x n` 网格的左上角。机器人每次只能向下或者向右移动一步，问到达右下角共有多少条不同路径。


这个题目符合杨辉三角形的规律，

即每个位置的路径数 = 左边位置的路径数 + 上边位置的路径数。

大致有两种解法：

1. 利用排列组合来计算，比如 m=3，n=2 时，路径数就等于组合数。因为到达右下角，向下几步、向右几步都是固定的，总步数为 m+n-2。比如 m=3, n=2，我们只要向下 1 步，向右 2 步就一定能到达终点。要走到右下角一定是向右走 m-1 步，向下走 n-1 步。也就是说总共走 m-1+n-1 = (m+n-2) 步，其中有 m-1 步是向右的。这就是一个组合问题，从 m+n-2 步中选择 m-1 步向右，总共有 C(m+n-2, m-1) 种排列方式。组合公式：C(n, m) = n! / (m! * (n-m)!)

例如 `5! = 5 × 4 × 3 × 2 × 1 = 120`。实际计算组合数时不直接求三个阶乘，而是逐项乘除，降低中间结果溢出的风险。

## 定义状态
dp[i][j] = {{c1::到达 (i,j) 位置的路径数}}
> 从左上角到 (i,j)

## 转移方程
dp[i][j] = {{c1::dp[i-1][j] + dp[i][j-1]}}
> 从上来 + 从左来 = 杨辉三角形

## 初始化
dp[i][0] = {{c1::1}}, dp[0][j] = {{c1::1}}
> 第一行和第一列只有一条路径（一直向右/下）

## 计算顺序
i 从 1 到 m-1，j 从 1 到 n-1。<br>一维优化：cur[j] = cur[j] + cur[j-1]（cur[j] 是上一行值）。

## 返回结果
返回 dp[m-1][n-1]（右下角的路径数）。

## 复杂度
<b>DP</b>：dp[i][j]=dp[i-1][j]+dp[i][j-1]，双重循环遍历网格 → 时间O(m×n)，空间可优化到O(n)（一行正序更新）<br><b>组合数学</b>：C(m+n-2, m-1) → 时间O(min(m,n))，空间O(1)

## 题解(DP)
dp[i][j] = dp[i-1][j] + dp[i][j-1]。一维优化：cur[j] += cur[j-1]。
```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i &lt; m; i++)
            dp[i][0] = 1;
        for (int i = 0; i &lt; n; i++)
            dp[0][i] = 1;
        for (int i = 1; i &lt; m; i++) {
            for (int j = 1; j &lt; n; j++) {
                dp[i][j] = dp[i][j - 1] + dp[i - 1][j];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

## 题解(组合数学)
C(m+n-2, m-1) = (m+n-2)! / ((m-1)! * (n-1)!)<br>总共走 m+n-2 步，选其中 m-1 步向下。用 long 累乘再累除防溢出。
```java
class Solution {
    public int uniquePaths(int m, int n) {
        int total = m + n - 2;
        int choose = Math.min(m - 1, n - 1);
        long res = 1;
        for (int i = 1; i <= choose; i++) {
            res = res * (total - choose + i) / i;
        }
        return (int) res;
    }
}
```
