## 题干
题干：给定单词 `word1` 和 `word2`，返回将 `word1` 转换成 `word2` 所使用的最少操作数。你可以对一个单词进行三种操作：插入一个字符、删除一个字符、替换一个字符。

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数*  。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

## 定义状态
dp[i][j] = {{c1::word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数}}
> 双串 DP，dp[M+1][N+1]

## 转移方程
dp[i][j] = min(删除{{c1::dp[i-1][j]+1}}, 插入{{c1::dp[i][j-1]+1}}, 替换{{c1::dp[i-1][j-1]+1}})<br>若 word1[i-1]==word2[j-1]：dp[i][j] = min(dp[i][j], {{c1::dp[i-1][j-1]}})
> 相等时无需操作（替换代价为 0）<br><img src="image 7.png">

## 初始化
dp[i][0] = {{c1::i}}（删除 i 个字符变空串）<br>dp[0][j] = {{c1::j}}（插入 j 个字符从空串变 word2）
> 空串 vs 非空串的基本操作次数

## 计算顺序
i 从 1 到 n1，j 从 1 到 n2 正向遍历。<br>dp[i][j] 依赖左、上、左上，正序即可。

## 返回结果
返回 dp[n1][n2]（word1 全部转换为 word2 的最少操作数）。

## 复杂度
- 时间 O(m×n)：二维dp表共(m+1)×(n+1)个格子，每格做常数次比较（min of 3 operations） → O(mn)<br>- 空间 O(m×n) → 优化到O(min(m,n))：当前行只依赖上一行和左边，两行滚动即可

## 题解
三种操作取 min，相等时直接继承对角线（代价 0）。
```java
class Solution {
    public int minDistance(String word1, String word2) {
        int n1 = word1.length() + 1;
        int n2 = word2.length() + 1;
        int[][] dp = new int[n1][n2];
        for (int i = 0; i &lt; n1; i++) {
            dp[i][0] = i;
        }
        for (int j = 0; j &lt; n2; j++) {
            dp[0][j] = j;
        }
        for (int i = 1; i &lt; n1; i++) {
            for (int j = 1; j &lt; n2; j++) {
                dp[i][j] = Math.min(Math.min(dp[i-1][j] + 1, dp[i][j-1] + 1), dp[i-1][j-1] + 1);
                if (word1.charAt(i-1) == word2.charAt(j-1)) {
                    dp[i][j] = Math.min(dp[i][j], dp[i-1][j-1]);
                }
            }
        }
        return dp[n1-1][n2-1];
    }
}
```
