# 斐波那契数列

## 题干
题干：给定整数 `n`，返回第 `n` 项斐波那契数（按题目定义的初始值与取模规则）。



## 定义状态
dp[i] = {{c1::第 i 项斐波那契数}}
> F(0)=0, F(1)=1

## 转移方程
dp[i] = {{c1::dp[i-1] + dp[i-2]}}
> 标准斐波那契递推

## 初始化
dp[0] = {{c1::0}}, dp[1] = {{c1::1}}
> 注意：爬楼梯第一项从 1 开始，斐波那契从 0 开始

## 计算顺序
i 从 2 到 n。可滚动变量优化到 O(1)。

## 返回结果
返回 dp[n]（可能需取模 1e9+7）。

## 复杂度
同「斐波那契数」(LC 509)：F(n)=F(n-1)+F(n-2)<br>迭代DP：时间O(n)，空间O(1)。矩阵快速幂：时间O(log n)，空间O(1)

## 题解
dp[i] = dp[i-1] + dp[i-2]，对 1000000007 取模。DP O(n) vs 递归 O(2^n)。
```java
class Solution {
    public int fib(int n) {
        if (n == 0) return 0;
        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 1;
        for (int i = 2; i &lt;= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
            dp[i] %= 1000000007;
        }
        return dp[n];
    }
}
```
