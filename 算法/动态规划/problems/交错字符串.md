# 交错字符串

## 题干
题干：给定字符串 `s1`、`s2`、`s3`，判断 `s3` 是否由 `s1` 与 `s2` 交错组成（保持各自字符相对顺序不变）。



> 我们利用while循环一个一个匹配不太行，对于空串的情况不好处理
> 


[https://www.notion.so](https://www.notion.so)




## 定义状态
dp[i][j] = {{c1::s1 前 i 个 + s2 前 j 个 能否交错组成 s3 前 i+j 个}}
> 双串 DP，布尔型

## 转移方程
dp[i][j] = (dp[i-1][j] && s1[i-1]==s3[i+j-1])<br>&nbsp;&nbsp;&nbsp;&nbsp;{{c1::||}} (dp[i][j-1] && s2[j-1]==s3[i+j-1])
> 当前字符要么来自 s1 要么来自 s2

## 初始化
dp[0][0] = {{c1::true}}<br>第一行/列：连续匹配 s1/s2 与 s3 的前缀
> 处理单个字符串的匹配前缀

## 计算顺序
i 从 1 到 n，j 从 1 到 m。依赖左和上。前提：s1.len + s2.len == s3.len。

## 返回结果
返回 dp[n][m]。

## 复杂度
- 时间 O(n×m)：dp[i][j]表示s1前i个+s2前j个能否组成s3前i+j个，共(n+1)×(m+1)状态，每格O(1) → O(nm)<br>- 空间 O(m)：dp[i][j]只依赖上方dp[i-1][j]和左边dp[i][j-1]，一维数组正序更新 → O(m)

## 题解
dp[i][j] = (dp[i-1][j] && s1[i-1]==s3[i+j-1]) || (dp[i][j-1] && s2[j-1]==s3[i+j-1])。
```java
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        if (s1.length() + s2.length() != s3.length())
            return false;
        int n = s1.length(), m = s2.length();
        boolean[][] dp = new boolean[n + 1][m + 1];
        dp[0][0] = true;
        for (int i = 1; i &lt;= n && s1.charAt(i - 1) == s3.charAt(i - 1); i++)
            dp[i][0] = true;
        for (int j = 1; j &lt;= m && s2.charAt(j - 1) == s3.charAt(j - 1); j++)
            dp[0][j] = true;
        for (int i = 1; i &lt;= n; i++) {
            for (int j = 1; j &lt;= m; j++) {
                dp[i][j] = (dp[i - 1][j] && s1.charAt(i - 1) == s3.charAt(i + j - 1))
                        || (dp[i][j - 1] && s2.charAt(j - 1) == s3.charAt(i + j - 1));
            }
        }
        return dp[n][m];
    }
}
```
