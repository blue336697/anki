# 完全平方数

## 题干
题干：给定整数 `n`，返回和为 `n` 的完全平方数的最少数量（完全平方数指 `1,4,9,...`）。


**这道题另一种解法用到了一个数学定理：四平方定理： 任何一个正整数都可以表示成不超过四个整数的平方之和。 推论：满足四数平方和定理的数n（四个整数的情况），必定满足 `n=4^a(8b+7)`**


## 定义状态
dp[i] = {{c1::和为 i 的最少完全平方数个数}}
> 完全背包求最小值

## 转移方程
dp[i] = {{c1::min(dp[i], dp[i - j*j] + 1)}}, j*j &lt;= i
> 每个完全平方数 j*j 视为一种硬币，完全背包正序

## 初始化
dp[0] = {{c1::0}}<br>dp[i] 初始化为 {{c1::i}}（最坏情况全用 1）
> 和为 0 需要 0 个数

## 计算顺序
i 从 1 到 n 正序遍历。内层枚举 j 满足 j*j <= i。完全背包正序。

## 返回结果
返回 dp[n]。

## 复杂度
- 时间 O(n√n)：外层遍历1~n（O(n)），内层遍历完全平方数j²≤i，j∈[1,√n] → n×√n = O(n√n)<br>- 空间 O(n)：dp数组长度n+1。等价于完全背包：硬币种类为{1,4,9,16,...}，求最少硬币数

## 题解
完全背包：dp[i] = min(dp[i], dp[i - j*j] + 1)。最坏情况全用 1（dp[i]=i）。
```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        for (int i = 1; i &lt;= n; i++) {
            dp[i] = i;
            for (int j = 1; i - j * j &gt;= 0; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```
