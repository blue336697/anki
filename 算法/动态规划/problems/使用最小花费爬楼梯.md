# 使用最小花费爬楼梯

## 题干
给定整数数组 `cost`，其中 `cost[i]` 是踏上第 `i` 阶台阶的花费。你可以从第 0 或第 1 阶开始，每次爬 1 或 2 阶。返回到达楼顶的最小花费（楼顶在最后一阶之上）。

## 定义状态
dp[i] = {{c1::到达第 i 阶的最小花费}}（到达 i 位置后，尚未支付 cost[i]）
> dp 数组长度为 n+1，dp[n] 表示到达楼顶

## 转移方程
dp[i] = Math.min({{c1::dp[i-1] + cost[i-1]}}, {{c1::dp[i-2] + cost[i-2]}})
> 从 i-1 来：付 cost[i-1] 爬 1 步到 i；从 i-2 来：付 cost[i-2] 爬 2 步到 i

## 初始化
dp[0] = {{c1::0}}<br>dp[1] = {{c1::0}}
> 从第 0 或第 1 阶出发无需付费

## 计算顺序
i 从 2 到 n（n = cost.length）正向递推。dp[i] 依赖前两个状态 → 可 O(1) 空间滚动。

## 返回结果
return dp[{{c1::n}}]（即 dp[cost.length]，到达楼顶的最小花费）

## 复杂度
时间 O(n) 空间 O(1)：只需 prev2 和 prev1 两个变量滚动

## 题解(DP-O1空间)
dp[i] 表示到达 i 的最小花费（i=0..n）。出发 dp[0]=dp[1]=0。每步选前一个或前两个位置跳到当前位置，加上对应出发位置的花费。
```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int prev2 = 0; // dp[0]
        int prev1 = 0; // dp[1]
        for (int i = 2; i <= n; i++) {
            int cur = Math.min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1; // dp[n]
    }
}
```

## 题解(DP-数组)
```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 0;
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
        }
        return dp[n];
    }
}
```
