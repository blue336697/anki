# 乘积最大子数组

## 题干
题干：给定整数数组 `nums`，请找出乘积最大的 **连续子数组**（至少包含一个元素），返回该子数组的乘积。


![image.png](image%2019.png)


## 定义状态
imax = {{c1::以当前元素结尾的最大乘积}}<br>imin = {{c2::以当前元素结尾的最小乘积}}
> 必须同时维护最大和最小，因为负数相乘会翻转

## 转移方程
if(nums[i]&lt;0) swap({{c1::imax, imin}})<br>imax = max(imax*nums[i], {{c2::nums[i]}})<br>imin = min(imin*nums[i], {{c3::nums[i]}})
> 负负得正：最小值×负数可能变最大值

## 初始化
imax = {{c1::1}}, imin = {{c2::1}}, max = {{c3::Integer.MIN_VALUE}}
> imax/imin 从 1 开始，遇到负数交换后乘第一个元素

## 计算顺序
一次遍历，每遇到元素先判断正负（负则交换 imax/imin），再更新 imax/imin 和全局 max。

## 返回结果
返回 max（全局最大乘积，不是最后一个 imax）。

## 复杂度
- 时间 O(n)：遍历一次，同时维护以i结尾的最大乘积imax和最小乘积imin（因为负数×负数可能反转变为最大），3次比较/乘法 → O(n)<br>- 空间 O(1)：imax、imin、max三个变量。关键技巧：遇到nums[i]<0时交换imax和imin

## 题解
同时维护 imax 和 imin。遇负数先交换再乘，因最小值×负数可能变最大值。
```java
class Solution {
    public int maxProduct(int[] nums) {
        int max = Integer.MIN_VALUE, imax = 1, imin = 1;
        for (int i = 0; i &lt; nums.length; i++) {
            if (nums[i] &lt; 0) {
                int tmp = imax;
                imax = imin;
                imin = tmp;
            }
            imax = Math.max(imax * nums[i], nums[i]);
            imin = Math.min(imin * nums[i], nums[i]);
            max = Math.max(max, imax);
        }
        return max;
    }
}
```
