# 整数拆分

## 题干
题干：给定正整数 `n`，将其拆分为至少两个正整数之和，使这些整数的乘积最大，返回最大乘积。





## 定义状态
dp[i] = {{c1::正整数 i 拆分后的最大乘积}}
> 至少拆成两个数

## 转移方程
dp[i] = max(dp[i], max({{c1::j * (i-j)}}, {{c2::j * dp[i-j]}}))
> 拆成两个数(j × i-j) 或 继续拆(i-j)取 dp[i-j]

## 初始化
dp[2] = {{c1::1}}（2=1+1→1×1=1）
> dp[0] 和 dp[1] 无意义（无法拆成至少两个数）

## 计算顺序
i 从 3 到 n，j 从 1 到 i-2。dp[i] 依赖 dp[i-j]（更小的子问题已算出）。

## 返回结果
返回 dp[n]。

## 复杂度
<b>DP</b>：dp[i]=max(j×max(i-j, dp[i-j]))，外层i 2~n，内层j 1~i-1 → O(n²)；空间O(n)<br><b>数学（贪心）</b>：尽量拆成3。余0→全3，余1→一个4其余3，余2→一个2其余3 → 时间O(1)，空间O(1)

## 题解(DP)
拆成 j+(i-j) 还是 j+继续拆(i-j)：dp[i] = max(dp[i], max(j*(i-j), j*dp[i-j]))。
```java
class Solution {
    public int integerBreak(int n) {
        int[] dp = new int[n + 1];
        dp[2] = 1;
        for (int i = 3; i &lt;= n; ++i) {
            for (int j = 1; j &lt; i - 1; ++j) {
                dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));
            }
        }
        return dp[n];
    }
}
```

## 题解(数学)
尽量拆 3：n 对 3 取余。<br>余 0 → 3^a；余 1 → 3^(a-1)×4；余 2 → 3^a×2。n≤3 返回 n-1。
