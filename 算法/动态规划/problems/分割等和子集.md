# 分割等和子集

## 题干
题干：给你一个只包含正整数的非空数组 `nums`，判断是否可以分割成两个子集，使得两个子集的元素和相等。



- 为什么倒序遍历就能求到解了
    
    > 这里可能会有人困惑为什么压缩到一维时，要采用逆序。因为在一维情况下，是根据 dp[j] || dp[j - nums[i]]来推d[j]的值，如不逆序，就无法保证在外循环 i 值保持不变 j 值递增的情况下，dp[j - num[i]]的值不会被当前所放入的nums[i]所修改，当j值未到达临界条件前，会一直被nums[i]影响，也即是可能重复的放入了多次nums[i]，为了避免前面对后面产生影响，故用逆序。 举个例子，数组为[2,2,3,5]，要找和为6的组合，i = 0时，dp[2]为真，当i自增到1，j = 4时，nums[i] = 2,dp[4] = dp[4] || dp[4 - 2]为true，当i不变，j = 6时,dp[6] = dp [6] || dp [6 - 2],而dp[4]为true，所以dp[6] = true,显然是错误的。 故必须得纠正在正序情况下，i值不变时多次放入nums[i]的情况。
    > 
- 状态定义：
    
    > 状态定义：dp[i][j]表示从数组的 [0, i] 这个子区间内挑选一些正整数，每个数只能用一次，使得这些数的和恰好等于 j。
    > 




## 定义状态
dp[j] = {{c1::能否从数组中选出一些数，和为 j}}
> 0-1 背包可行性变种，容量 = sum/2

## 转移方程
dp[j] = {{c1::dp[j] | dp[j - nums[i]]}}
> 或运算：不选当前数(保持) 或 选当前数(从 j-nums[i] 转移)

## 初始化
dp[0] = {{c1::true}}
> 不选任何数，和为 0 总是可行的

## 计算顺序
外层 nums[i]，内层 target → nums[i] 倒序遍历。<br>倒序防止同一个元素被重复使用（0-1 背包）。若 sum%2 != 0 直接返回 false。

## 返回结果
返回 dp[target]（target = sum/2）。

## 复杂度
- 时间 O(n×target)：0/1背包问题，target=sum/2。n个物品，每个物品遍历target个容量（倒序） → O(n×target)<br>- 空间 O(target)：一维dp倒序遍历（防止同一物品重复使用），数组长度target+1。为什么倒序：防止同一物品被多次选用

## 题解
0-1 背包变种：dp[j] |= dp[j-num]，倒序遍历防重复。
```java
class Solution {
    public boolean canPartition(int[] nums) {
        int len = nums.length;
        int sum = 0;
        for (int num : nums) sum += num;
        if (sum % 2 != 0) return false;
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        if (nums[0] &lt;= target) dp[nums[0]] = true;
        for (int i = 1; i &lt; len; i++) {
            for (int j = target; j &gt;= nums[i]; j--) {
                if (dp[target]) return true;
                dp[j] = dp[j] | dp[j - nums[i]];
            }
        }
        return dp[target];
    }
}
```
