# 分割等和子集

## 题干
题干：给你一个只包含正整数的非空数组 `nums`，判断是否可以分割成两个子集，使得两个子集的元素和相等。

如果数组总和为奇数，一定无法平分；否则问题转化为：能否从 `nums` 中选出若干个数，使它们的和等于 `sum / 2`。

## 定义状态
dp[j] = {{c1::能否从数组中选出一些数，和为 j}}
> 0-1 背包可行性变种，容量 = sum/2

## 转移方程
dp[j] = {{c1::dp[j] || dp[j - num]}}
> 或运算：不选当前数(保持) 或 选当前数(从 j-nums[i] 转移)

## 初始化
dp[0] = {{c1::true}}
> 不选任何数，和为 0 总是可行的

## 计算顺序
先求总和 `sum`，若 `sum` 为奇数直接返回 `false`。<br>外层遍历每个 `num`，内层从 `target` 倒序遍历到 `num`。倒序是 0-1 背包的关键：保证当前 `num` 在本轮只被使用一次。

## 返回结果
返回 dp[target]（target = sum/2）。

## 复杂度
时间 O(n×target)：`target = sum / 2`，每个数字作为一个 0-1 背包物品，每个物品最多遍历 `target` 个容量 -> O(n×target)<br>空间 O(target)：使用一维 `boolean[] dp`，长度为 `target + 1`，不再保留二维状态

## 题解
0-1 背包可行性问题：`dp[j]` 表示是否能凑出和 `j`。每个 `num` 只能用一次，所以容量 `j` 必须倒序遍历；如果正序遍历，本轮刚更新出的 `dp[j]` 会继续影响更大的容量，等价于同一个 `num` 被重复使用。

把转移翻译成业务含义：

- 不选择当前数字 `num`：是否能凑出 `j`，沿用原来的 `dp[j]`。
- 选择当前数字 `num`：需要此前已经能够凑出 `j - num`，即 `dp[j - num]`。
- 两条路径任意一条成立即可，因此转移是 `dp[j] = dp[j] || dp[j - num]`。

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }

        if ((sum & 1) == 1) {
            return false;
        }

        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
            if (dp[target]) {
                return true;
            }
        }

        return dp[target];
    }
}
```
