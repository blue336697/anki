# 青蛙跳台阶问题

## 题干
题干：一只青蛙一次可以跳上 1 级台阶，也可以跳上 2 级台阶。求该青蛙跳上一个 `n` 级的台阶总共有多少种跳法。


https://www.cnblogs.com/CXCXCXC/p/4641812.html


## 定义状态
dp[i] = {{c1::跳上第 i 级台阶的跳法数}}
> 与爬楼梯完全相同

## 转移方程
dp[i] = {{c1::dp[i-1] + dp[i-2]}}
> 最后一步跳 1 级或 2 级

## 初始化
dp[0] = {{c1::1}}, dp[1] = {{c2::1}}, dp[2] = {{c3::2}}
> 注意 dp[0]=1 的处理，结果需对 1e9+7 取模

## 计算顺序
i 从 3 到 n 正向遍历。可优化为两个变量 i, j 滚动。

## 返回结果
返回 dp[n] % 1000000007。

## 复杂度
同「爬楼梯」(LC 70)：dp[i]=dp[i-1]+dp[i-2] → 时间O(n)，空间O(1)

## 题解
dp[i] = dp[i-1] + dp[i-2]，结果对 1000000007 取模。dp[0]=1 用于统一递推。
```java
class Solution {
    public int numWays(int n) {
        int[] dp = new int[Math.max(n + 1, 3)];
        dp[0] = 1;
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i &lt;= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
            dp[i] %= 1000000007;
        }
        return dp[n];
    }
}
```
