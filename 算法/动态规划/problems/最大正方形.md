# 最大正方形

## 题干
题干：给定一个由 `'0'` 和 `'1'` 组成的二维矩阵 `matrix`，返回只包含 `'1'` 的最大正方形的面积。

## 定义状态
dp[i+1][j+1] = {{c1::以 matrix[i][j] 为右下角的最大正方形边长}}
> dp 比 matrix 多一行一列，方便处理边界<br><img src="image 15.png">

## 转移方程
若 matrix[i][j]=='1'：dp[i+1][j+1] = min({{c1::dp[i][j+1]}}, {{c2::dp[i+1][j]}}, {{c3::dp[i][j]}}) + 1
> 取左、上、左上最小值+1，边长受限于最短边

## 初始化
dp 数组全部初始化为 {{c1::0}}（多出的一行一列自然为 0）
> matrix[0][0] 也能统一处理

## 计算顺序
i 从 0 到 high-1，j 从 0 到 wide-1 双重循环。<br>一维优化：dp[wide+1] + northwest 变量保存左上旧值，倒序遍历 j。

## 返回结果
返回 maxSide * maxSide（最大边长的平方 = 面积）。

## 复杂度
- 时间 O(M×N)：双重循环遍历矩阵所有格子，每格取min(左,上,左上)+1 → O(MN)<br>- 空间 O(N)：dp[i][j]只依赖左边、上边、左上角三个位置 → 保留一行dp数组+一个prev对角变量 → O(N)

## 题解(DP)
取左、上、左上最小值+1。因正方形边长受限于最短板。
```java
class Solution {
    public int maximalSquare(char[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0)
            return 0;
        int maxSpace = 0;
        int high = matrix.length;
        int wide = matrix[0].length;
        int[][] dp = new int[high + 1][wide + 1];
        for (int i = 0; i &lt; high; i++) {
            for (int j = 0; j &lt; wide; j++) {
                if (matrix[i][j] == '1') {
                    dp[i+1][j+1] = Math.min(
                        Math.min(dp[i+1][j], dp[i][j+1]),
                        dp[i][j]) + 1;
                    maxSpace = Math.max(maxSpace, dp[i+1][j+1]);
                }
            }
        }
        return maxSpace * maxSpace;
    }
}
```

## 题解(降维优化)
一维 dp[wide+1] + northwest 保存左上旧值。每列遍历时 dp[col+1] 表示上一行的值。
```java
class Solution {
    public int maximalSquare(char[][] matrix) {
        if (matrix == null || matrix.length &lt; 1 || matrix[0].length &lt; 1)
            return 0;
        int height = matrix.length;
        int width = matrix[0].length;
        int maxSide = 0;
        int[] dp = new int[width + 1];
        int northwest = 0;
        for (char[] chars : matrix) {
            northwest = 0;
            for (int col = 0; col &lt; width; col++) {
                int nextNorthwest = dp[col + 1];
                if (chars[col] == '1') {
                    dp[col + 1] = Math.min(Math.min(dp[col], dp[col + 1]), northwest) + 1;
                    maxSide = Math.max(maxSide, dp[col + 1]);
                } else {
                    dp[col + 1] = 0;
                }
                northwest = nextNorthwest;
            }
        }
        return maxSide * maxSide;
    }
}
```
