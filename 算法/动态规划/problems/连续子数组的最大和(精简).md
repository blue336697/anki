# 连续子数组的最大和(精简)

## 题干
题干：给定整数数组 `nums`，请找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。

采用动态规划的思想完成
有两种处理方法，创建一个临时变量指向数组的第一个，
然后和数组本身形象化成两个数组，可以这样处理的原因是因为，
我们需要判读当前遍历数组的值的前一个值是否为正数还是负数，
如果是前一个值为负数我们就对当前值不变，如果是正数我们就相加


## 定义状态
nums[i] 复用为 {{c1::以 nums[i] 结尾的最大子数组和}}
> 原地修改：直接在原数组上做 DP

## 转移方程
nums[i] += max({{c1::nums[i-1]}}, 0)
> 前一个位置贡献为正则累加，为负则丢弃

## 初始化
res = {{c1::nums[0]}}
> 第一个元素即为初始最大值

## 计算顺序
i 从 1 到 len-1 正向遍历。每次 nums[i] += max(nums[i-1], 0)，再更新 res。

## 返回结果
返回 res（全局最大值）。

## 复杂度
- 时间 O(n)：遍历数组一次，每步做一次 Math.max(nums[i-1], 0) 和一次加法，共 n-1 次 O(1) 操作 → O(n)<br>- 空间 O(1)：原地修改 nums 数组（不额外分配），只用 res 一个变量

## 题解
原地 DP：nums[i] += max(nums[i-1], 0)。前一个位置贡献为正则累加，为负则丢弃。
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int res = nums[0];
        for (int i = 1; i &lt; nums.length; i++) {
            nums[i] += Math.max(nums[i - 1], 0);
            res = Math.max(res, nums[i]);
        }
        return res;
    }
}
```
