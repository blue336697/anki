# 青蛙跳台阶问题 II

## 题干
题干：一只青蛙一次可以跳上 1..n 级台阶。求跳上 `n` 级台阶总共有多少种跳法。

这个是台阶问题的变种，不限制青蛙最大能跳多少阶，输入n，青蛙一次能跳0、1、、、、n，问到n阶最大的跳法
这里的青蛙比前面两道题的青蛙更厉害一些，他一次可以跳1阶，2阶，3阶……。所以要想跳到第n个台阶，我们可以从第1个台阶跳上来，也可以从第2个台阶跳上来……，所以递推公式是：f(n)=f(n-1)+f(n-2)+……+f(2)+f(1);
同样如果我们想跳到第n-1个台阶，也可以列出下面这个公式：f(n-1)=f(n-2)+……+f(2)+f(1);
通过这两个公式我们可以得出
f(n)=2*f(n-1)
实际上他是个等比数列，base case当n等于1的时候结果为1，来看下代码


## 定义状态
f(n) = {{c1::跳上第 n 级台阶的跳法数}}
> 不限制最大跳跃距离

## 转移方程
f(n) = {{c1::f(n-1) + f(n-2) + ... + f(2) + f(1)}}<br>化简：f(n) = {{c1::2 * f(n-1)}}
> f(n) - f(n-1) = f(n-1)，推出等比数列

## 初始化
f(1) = {{c1::1}}
> 公比 2，等比数列

## 计算顺序
f(1)=1，从 2 到 n：dp[i] = 2 * dp[i-1]（或直接返回 2^(n-1)）。

## 返回结果
返回 dp[n]（或直接用公式 2^(n-1)）。

## 复杂度
变态跳台阶：每次可跳1~n级 → dp[i]=2^(i-1)<br>- 时间 O(n)：前缀和一次遍历 → O(n)；或用公式2^(n-1)+快速幂 → O(log n)<br>- 空间 O(1)：一个preSum变量

## 题解
等比数列：f(n) = 2 * f(n-1) = 2^(n-1)。dp[i] = 2 * dp[i-1]。
```java
class Solution {
    public int numWays(int n) {
        int[] dp = new int[Math.max(n + 1, 3)];
        dp[0] = 1;
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i &lt;= n; i++) {
            dp[i] = 2 * dp[i - 1];
        }
        return dp[n];
    }
}
```
