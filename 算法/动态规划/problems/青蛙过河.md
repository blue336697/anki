# 403. 青蛙过河
<!-- anki-deck: 青蛙过河 -->

## 题干
一只青蛙想要过河。河流被分成 `n` 个单元格，每个单元格上有一块石头（或没有）。给定石头的坐标数组 `stones`（严格递增），青蛙从第一块石头开始，第一次跳跃距离必须是 1。如果上一步跳了 `k` 个单位，下一步可以跳 `k-1`、`k` 或 `k+1` 个单位。判断青蛙能否到达最后一块石头。

示例：`stones=[0,1,3,5,6,8,12,17]` → `true`

## 定义状态
dp = {{c1::Map&lt;Integer, Set&lt;Integer&gt;&gt;}}，key=石头位置，value=到达该位置的所有可能步长 k
> 每块石头记录所有能到达它的跳跃步长；用 HashMap 而非数组，按位置索引而非按序号

## 转移方程
对每块石头的每个步长 k，尝试 step = {{c1::k-1, k, k+1}}<br>
next = s + step<br>
若 {{c2::next == last}} → 直接 return true（找到终点）<br>
若 {{c3::dp.containsKey(next)}} → dp.get(next).add(step)
> 用 HashMap 的 containsKey 替代二分查找，O(1) 判断石头是否存在

## 初始化
dp.get(0).add({{c1::0}})<br>
last = stones[stones.length - 1]
> 起始位置步长为 0，使得第一跳 k=0→k+1=1 符合题意；记录终点位置用于提前返回

## 计算顺序
外层遍历 stones 数组中每块石头的位置 s，内层遍历 dp.get(s) 中所有步长 k。
> 基于当前石头的位置手动计算下一跳，而非依赖数组下标

## 返回结果
遍历过程中 {{c1::next == last}} 时立即 return true<br>
遍历完仍未到达 → {{c1::return stones.length == 1}}（只有一块石头时天然可达）
> HashMap 解法可以提前返回，无需等到遍历结束

## 复杂度
时间：{{c1::O(n^2)}} — 每块石头的每个步长都要尝试三种跳跃<br>
空间：{{c1::O(n^2)}} — 最坏情况每块石头 Set 大小 O(n)

## 题解(DP-HashMap)
HashMap 以石头位置为 key，containsKey 判断石头是否存在。跳到最后一块石头时提前返回 true。
```java
class Solution {
    public boolean canCross(int[] stones) {
        Map<Integer, Set<Integer>> dp = new HashMap<>();
        for (int s : stones) dp.put(s, new HashSet<>());
        dp.get(0).add(0);
        int last = stones[stones.length - 1];
        for (int s : stones) {
            for (int k : dp.get(s)) {
                for (int step = k - 1; step <= k + 1; step++) {
                    if (step <= 0) continue;
                    int next = s + step;
                    if (next == last) return true;
                    if (dp.containsKey(next)) {
                        dp.get(next).add(step);
                    }
                }
            }
        }
        return stones.length == 1;
    }
}
```
