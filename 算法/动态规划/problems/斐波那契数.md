# 斐波那契数

## 题干
题干：给定整数 `n`，返回第 `n` 个斐波那契数（按题目定义）。

![image.png](image%2033.png)


## 定义状态
F(n) = {{c1::第 n 个斐波那契数}}
> F(0)=0, F(1)=1, F(2)=1

## 转移方程
F(n) = {{c1::F(n-1) + F(n-2)}}
> 与爬楼梯 n 阶等价，初始值略有不同

## 初始化
n==0 → {{c1::0}}, n==1||n==2 → {{c2::1}}
> 边界条件判断

## 计算顺序
可用迭代或递归（递归会超时）。DP：从 2 到 n 迭代。

## 返回结果
返回 F(n)。

## 复杂度
- 时间 O(n)：自底向上迭代n次加法 → O(n)<br>- 空间 O(1)：prev1、prev2两个滚动变量<br>矩阵快速幂优化：O(log n)/O(1)。递归（无记忆化）：O(2^n)/O(n) — 不推荐

## 题解
递归版简洁但指数复杂度 O(2^n)，DP 迭代最优 O(n)。F(0)=0, F(1)=1, F(2)=1。
```java
class Solution {
    public int fib(int n) {
        if (n == 0) return 0;
        if (n == 1 || n == 2) return 1;
        return fib(n - 1) + fib(n - 2);
    }
}
```
