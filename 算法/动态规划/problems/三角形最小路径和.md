# 三角形最小路径和

## 题干
题干：给定三角形数组 `triangle`，从顶部到底部每一步只能走到下一行相邻位置，返回最小路径和。

每一步只能移动到下一行中**相邻**的节点上。相邻的节点在这里指的是**下标与上一层节点下标相同**，或**下标等于上一层节点下标 + 1** 的两个节点。


## 定义状态
dp[j] = {{c1::从底部到当前行第 j 列的最小路径和}}
> 自底向上：dp 初始化为最后一行的副本 + 1 位

## 转移方程
dp[j] = min({{c1::dp[j]}}, {{c2::dp[j+1]}}) + triangle[i][j]
> 从下一行的相邻两个位置（左下、右下）取最小 + 当前值

## 初始化
dp 初始化为最后一行的值（+1 位防止越界）
> 从最底层开始向上递推

## 计算顺序
自底向上：i 从 n-1 到 0，j 从 0 到 i 正向遍历。<br>好处：不需要处理三角形边缘的边界条件。

## 返回结果
返回 dp[0]（从底部到顶部的唯一位置）。

## 复杂度
- 时间 O(n²)：三角形n行，第i行i个元素，总计n(n+1)/2个状态，每个做min+加法 → O(n²)<br>- 空间 O(n)：自底向上DP，每行只依赖下一行 → 保留一个长度n+1的dp数组

## 题解
自底向上：dp[j] = min(dp[j], dp[j+1]) + triangle[i][j]。无需处理三角形边缘边界。
```java
class Solution {
    public int minimumTotal(List&lt;List&lt;Integer&gt;&gt; triangle) {
        int n = triangle.size();
        int[] dp = new int[n + 1];
        for (int i = n - 1; i &gt;= 0; i--) {
            for (int j = 0; j &lt;= i; j++) {
                dp[j] = Math.min(dp[j], dp[j + 1]) + triangle.get(i).get(j);
            }
        }
        return dp[0];
    }
}
```
