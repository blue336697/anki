# 最大子数组和(返回位置)

## 题干
题干：给定整数数组 `nums`，找出最大和的连续子数组，返回 `[maxSum, startIndex, endIndex]`。

与标准「最大子数组和」的区别：除了返回最大和，还要返回子数组的**起始和结束位置**。

## 定义状态
dp = {{c1::以当前元素结尾的最大子数组和}}<br>maxSum = {{c2::全局最大子数组和}}<br>tempStart = {{c3::当前子数组的起始位置}}
> 需要额外维护起始位置

## 转移方程
if (dp + nums[i] &lt; nums[i]) { dp = nums[i]; tempStart = {{c1::i}}; }<br>else dp = {{c2::dp + nums[i]}};
> 前缀为负贡献时重新开始

## 初始化
dp = {{c1::nums[0]}}, maxSum = {{c2::nums[0]}}, tempStart = {{c3::0}}, start = 0, end = 0
> 全部从第一个元素开始

## 计算顺序
i 从 1 到 len-1 正向遍历。维护 tempStart 记录当前子数组起点。

## 返回结果
返回 [maxSum, start, end]。<br>注意：只有 dp 严格大于 maxSum 时才更新 start 和 end。

## 复杂度
- 时间 O(n)：与标准 Kadane 算法相同，遍历数组一次，每步额外维护 tempStart/start/end 三个索引变量（O(1)） → O(n)<br>- 空间 O(1)：只需 dp、maxSum、tempStart、start、end 五个变量，不随 n 增长

## 题解
维护 tempStart 记录当前子数组起点，dp > maxSum 时更新 start/end。
```java
public class Solution {
    public static int[] maxSubArrayRange(int[] nums) {
        if (nums == null || nums.length == 0)
            return new int[]{-1, -1};
        int dp = nums[0];
        int maxSum = nums[0];
        int tempStart = 0;
        int start = 0;
        int end = 0;
        for (int i = 1; i &lt; nums.length; i++) {
            if (dp + nums[i] &lt; nums[i]) {
                dp = nums[i];
                tempStart = i;
            } else {
                dp = dp + nums[i];
            }
            if (dp &gt; maxSum) {
                maxSum = dp;
                start = tempStart;
                end = i;
            }
        }
        return new int[]{maxSum, start, end};
    }
}
```
