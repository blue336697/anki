# 规划兼职工作

## 题干
给定若干兼职工作，每个工作有开始时间、结束时间和收益。选择若干互不重叠的工作，使总收益最大。

输入由等长数组 `startTime`、`endTime` 和 `profit` 表示；当上一份工作的结束时间小于等于下一份工作的开始时间时，两份工作不冲突。

## 定义状态
将工作按结束时间升序排序，dp[i] = {{c1::只考虑排序后前 i 份工作时能够获得的最大收益}}
> dp 的下标表示工作数量；第 i 份工作的数组下标是 i-1

## 转移方程
dp[i] = max({{c1::dp[i-1]}}, {{c1::dp[pre] + jobs[i-1].profit}})
> 不选当前工作，或选择当前工作并接在最后一个结束时间不晚于当前开始时间的前缀之后

## 初始化
dp[0] = {{c1::0}}
> 不选择任何工作时收益为 0

## 计算顺序
先将三组输入合并为 `[start, end, profit]`，按 `end` 升序排序。`i` 从 1 到 `n` 正向计算；对每份工作二分查找前 `i-1` 份工作中结束时间不大于当前开始时间的工作数量 `pre`。

## 返回结果
返回 `dp[n]`，即考虑全部工作时的最大收益。

## 复杂度
时间 O(n log n)：排序需要 O(n log n)，随后处理 n 份工作，每份工作二分查找一次 O(log n)，合计 O(n log n)。<br>空间 O(n)：保存工作数组和长度为 n+1 的 dp 数组。

## 题解(DP+二分)
这是带权区间调度。按结束时间排序后，`dp[i-1]` 表示不选当前工作；二分得到的 `pre` 是能与当前工作兼容的工作前缀长度，`dp[pre] + profit` 表示选择当前工作的收益。

```java
class Solution {
    public int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
        int n = startTime.length;
        int[][] jobs = new int[n][3];
        for (int i = 0; i < n; i++) {
            jobs[i] = new int[]{startTime[i], endTime[i], profit[i]};
        }
        Arrays.sort(jobs, Comparator.comparingInt(job -> job[1]));

        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            int start = jobs[i - 1][0];
            int compatibleCount = upperBoundEndTime(jobs, i - 1, start);
            dp[i] = Math.max(
                    dp[i - 1],
                    dp[compatibleCount] + jobs[i - 1][2]
            );
        }
        return dp[n];
    }

    private int upperBoundEndTime(int[][] jobs, int rightExclusive, int start) {
        int left = 0;
        int right = rightExclusive;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (jobs[mid][1] <= start) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```
