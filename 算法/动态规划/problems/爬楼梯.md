# 爬楼梯

## 题干
题干：假设你正在爬楼梯，需要 `n` 阶才能到达楼顶。每次你可以爬 1 或 2 个台阶，问共有多少种不同的方法可以爬到楼顶。

![image.png](image%2010.png)


> 我个人是不建议为f[0]设置值的，循环里面应该从3开始。 题目说到了n是一个正整数，那么n就不会是0，那么如果循环里面，以2为开始，就会面临f[2] = f[1] + f[0] 所以也就违背了函数的入参为正整数的原则。 如果为f[0]指定值的话，通过下面的方程，可能会改变f[2]的值，因为不知道应该为f[0]设置0还是1， 但是我们可以明确的知道f[2]就是有2种方法，所以我们可以直接赋值f[2]=2，尽量避免其他可变因素。 而f[n]也正好为第n阶所求的。
> 


## 定义状态
f(n) = {{c1::爬到第 n 阶的方法数}}
> 类似斐波那契

## 转移方程
f(n) = {{c1::f(n-1) + f(n-2)}}
> 最后一步跨 1 阶或 2 阶

## 初始化
f(1) = {{c1::1}}, f(2) = {{c1::2}}
> 1 阶只有 1 种，2 阶有 1+1 和 2 两种

## 计算顺序
从 3 到 n 正向递推。<br>可以三变量滚动：p, q, r → r=p+q; p=q; q=r → O(1) 空间。

## 返回结果
返回 f(n) 或滚动变量 r。

## 复杂度
<b>迭代DP</b>：dp[i]=dp[i-1]+dp[i-2]，从1到n迭代n次加法 → 时间O(n)，空间O(1)（prev2/prev1/curr三个变量）<br><b>矩阵快速幂</b>：时间O(log n)，空间O(1)<br><b>递归（无记忆化）</b>：时间O(2^n)，空间O(n) — 不推荐

## 题解(DP)
三变量滚动：p=f(n-2), q=f(n-1), r=p+q。O(n) O(1)。
```java
class Solution {
    public int climbStairs(int n) {
        if (n &lt;= 2) return n;
        int[] f = new int[n + 1];
        f[1] = 1;
        f[2] = 2;
        for (int i = 3; i &lt;= n; i++) {
            f[i] = f[i - 1] + f[i - 2];
        }
        return f[n];
    }
}
```
