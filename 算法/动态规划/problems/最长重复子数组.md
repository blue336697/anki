# 最长重复子数组

## 题干
题干：给定两个整数数组 `nums1` 和 `nums2`，返回它们的最长公共 **连续子数组** 的长度。


定义状态：dp[i][j] 表示以数组一的下标 i 为结尾、数组二的下标 j 为结尾的最长公共子串长度。

最长公共子串长度的推导如下：

- 如果当前遍历到的 nums1[i] 和 nums2[j] 相同，那么基础上 dp[i][j] = 1。
- 这时要考虑它们之前的部分是否也相同：
- 如果之前不相同（即 dp[i-1][j-1] = 0），那么 dp[i][j] = 1。
- 如果之前也相同（即 dp[i-1][j-1] > 0），那么 dp[i][j] = dp[i-1][j-1] + 1。
- 注意：以上分析的是“同进退”的情况，错位的情况还需要单独考虑。

转移方程（长度为 i、j）：

- 当 nums1[i-1] != nums2[j-1] 时，dp[i][j] = 0；
- 当 nums1[i-1] == nums2[j-1] 时，dp[i][j] = dp[i-1][j-1] + 1。

初始化部分：全部初始化为 0，当 i == 0 或 j == 0 时，没有公共部分。

## 定义状态
dp[i][j] = {{c1::以 nums1[i-1] 和 nums2[j-1] 结尾的最长公共子数组长度}}
> 注意：要求连续！与 LCS 不同

## 转移方程
相等：dp[i][j] = {{c1::dp[i-1][j-1] + 1}}<br>不等：dp[i][j] = {{c2::0}}
> 不等必须归零！这是与 LCS 的关键区别

## 初始化
dp[*][*] = {{c1::0}}
> 全部初始化为 0，空数组无公共部分

## 计算顺序
i 从 1 到 len1，j 从 1 到 len2。<br>一维优化需倒序遍历 j，不等时手动 dp[j]=0 覆盖旧值。

## 返回结果
返回 maxLen（遍历过程中持续更新的全局最大值）。<br>不是 dp[len1][len2]，因为最长子数组不一定在末尾。

## 复杂度
- 时间 O(m×n)：双重循环，dp[i][j]表示以nums1[i-1]和nums2[j-1]结尾的最长公共子数组 → m×n个状态O(1)比较 → O(mn)<br>- 空间 O(min(m,n))：dp[i][j]只依赖dp[i-1][j-1]（左上角），可倒序更新一维数组 → O(min(m,n))

## 题解(二维DP)
相等 dp[i][j] = dp[i-1][j-1] + 1；不等必须清零！与 LCS 的关键区别。
```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int[][] dp = new int[nums1.length + 1][nums2.length + 1];
        int maxLen = 0;
        for (int i = 1; i &lt; dp.length; i++) {
            for (int j = 1; j &lt; dp[0].length; j++) {
                if (nums1[i - 1] == nums2[j - 1])
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                maxLen = Math.max(dp[i][j], maxLen);
            }
        }
        return maxLen;
    }
}
```

## 题解(一维优化)
倒序遍历 j 防止覆盖，不等时手动清零 dp[j]=0。
```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int[] dp = new int[nums2.length + 1];
        int maxLen = 0;
        for (int i = 1; i &lt;= nums1.length; i++) {
            for (int j = nums2.length; j &gt;= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1])
                    dp[j] = dp[j - 1] + 1;
                else
                    dp[j] = 0;
                maxLen = Math.max(dp[j], maxLen);
            }
        }
        return maxLen;
    }
}
```
