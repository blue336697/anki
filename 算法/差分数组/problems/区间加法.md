# 370. 区间加法

## 题干
假设你有一个长度为 `length` 的数组，初始值全为 0。给定一组更新操作 `updates[i] = [startIdx, endIdx, inc]`，对于每个操作，将数组中从下标 `startIdx` 到 `endIdx`（包含两端）的每个元素加上 `inc`。返回操作完成后的最终数组。

示例：`length=5, updates=[[1,3,2],[2,4,3],[0,2,-2]]` → `[-2,0,3,5,3]`

## 差分策略
构建差分数组：`diff[i] = arr[i] - arr[i-1]`（初始全 0 时 diff 也全 0）

区间更新：`diff[start] += inc` ，`diff[end+1] -= inc`（注意 end+1 越界）

前缀和还原：遍历 diff，`arr[i] = arr[i-1] + diff[i]`，得到最终数组

核心原理：
{{c1::diff[start] += inc}} — 从 start 开始，prefix sum 都会 +inc
{{c2::diff[end+1] -= inc}} — 从 end+1 开始，prefix sum 不再受 +inc 影响

## 复杂度
时间：{{c1::O(U+N)}}，U 为更新次数（构建 diff），N 为数组长度（前缀和还原）
空间：{{c1::O(N)}} — diff 数组（若不计结果数组，可复用结果数组当 diff）

## 题解（差分数组）
对每次更新 [start, end, inc]：
- `res[start] += inc`
- 若 `end+1 < length`：`res[end+1] -= inc`

遍历完所有更新后，对 res 做一次前缀和即得答案。**注意**：这里直接复用结果数组作为 diff，省去额外 diff 数组。

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        int[] res = new int[length];
        // 原地构建差分数组
        for (int[] update : updates) {
            int start = update[0];
            int end = update[1];
            int inc = update[2];
            res[start] += inc;
            if (end + 1 < length) {
                res[end + 1] -= inc;
            }
        }
        // 前缀和还原原始数组
        for (int i = 1; i < length; i++) {
            res[i] += res[i - 1];
        }
        return res;
    }
}
```
