# 多数元素

## 题干
给定一个大小为 n 的数组 nums，返回其中的多数元素。多数元素是指在数组中出现次数大于 n/2 的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。
![image.png](image.png)

## 复杂度
HashMap法：时间 {{c1::O(n)}}，空间 {{c1::O(n)}}
Boyer-Moore投票：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}

## 关键技巧
Boyer-Moore 投票算法（O(1)空间）：
candidate = nums[0], count = 1
遍历：若 count==0 则换 candidate，num==candidate 则 count++，否则 count--
原理：多数元素数量 > n/2，一定能抵消所有其他元素并胜出。

## 题解(HashMap)
统计频率，遇到计数 > n/2 直接返回，提前退出。

```java
public class Solution {
    public int majorityElement(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        int n = nums.length;
        for (int x : nums) {
            int c = cnt.getOrDefault(x, 0) + 1;
            if (c > n / 2) return x;
            cnt.put(x, c);
        }
        return -1;
    }
}
```
