# 两个数组的交集

## 题干
给定两个数组 nums1 和 nums2，返回它们的交集。输出结果中的每个元素一定是唯一的。不考虑输出顺序。

## 复杂度
时间：{{c1::O(n+m)}} — 遍历两个数组
空间：{{c1::O(n)}} — HashMap 存 nums1

## 关键技巧
去重技巧：map value 做状态标记
1：nums1中出现过（待选）
2：已经加入结果集（避免重复输出）
复用 nums1 数组空间存储结果，最后 copyOf 截取。

## 题解(HashMap去重)
用map的value标记状态：1=第一个数组出现过，2=已加入结果集。

```java
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        Map<Integer, Integer> map = new HashMap<>();
        for(int i = 0; i < nums1.length; i++){
            if(map.containsKey(nums1[i]))
                continue;
            else
                map.put(nums1[i], 1);
        }
        int j = 0;
        for(int i = 0; i < nums2.length; i++){
            if(map.containsKey(nums2[i]) && map.get(nums2[i]) == 1){
                nums1[j] = nums2[i];
                map.put(nums2[i], map.get(nums2[i]) + 1);
                j++;
            }else
                continue;
        }
        return Arrays.copyOf(nums1, j);
    }
}
```
