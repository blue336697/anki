# 有效的字母异位词

## 题干
给定两个字符串 s 和 t，编写一个函数来判断 t 是否是 s 的字母异位词。字母异位词：两个字符串中每个字符的出现次数相同。

## 复杂度
时间：{{c1::O(n)}} — 一次遍历两个字符串
空间：{{c1::O(26)=O(1)}} — 固定大小数组

## 关键技巧
当 key 范围有限且连续时（如26个小写字母），用固定大小数组代替 HashMap。
数组比 HashMap 更快、更省内存（无装箱开销）。
本质是计数排序思想的简化版：字符→索引，值→计数。

## 题解(原地哈希)
s对应字符++，t对应字符--，最后全0则互为异位词。

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if(s == null || t == null || s.length() != t.length())
            return false;
        int[] hash = new int[26];
        for(int i = 0; i < s.length(); i++){
            hash[s.charAt(i) - 'a'] ++;
            hash[t.charAt(i) - 'a'] --;
        }
        for(int i = 0; i < hash.length; i++){
            if(hash[i] != 0)
                return false;
        }
        return true;
    }
}
```
