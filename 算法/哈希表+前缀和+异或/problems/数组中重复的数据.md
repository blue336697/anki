# 数组中重复的数据

## 题干
给你一个长度为 n 的整数数组 nums，其中 nums 的所有整数都在范围 [1, n] 内，且每个整数出现一次或两次。请你找出所有出现两次的整数，并以数组形式返回。时间复杂度 O(n)，空间复杂度 O(1)。
![image 8.png](image%208.png)

## 复杂度
取反标记法：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}
加n标记法：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}

## 关键技巧
原地哈希思想：利用原数组做标记，不额外开数组。
方法1（取反）：访问过就取反，第二次访问时发现已是负数 → 重复
方法2（加n）：访问一次加n，访问两次加2n，最终值 > 2n的索引即重复
共同前提：值范围 [1, n]，可以映射到索引 [0, n-1]。

## 题解(取反标记)
用原数组做标记：将nums[x-1]取反，若第二次访问时已为负数，则x是重复值。

```java
class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        int n = nums.length;
        List<Integer> ans = new ArrayList<Integer>();
        for (int i = 0; i < n; ++i) {
            int x = Math.abs(nums[i]);
            if (nums[x - 1] > 0) {
                nums[x - 1] = -nums[x - 1];
            } else {
                ans.add(x);
            }
        }
        return ans;
    }
}
```

## 题解(加n标记)
每个数对应的索引加n，重复的数对应的索引会被加2次，值 > 2n 的索引+1就是重复数。

```java
class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> ret = new ArrayList<>();
        int n = nums.length;
        for(int i = 0; i < n; i++){
            nums[(nums[i] - 1) % n] += n;
        }
        for(int i = 0; i < n; i++){
            if(nums[i] > 2 * n) ret.add(i+1);
        }
        return ret;
    }
}
```
