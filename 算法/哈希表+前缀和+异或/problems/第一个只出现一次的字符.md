# 第一个只出现一次的字符

## 题干
在字符串 s 中找出第一个只出现一次的字符。如果没有，返回一个单空格。

## 复杂度
HashMap法：时间 {{c1::O(n)}}，空间 {{c1::O(n)}}
数组法：时间 {{c1::O(n)}}，空间 {{c1::O(26)=O(1)}}

## 关键技巧
需要一个"稳定"的遍历顺序找到"第一个"：不能用 HashMap 遍历（无序），必须重新遍历原字符串。
字符范围有限（26字母）时，int[26] 比 HashMap 更快更省空间。

## 题解(HashMap)
统计频率后再从头遍历，找到第一个count==1的字符。

```java
public class Solution {
    public int firstUniqChar(String s) {
        Map<Character, Integer> cnt = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            cnt.put(c, cnt.getOrDefault(c, 0) + 1);
        }
        for (int i = 0; i < s.length(); i++) {
            if (cnt.get(s.charAt(i)) == 1) return i;
        }
        return -1;
    }
}
```

## 题解(数组-原地哈希)
由于只有小写字母，用int[26]更高效，字符→索引映射。

```java
class Solution {
    public char firstUniqChar(String s) {
        int[] temp = new int[26];
        char[] charss = s.toCharArray();
        for(char item:charss)
            temp[item-'a']++;
        for(char item:charss)
            if(temp[item-'a']==1)
                return item;
        return ' ';
    }
}
```
