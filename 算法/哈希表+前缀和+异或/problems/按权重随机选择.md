# 按权重随机选择

## 题干
给定一个正整数数组 w，其中 w[i] 代表第 i 个下标的权重。实现 pickIndex 函数，随机地从范围 [0, w.length - 1] 内选取一个下标，选取下标 i 的概率与 w[i] 成正比。

## 复杂度
构造：时间 {{c1::O(n)}}，空间 {{c1::O(n)}} — 前缀和数组
pickIndex：时间 {{c1::O(log n)}} — 二分查找

## 关键技巧
前缀和 + 二分查找的经典组合：
w=[1,3] → sum=[0,1,4]，区间(0,1]→0, (1,4]→1
随机数 t∈[1,4]，二分查找 sum[mid]>=t 的最左位置。
返回 right-1 是因为 sum 从索引1开始映射到w的索引0。

## 题解(前缀和+二分)
前缀和将权重转化为区间长度，随机数t落在哪个区间就选对应下标。

```java
class Solution {
    int[] sum;
    public Solution(int[] w) {
        int n = w.length;
        sum = new int[n + 1];
        for (int i = 1; i <= n; i++)
            sum[i] = sum[i - 1] + w[i - 1];
    }

    public int pickIndex() {
        int n = sum.length;
        int t = (int) (Math.random() * sum[n - 1]) + 1;
        int left = 1, right = n - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (sum[mid] >= t)
                right = mid;
            else
                left = mid + 1;
        }
        return right - 1;
    }
}
```
