# 输出与流关闭

## 三种输出方式

| 方式 | 性能 | 适用场景 |
|------|------|---------|
| `System.out.println()` | 慢（每次flush） | &lt;100行输出 |
| `StringBuilder` + `System.out.print` | 快 | 100~10000行 |
| `PrintWriter` 缓冲输出 | 最快 | &gt;10000行 |

## System.out.println（最简单，最慢）
```java
System.out.println(result);      // 带换行
System.out.print(result + " ");  // 不带换行
System.out.printf("%.2f\n", d);  // 格式化
```
缺点：{{c1::每次调用 println 都 flush，大量输出时极慢}}

## StringBuilder 批量输出（推荐日常用）
```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < n; i++) {
    sb.append(results[i]).append("\n");
}
System.out.print(sb.toString());
```
{{c2::用 \\n 而非 System.lineSeparator()，跨 OJ 平台一致}}

## PrintWriter 缓冲输出（大赛推荐）
```java
import java.io.PrintWriter;
PrintWriter pw = new PrintWriter(new OutputStreamWriter(System.out));

for (int i = 0; i < n; i++) {
    pw.println(results[i]);
}
pw.flush(); // {{c1::必须 flush！否则输出丢失}}
```

## 流关闭核心规则
1. {{c2::System.in 绝对不要 close()}} — 全局流，关了所有读取都失效
2. {{c3::System.out 绝对不要 close()}} — 同理，关了后续输出全失效
3. Scanner 包裹 System.in → close 会连带关闭 System.in → 小心
4. BufferedReader 可以 close（ACM 短程序可不关，JVM 自动回收）
5. {{c4::PrintWriter 必须 flush() → close()}}，顺序不能反

## try-with-resources 标准模板（最推荐）
```java
try (BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
     PrintWriter pw = new PrintWriter(new OutputStreamWriter(System.out))) {
    String line;
    while ((line = br.readLine()) != null) {
        int n = Integer.parseInt(line.trim());
        pw.println(solve(n));
    }
    pw.flush();
} catch (IOException e) {
    e.printStackTrace();
}
```

## 传统 finally 关闭模板
```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
PrintWriter pw = new PrintWriter(new OutputStreamWriter(System.out));
try {
    // solve...
    pw.flush();
} catch (IOException e) {
    e.printStackTrace();
} finally {
    try { if (br != null) br.close(); } catch (IOException e) { }
    if (pw != null) pw.close();
}
```

## ACM 场景选择建议
- 练习/调试 → {{c1::Scanner + System.out.println，写完就跑}}
- 正式比赛/中数据量 → {{c2::BufferedReader + StringBuilder + System.out.print}}
- 大数据量/极限性能 → {{c3::FastReader + PrintWriter，必须 flush()}}

## 常见坑
1. `pw.flush()` 忘记 → 输出截断
2. `sc.close()` 后 `System.in` 关了 → `NoSuchElementException`
3. try-with-resources 中 `pw.flush()` 写在 try 块末尾（不能在 finally）
4. 不要同时用 `System.out` 和 `PrintWriter` 输出，顺序可能乱
