# 常见输入格式模板

## 格式1：单行单个值 + 数组
**输入**：第一行 n，第二行 n 个数
```java
int n = Integer.parseInt(br.readLine());
int[] arr = new int[n];
String[] parts = br.readLine().split(" ");
for (int i = 0; i < n; i++) arr[i] = Integer.parseInt(parts[i]);
```

## 格式2：多组数据读到 EOF（最经典）
**输入**：每行两个数 a b，直到文件结束
```java
String line;
while ((line = br.readLine()) != null) {
    String[] parts = line.split(" ");
    int a = Integer.parseInt(parts[0]);
    int b = Integer.parseInt(parts[1]);
    System.out.println(a + b);
}
```
判断：{{c1::readLine() == null 即 EOF}}

## 格式3：T 组测试用例（每组固定结构）
**输入**：第一行 T，每组第一行 n，接下来 n 行
```java
int T = Integer.parseInt(br.readLine());
while (T-- > 0) {
    int n = Integer.parseInt(br.readLine());
    for (int i = 0; i < n; i++) {
        String line = br.readLine();
        // process each line
    }
}
```
关键：{{c2::每组内部行数由读到的数据决定，不需要额外标记}}

## 格式4：T 组 + 每组一行多个值
**输入**：T 组，每组一行 n 和 m，接着一行 m 个数
```java
int T = Integer.parseInt(br.readLine());
while (T-- > 0) {
    StringTokenizer st = new StringTokenizer(br.readLine());
    int n = Integer.parseInt(st.nextToken());
    int m = Integer.parseInt(st.nextToken());
    st = new StringTokenizer(br.readLine());
    int[] arr = new int[m];
    for (int i = 0; i < m; i++) arr[i] = Integer.parseInt(st.nextToken());
    // solve with n, m, arr
}
```

## 格式5：矩阵/二维数组
**输入**：第一行 n m，接下来 n 行每行 m 个数
```java
StringTokenizer st = new StringTokenizer(br.readLine());
int n = Integer.parseInt(st.nextToken());
int m = Integer.parseInt(st.nextToken());
int[][] matrix = new int[n][m];
for (int i = 0; i < n; i++) {
    st = new StringTokenizer(br.readLine());
    for (int j = 0; j < m; j++) {
        matrix[i][j] = Integer.parseInt(st.nextToken());
    }
}
```

## 格式6：图的边输入
**输入**：第一行 n m，接下来 m 行每行 u v
```java
st = new StringTokenizer(br.readLine());
int n = Integer.parseInt(st.nextToken());
int m = Integer.parseInt(st.nextToken());
List<Integer>[] graph = new ArrayList[n + 1];
for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
for (int i = 0; i < m; i++) {
    st = new StringTokenizer(br.readLine());
    int u = Integer.parseInt(st.nextToken());
    int v = Integer.parseInt(st.nextToken());
    graph[u].add(v);
    graph[v].add(u); // undirected
}
```

## 格式7：字符串数组
```java
int n = Integer.parseInt(br.readLine());
String[] strs = new String[n];
for (int i = 0; i < n; i++) {
    strs[i] = br.readLine(); // 每行一个字符串
}
```

## 格式8：数字后跟含空格字符串
**输入**：`3 hello world`（数字后跟长字符串）
```java
String[] parts = br.readLine().split(" ", 2); // limit=2 限制split次数
int n = Integer.parseInt(parts[0]);
String s = parts[1]; // "hello world"
```
{{c1::split(" ", 2) 限制最多分割成 2 部分}}

## 格式9：不定长的一行（多空格）
```java
String[] parts = br.readLine().trim().split("\\s+");
int[] arr = new int[parts.length];
for (int i = 0; i < parts.length; i++) {
    arr[i] = Integer.parseInt(parts[i]);
}
```
{{c2::split("\\\\s+") 匹配连续多个空格/tab}}

## 输入格式速查卡
| 特征 | 处理方法 |
|------|---------|
| 固定 T 组 | `int T = read(); while(T-- > 0)` |
| 读到 EOF | `while((line=readLine()) != null)` |
| 单行不定长 | `split("\\\\s+")` 或 StringTokenizer |
| 数字+长字符串 | `split(" ", 2)` 限制 split 次数 |
| 矩阵 | 双重循环 + StringTokenizer |
| 图 | 读 n,m → 循环 m 行 → 邻接表 |
| 跳过空行 | `if(line.isEmpty()) continue` |
