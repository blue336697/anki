# 跳跃游戏

## 题干
给定一个非负整数数组 nums，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。

## 复杂度
时间：{{c1::O(n)}} — 一次遍历，维护最远可达距离
空间：{{c1::O(1)}}

## 关键技巧
核心：维护最远可达距离 temp = max(temp, i + nums[i])
当 i > temp 时说明当前位置不可达，返回 false。
temp 得不到更新+出现0时自然卡住，巧妙处理了「循环0」的情况。

## 题解(贪心)
维护最远可达距离 temp，当 i > temp 时说明当前位置不可达。

```java
class Solution {
    public boolean canJump(int[] nums) {
        int i = 0, temp = 0, n = nums.length;
        while (i < n) {
            if (i > temp)
                return false;
            // 这一步可以防止有循环0的出现
            // 出现循环0，temp得不到更新，i就会大于temp返回false
            // 又能允许形如 [2,5,0,0] 的数组通过
            temp = Math.max(temp, i + nums[i++]);
        }
        return true;
    }
}
```
