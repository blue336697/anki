# 最大数

## 题干
给定一组非负整数 nums，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。
![image 4.png](image%204.png)

## 复杂度
时间：{{c1::O(n log n)}} — 排序开销
空间：{{c1::O(n)}} — 字符串数组

## 关键技巧
自定义排序：对于 a 和 b，比较 ab 和 ba 的拼接结果。
若 b+a > a+b（字典序），则 b 应该排在 a 前面（降序）。
边界：全0数组应返回"0"而非"00...0"，需要去除前导0。

## 题解(排序贪心)
自定义排序：对于 a 和 b，比较拼接结果 ba 和 ab，ba 更大则 b 排前面（降序）。

```java
public class Solution {
    public static String largestNumber(int[] nums) {
        if (nums == null || nums.length == 0)
            return "";
        int len = nums.length;
        String[] sa = new String[len];
        for (int i = 0; i < len; i++)
            sa[i] = "" + nums[i];
        // 这里就是使用贪心算法，比较两个元素组合起来的最大值
        Arrays.sort(sa, (a, b) -> {
            String ab = a + b, ba = b + a;
            return ba.compareTo(ab);
        });

        StringBuilder sb = new StringBuilder();
        for (String num : sa)
            sb.append(num);

        int length = sb.length();
        int k = 0;
        while (k < length - 1 && sb.charAt(k) == '0') k++;
        return sb.substring(k);
    }
}
```
