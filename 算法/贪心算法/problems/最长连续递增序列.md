# 最长连续递增序列

## 题干
给定一个未经排序的整数数组，找到最长且连续递增的子序列，并返回该序列的长度。

## 复杂度
DP：时间 {{c1::O(n)}}，空间 {{c1::O(n)}}
贪心：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}

## 关键技巧
贪心 vs DP：
DP：dp[i] 表示以 i 结尾的最长连续递增长度，若递增则 dp[i]=dp[i-1]+1
贪心：维护当前递增长度 curLength，不满足条件时重置为 1
贪心更简洁，空间 O(1)，因为当前状态只依赖前一个元素。

## 题解(动态规划)
dp[i] 表示以 nums[i] 结尾的最长连续递增序列的长度。若递增则 dp[i]=dp[i-1]+1。

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        int len = nums.length;
        if (len <= 0)
            return 0;
        // dp[i]是以nums[i]结尾的最长连续递增序列的长度
        int[] dp = new int[len];
        // 初始化值为1，没有连续的自身为1
        Arrays.fill(dp, 1);
        int res = 0;
        for (int i = 1; i < len; i++) {
            // 如果没有满足条件就直接跳过，该值在下一次被用到也是原始值
            // 相当于分隔了
            if (nums[i] > nums[i - 1])
                dp[i] = dp[i - 1] + 1;
            res = res > dp[i] ? res : dp[i];
        }
        return res;
    }
}
```

## 题解(贪心)
维护当前递增长度 curLength，不满足条件时重置为 1，贪心的"断点分隔"思想。

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        int curLength = 1;
        int ans = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                curLength++;
            } else {
                curLength = 1;
            }
            ans = Math.max(ans, curLength);
        }
        return ans;
    }
}
```
