# 二分查找边界模板
<!-- tags: source::字节 pattern::二分边界 -->

## 题干
给定一个按非递减顺序排列的数组 `nums` 和目标值 `target`，实现四种边界查询：

1. 第一个大于等于 `target` 的下标
2. 第一个严格大于 `target` 的下标
3. 最后一个严格小于 `target` 的下标
4. 最后一个小于等于 `target` 的下标

如果“第一个”不存在，返回 `nums.length`；如果“最后一个”不存在，返回 `-1`。这一约定使返回值可直接作为插入位置或半开区间边界。

## 两个母函数
`lowerBound(target)`：返回第一个满足 {{c1::nums[i] >= target}} 的下标。
`upperBound(target)`：返回第一个满足 {{c1::nums[i] > target}} 的下标。
最后一个 `< target`：{{c1::lowerBound(target) - 1}}。
最后一个 `<= target`：{{c1::upperBound(target) - 1}}。

只需要牢牢记住前两个“找第一个”的函数，后两个通过减一得到，能显著减少边界模板数量。

## 搜索区间与不变量
统一使用左闭右开区间 `[left,right)`，初始为 `[0,n)`：

- `right` 可以等于 n，天然表达“没有满足条件的元素”
- 循环条件是 `left < right`
- 中点 `mid` 一定处于有效下标范围 `[left,right)`
- 若 `mid` 已满足目标谓词，答案可能是 mid 或更左，令 `right = mid`
- 否则 mid 不可能是答案，令 `left = mid + 1`

循环结束时 `left == right`，该位置就是第一个使谓词为真的下标。

## lowerBound 与 upperBound 的唯一区别
两者框架完全相同，只差“什么叫满足条件”：

- lower bound 在 `nums[mid] >= target` 时收缩右边界
- upper bound 在 `nums[mid] > target` 时收缩右边界

不要混用 `right = mid - 1`；那属于闭区间 `[left,right]` 模板。

## 复杂度
时间：{{c1::O(log n)}}。
空间：{{c1::O(1)}}。

## 题解(左闭右开边界二分)
```java
class BinarySearchBounds {
    public int lowerBound(int[] nums, int target) {
        int left = 0;
        int right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    public int upperBound(int[] nums, int target) {
        int left = 0;
        int right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    public int lastLessThan(int[] nums, int target) {
        return lowerBound(nums, target) - 1;
    }

    public int lastLessOrEqual(int[] nums, int target) {
        return upperBound(nums, target) - 1;
    }
}
```

## 追问：等于 target 的区间
若 `target` 存在，其全部出现位置组成半开区间：

`[{{c1::lowerBound(target)}}, {{c1::upperBound(target)}})`

出现次数为 `upperBound(target) - lowerBound(target)`。若二者相等，说明目标值不存在。
