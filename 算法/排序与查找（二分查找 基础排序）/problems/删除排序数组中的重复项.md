# 删除排序数组中的重复项

## 题干
给你一个非严格递增排列的数组 nums，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应保持一致。不要使用额外的数组空间，必须在原地修改输入数组并在使用 O(1) 额外空间的条件下完成。

## 复杂度
双指针：时间 {{c1::O(n)}}，空间 {{c1::O(1)}}
哈希法：时间 {{c1::O(n)}}，空间 {{c1::O(n)}}

## 关键技巧
排序数组去重双指针模板：
i = 0（原地指针），j = 1（探索指针）
nums[i] != nums[j] 时，nums[++i] = nums[j]
最终长度 = i + 1
优化：可在 j-i>1 时才赋值，避免无意义覆盖（原数组本就无重复时）

## 题解(双指针)
i指向已处理的不重复数组末尾，j向前探索，遇到新元素就放到i+1位置。

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length <= 1)
            return nums.length;
        int i = 0, j = 1;
        while (j < nums.length) {
            if (nums[i] != nums[j]) {
                nums[i + 1] = nums[j];
                i++;
            }
            j++;
        }
        return i + 1;
    }
}
```
