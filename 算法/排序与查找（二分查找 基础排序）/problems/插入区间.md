# 插入区间
<!-- tags: source::字节 pattern::区间扫描 -->

## 题干
给定按起点升序排列、且彼此不重叠的闭区间数组 `intervals`，以及一个新区间 `newInterval`。把新区间插入原数组，合并所有重叠区间，返回仍按起点升序且互不重叠的结果。

区间 `[a,b]` 与 `[c,d]` 在 `c <= b` 时相交；端点相等也要合并。

## 三段扫描
因为原区间已经有序且互不重叠，扫描过程天然分为三段：

1. 当前区间终点 `< newStart`：{{c1::完全位于新区间左侧，直接加入结果}}
2. 当前区间起点 `<= newEnd`：{{c1::与新区间重叠，扩展 newStart/newEnd}}
3. 剩余区间：{{c1::完全位于合并后新区间右侧，直接加入结果}}

第二段结束后，只需把合并后的新区间加入一次。

## 边界与副作用
不要直接修改调用方传入的 `newInterval`，除非题目明确允许。用局部变量保存合并后的左右端点，可以避免输入数组被意外改写。

第一段必须使用 `end < newStart`；第二段使用 `start <= newEnd`。这两个不等号共同保证闭区间端点相等时会合并。

## 复杂度
时间：{{c1::O(n)}} — 三段循环中的下标只单调前进，每个原区间恰好处理一次。
辅助空间：{{c1::O(1)}}，不计必须返回的结果数组；结果本身占 O(n)。

## 题解(三段线性扫描)
```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> result = new ArrayList<>();
        int index = 0;
        int mergedStart = newInterval[0];
        int mergedEnd = newInterval[1];

        while (index < intervals.length && intervals[index][1] < mergedStart) {
            result.add(intervals[index]);
            index++;
        }

        while (index < intervals.length && intervals[index][0] <= mergedEnd) {
            mergedStart = Math.min(mergedStart, intervals[index][0]);
            mergedEnd = Math.max(mergedEnd, intervals[index][1]);
            index++;
        }
        result.add(new int[] {mergedStart, mergedEnd});

        while (index < intervals.length) {
            result.add(intervals[index]);
            index++;
        }
        return result.toArray(new int[0][]);
    }
}
```
