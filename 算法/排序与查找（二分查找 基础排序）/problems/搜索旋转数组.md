# 搜索旋转数组

## 题干
与「搜索旋转排序数组」不同：数组中存在重复元素。给定一个可能存在重复元素值的数组 nums，和一个目标值 target。如果 nums 中存在 target，返回索引值最小的一个，否则返回 -1。

## 复杂度
平均：时间 {{c1::O(log n)}}，空间 {{c1::O(1)}}
最坏(全重复)：时间 {{c1::O(n)}} — 无法二分，退化为线性

## 关键技巧
与无重复版本的核心区别：
1. 预处理：while(left<right && nums[left]==nums[right]) right-- 跳过首尾重复
2. 找到 target 后不直接返回，而是记录最小值并继续向左搜索
3. 最坏情况（全重复数组）退化为 O(n)

## 题解(二分+去重)
处理重复：先跳过首尾相等的元素；找到target后继续向左搜索最小索引。

```java
class Solution {
    public int search(int[] nums, int target) {
        int len = nums.length;
        int left = 0, right = len - 1;
        int res = Integer.MAX_VALUE;
        while (left <= right) {
            // 跳过首尾重复元素
            while (left < right && nums[left] == nums[right])
                right--;
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                res = Math.min(res, mid);
                right = mid - 1; // 继续向左找更小的索引
            }
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target <= nums[mid])
                    right = mid - 1;
                else
                    left = mid + 1;
            } else {
                if (nums[mid] <= target && target <= nums[right])
                    left = mid + 1;
                else
                    right = mid - 1;
            }
        }
        return res == Integer.MAX_VALUE ? -1 : res;
    }
}
```
