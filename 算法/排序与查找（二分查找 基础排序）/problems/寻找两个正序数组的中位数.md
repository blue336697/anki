# 寻找两个正序数组的中位数

## 题干
给定两个大小分别为 m 和 n 的正序数组 nums1 和 nums2。找出这两个正序数组的中位数，要求时间复杂度 O(log(m+n))。

## 复杂度
二分法：时间 {{c1::O(log(min(m,n)))}} — 在较短数组上二分
第k小法：时间 {{c1::O(log(m+n))}} — 每次排除 k/2 个元素
暴力合并：时间 {{c1::O(m+n)}}，空间 {{c1::O(m+n)}}

## 关键技巧
三种解法：
1. 第k小数法（推荐）：求第 (len+1)/2 和 (len+2)/2 小的数的平均值，每次排除 k/2 个
2. 逻辑遍历：O(m+n)，维护 left 和 right 两个变量，right 存当前值，left 存上一个值
3. 二分法（最优）：在较短数组上二分，通过公式确定另一数组的分割位置

## 题解(第k小数法)
每次排除 k/2 个元素：比较两数组第k/2位置的元素，较小的那一半之前不可能包含第k小元素。

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int m = nums2.length;
        // 将偶数和奇数情况合并：求第(left)小和第(right)小的平均值
        int left = (n + m + 1) / 2;
        int right = (n + m + 2) / 2;
        return (getKth(nums1, 0, n - 1, nums2, 0, m - 1, left)
                + getKth(nums1, 0, n - 1, nums2, 0, m - 1, right)) * 0.5;
    }

    private int getKth(int[] nums1, int start1, int end1,
                       int[] nums2, int start2, int end2, int k) {
        int len1 = end1 - start1 + 1;
        int len2 = end2 - start2 + 1;
        // 保证len1较短，简化空数组处理
        if (len1 > len2)
            return getKth(nums2, start2, end2, nums1, start1, end1, k);
        // 短数组为空，直接从长数组取
        if (len1 == 0)
            return nums2[start2 + k - 1];
        // 找第1小就是取两个数组头部的较小值
        if (k == 1)
            return Math.min(nums1[start1], nums2[start2]);
        // 每次排除 k/2 个元素
        int i = start1 + Math.min(len1, k / 2) - 1;
        int j = start2 + Math.min(len2, k / 2) - 1;
        if (nums1[i] > nums2[j])
            return getKth(nums1, start1, end1, nums2, j + 1, end2, k - (j - start2 + 1));
        else
            return getKth(nums1, i + 1, end1, nums2, start2, end2, k - (i - start1 + 1));
    }
}
```

## 题解(逻辑遍历)
逻辑上两个数组粘连，物理上分别遍历，走到第 len/2 步即得到中位数。

```java
class Solution {
    public double findMedianSortedArrays(int[] A, int[] B) {
        int m = A.length;
        int n = B.length;
        int len = m + n;
        int left = -1, right = -1;
        int aStart = 0, bStart = 0;
        for (int i = 0; i <= len / 2; i++) {
            // left保存上一个值（处理偶数长度时需要两个数取平均）
            left = right;
            if (aStart < m && (bStart >= n || A[aStart] < B[bStart]))
                right = A[aStart++];
            else
                right = B[bStart++];
        }
        if ((len & 1) == 0)
            return (left + right) / 2.0;
        else
            return right;
    }
}
```
