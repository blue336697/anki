# 在排序数组中查找元素的第一个和最后一个位置

## 题干
给定一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 target，返回 [-1, -1]。要求 O(log n) 时间复杂度。

## 复杂度
时间：{{c1::O(log n)}} — 两次二分查找
空间：{{c1::O(1)}}

## 关键技巧
二分查找范围查询规律：
变化条件                      | 返回值
>= target (nums[mid]>=target,right=mid-1) | left = 第一个 >= target 的位置
<= target (nums[mid]<=target,left=mid+1)  | right = 最后一个 <= target 的位置
技巧：找 target 的最后一个位置 = 找 target+1 的第一个位置 - 1

## 题解(二分+范围查询)
巧妙：找target+1的第一个位置-1就是target的最后一个位置。

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        if (nums.length == 0)
            return new int[]{-1, -1};
        // 找第一个 >= target 的位置
        int leftIndex = binarySearch(nums, target);
        // 找第一个 >= target+1 的位置 - 1 = 最后一个 target
        int rightIndex = binarySearch(nums, target + 1) - 1;
        if (leftIndex <= rightIndex && rightIndex < nums.length
                && target == nums[leftIndex] && target == nums[rightIndex])
            return new int[]{leftIndex, rightIndex};
        return new int[]{-1, -1};
    }

    // 二分查找：返回第一个 >= target 的位置
    public int binarySearch(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (nums[mid] >= target)
                right = mid - 1;
            else
                left = mid + 1;
        }
        return left;
    }
}
```
