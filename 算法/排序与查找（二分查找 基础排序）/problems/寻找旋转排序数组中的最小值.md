# 寻找旋转排序数组中的最小值

## 题干
已知一个长度为 n 的数组，预先按照升序排列，经由 1 到 n 次旋转后得到输入数组。数组中的元素互不相同。找出数组中的最小元素。要求 O(log n) 时间复杂度。
![image 11.png](image%2011.png)

## 复杂度
时间：{{c1::O(log n)}} — 二分查找
空间：{{c1::O(1)}}

## 关键技巧
旋转数组找最小值核心：
1. 比较 nums[mid] 与 nums[right]（不是 nums[0]！）
2. mid > right → 最小值在 mid 右侧 → left = mid + 1
3. mid <= right → 最小值在 mid 或其左侧 → right = mid
4. while(left < right) 不取等号，mid 使用地板除靠左
5. 与「搜索旋转排序数组」区分：本题用right做参考，搜索题用left做参考

## 题解(二分)
比较 nums[mid] 与 nums[right]：mid>right 时最小值必在右侧，否则在左侧含mid。

```java
class Solution {
    public int findMin(int[] nums) {
        int len = nums.length;
        if (nums == null || len == 0)
            return -5500;
        int left = 0;
        int right = nums.length - 1;
        while (left < right) {
            // 地板除，mid更靠近left
            int mid = left + (right - left) / 2;
            // 最小值在mid右侧
            if (nums[mid] > nums[right])
                left = mid + 1;
            // 最小值在mid或其左侧
            else
                right = mid;
        }
        return nums[left];
    }
}
```
