# 寻找峰值

## 题干
峰值元素是指其值严格大于左右相邻值的元素。给你一个整数数组 nums，找到峰值元素并返回其索引。数组可能包含多个峰值，返回任何一个峰值所在位置即可。假设 nums[-1] = nums[n] = -∞。要求 O(log n) 时间复杂度。

## 复杂度
时间：{{c1::O(log n)}} — 二分查找
空间：{{c1::O(1)}}

## 关键技巧
爬坡法二分核心（无需有序数组也能二分）：
1. 核心规律：若 nums[mid] > nums[mid+1]，则左侧（含mid）必有峰值
2. 若 nums[mid] < nums[mid+1]，则右侧必有峰值
3. 为什么成立：边界为负无穷，沿上升方向走一定能到达一个峰值
4. while(left < right) 不用取等号，因为保证有解且最终收敛到峰值

## 题解(二分/爬坡法)
爬坡法：比较mid和mid+1，哪边大就往哪边走，大的那侧必然存在峰值。

```java
class Solution {
    public int findPeakElement(int[] nums) {
        int len = nums.length;
        if (len == 0)
            return -1;
        int left = 0, right = len - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            // mid可能是峰值，左侧含mid一定存在峰值
            if (nums[mid] > nums[mid + 1])
                right = mid;
            // 上坡方向一定有峰值
            else
                left = mid + 1;
        }
        return right;
    }
}
```
