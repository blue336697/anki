# 数组中的逆序对

## 题干
在数组中的两个数字，如果前面一个数字大于后面的数字，则这两个数字组成一个逆序对。输入一个数组，求出这个数组中的逆序对的总数。

## 复杂度
归并法：时间 {{c1::O(n log n)}}，空间 {{c1::O(n)}}(辅助数组)
暴力法：时间 {{c1::O(n^2)}}，空间 {{c1::O(1)}}

## 关键技巧
归并排序天然适合统计逆序对：
在 merge 过程中，当右侧元素 nums[j] 小于左侧元素 nums[i] 时，
左侧从 i 到 mid 共 (mid - i + 1) 个元素都大于 nums[j]，直接累加到计数器。
原理：左右子数组已分别有序，一旦 nums[i] > nums[j]，则左子数组剩余部分全部 > nums[j]。

## 题解(归并排序)
归并时每当右半部分元素被选中，左半部分从i到mid的所有元素都大于它，形成 mid-i+1 个逆序对。

```java
class Solution {
    int res = 0;

    public int reversePairs(int[] nums) {
        this.res = 0;
        sortArray(nums);
        return res;
    }

    public int[] sortArray(int[] nums) {
        if (nums == null || nums.length == 0)
            return nums;
        int len = nums.length;
        // 迭代归并：步长从1翻倍
        for (int i = 1; i < len; i *= 2)
            mergePass(nums, i, len);
        return nums;
    }

    // 一趟归并
    public void mergePass(int[] nums, int length, int len) {
        int i;
        for (i = 0; i + 2 * length - 1 < len; i = i + 2 * length)
            merge(nums, i, i + length - 1, i + 2 * length - 1);
        // 处理剩余子表
        if (i + length - 1 < len - 1)
            merge(nums, i, i + length - 1, len - 1);
    }

    // 归并两个有序子数组
    public void merge(int[] nums, int low, int mid, int high) {
        int[] temp = new int[high - low + 1];
        int i = low, j = mid + 1, k = 0;
        while (i <= mid && j <= high) {
            if (nums[i] <= nums[j]) {
                temp[k++] = nums[i++];
            } else {
                // 关键：右侧元素更小时统计逆序对
                res += mid - i + 1;
                temp[k++] = nums[j++];
            }
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= high) temp[k++] = nums[j++];
        // 复制回原数组
        for (k = 0, i = low; i <= high; k++, i++)
            nums[i] = temp[k];
    }
}
```
