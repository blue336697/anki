# 删除被覆盖区间
<!-- tags: source::字节 pattern::区间排序 -->

## 题干
给定一组闭区间。若区间 `[a,b]` 存在另一个区间 `[c,d]`，满足 `c <= a` 且 `b <= d`，则前者被后者覆盖。删除所有被覆盖区间，返回剩余区间数量。

## 排序规则
区间按以下顺序排列：

1. 起点升序
2. 起点相同时，终点{{c1::降序}}

同起点时必须让长区间在前。例如 `[1,4]` 必须排在 `[1,2]` 前面，后者才能被已经维护的最远右端点识别为覆盖。

## 扫描不变量
`maxEnd` 表示已扫描区间中最大的右端点。

- 若当前 `end <= maxEnd`，前面必然存在起点不大于当前起点、终点不小于当前终点的区间，当前区间被覆盖
- 若当前 `end > maxEnd`，当前区间未被覆盖，剩余数量加一并更新 `maxEnd`

初始化使用 `Integer.MIN_VALUE`，从而兼容负数端点。

## 复杂度
时间：{{c1::O(n log n)}} — 排序 O(n log n)，单次扫描 O(n)。
辅助空间：{{c1::O(log n)}} — Java 对对象数组排序通常需要排序栈/临时空间；算法扫描状态本身为 O(1)。

## 题解(排序+最远右端点)
```java
import java.util.Arrays;

class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
        Arrays.sort(intervals, (first, second) -> {
            int startOrder = Integer.compare(first[0], second[0]);
            if (startOrder != 0) {
                return startOrder;
            }
            return Integer.compare(second[1], first[1]);
        });

        int remaining = 0;
        int maxEnd = Integer.MIN_VALUE;
        for (int[] interval : intervals) {
            if (interval[1] > maxEnd) {
                remaining++;
                maxEnd = interval[1];
            }
        }
        return remaining;
    }
}
```
