# 搜索旋转排序数组

## 题干
整数数组 nums 按升序排列，在预先未知的某个下标 k 上进行了旋转。例如 [0,1,2,4,5,6,7] 在下标 3 处旋转后变为 [4,5,6,7,0,1,2]。给你旋转后的数组 nums 和一个整数 target，如果 nums 中存在 target 则返回索引，否则返回 -1。要求 O(log n) 时间复杂度。

## 复杂度
时间：{{c1::O(log n)}} — 二分查找
空间：{{c1::O(1)}}

## 关键技巧
旋转排序数组二分核心：
1. 比较 nums[left] 和 nums[mid] 确定当前区间的哪一半有序
2. 判断 target 是否在有序的那一半范围内
3. 若在有序范围内则收缩到有序侧，否则收缩到另一侧
边界条件：`nums[left] <= nums[mid]` 用 `<=` 处理只剩一个元素或 `mid == left` 的情况。

该结论依赖数组元素互不相同；存在重复元素时，`nums[left] == nums[mid]` 不能证明左半段整体有序。

## 题解(二分)
核心：判断左半还是右半有序，然后判断target落在哪个区间。

```java
class Solution {
    public int search(int[] nums, int target) {
        int len = nums.length;
        int left = 0, right = len - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target)
                return mid;
            // 左半部分是有序的
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid])
                    right = mid - 1;
                else
                    left = mid + 1;
            } else {
                // 右半部分是有序的
                if (nums[mid] < target && target <= nums[right])
                    left = mid + 1;
                else
                    right = mid - 1;
            }
        }
        return -1;
    }
}
```
