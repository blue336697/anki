# 合并区间

## 题干
以数组 intervals 表示若干个区间的集合，其中 intervals[i] = [start_i, end_i]。合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

## 复杂度
时间：{{c1::O(n log n)}} — 排序开销
空间：{{c1::O(n)}} — 结果列表

## 关键技巧
区间合并模板：
1. 按 start 升序排序
2. 遍历每个区间：若不重叠(last.end < cur.start)则直接加入；否则更新 last.end = max(last.end, cur.end)
3. 转数组：res.toArray(new int[0][])

## 题解(排序+合并)
按左端点排序后，依次判断新区间是否与已合并区间的最后一个重叠。

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0)
            return new int[0][2];
        // 按左端点升序排序
        Arrays.sort(intervals, (n1, n2) -> n1[0] - n2[0]);
        List<int[]> res = new ArrayList<>();
        for (int[] interval : intervals) {
            // 不重叠，直接添加
            if (res.size() == 0 || res.get(res.size() - 1)[1] < interval[0])
                res.add(interval);
            else
                // 重叠，合并：更新last.end = max(last.end, cur.end)
                res.get(res.size() - 1)[1] = Math.max(res.get(res.size() - 1)[1], interval[1]);
        }
        return res.toArray(new int[0][]);
    }
}
```
