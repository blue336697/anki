# 爱吃香蕉的最小速度
<!-- tags: source::字节 pattern::二分答案 -->

## 题干
给定每堆香蕉的数量 `piles` 和总小时数 `h`。每小时选择一堆，以速度 `k` 吃香蕉；若该堆不足 k 根，就吃完该堆并结束这一小时。求能在 h 小时内吃完全部香蕉的最小正整数速度 k。

题目通常保证 `piles.length <= h`，因此一定存在答案。

## 为什么二分答案
搜索对象不是数组下标，而是答案速度 `k`。速度范围为 `[1,max(piles)]`。

定义谓词 `canFinish(k)`：

- k 越大，吃完每堆所需小时数不会增加
- 若速度 k 可行，则所有 `k' > k` 都可行
- 若速度 k 不可行，则所有 `k' < k` 都不可行

可行性序列形如 `false ... false, true ... true`，目标是找到{{c1::第一个为 true 的速度}}，即 lower bound。

## 判定函数
以速度 k 吃完数量为 p 的一堆，需要：

`ceil(p / k) = {{c1::(p + k - 1) / k}}`

Java 中先把 p 转为 `long` 再加 `k - 1`，避免 `int` 加法溢出。累计小时数一旦超过 h 就可提前返回 false。

## 二分不变量
使用闭区间候选值并保留已知可行的右边界：

- `left`：仍可能是答案的最小速度
- `right`：仍可能是答案的最大速度，初始 `max(piles)` 一定可行
- `mid` 可行时令 `right = mid`
- `mid` 不可行时令 `left = mid + 1`

循环在 `left == right` 时结束，该值就是最小可行速度。

## 复杂度
设 n 为堆数，M 为最大堆大小。
时间：{{c1::O(n log M)}}。
空间：{{c1::O(1)}}。

## 题解(二分答案)
```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int left = 1;
        int right = 0;
        for (int pile : piles) {
            right = Math.max(right, pile);
        }

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canFinish(piles, h, mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean canFinish(int[] piles, int h, int speed) {
        long hours = 0L;
        for (int pile : piles) {
            hours += ((long) pile + speed - 1) / speed;
            if (hours > h) {
                return false;
            }
        }
        return true;
    }
}
```
