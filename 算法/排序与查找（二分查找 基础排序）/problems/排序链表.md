# 排序链表

## 题干
给你链表的头节点 head，将其按升序排列并返回排序后的链表。要求 O(n log n) 时间复杂度和 O(1) 空间复杂度。

## 复杂度
迭代归并：时间 {{c1::O(n log n)}}，空间 {{c1::O(1)}}
递归归并：时间 {{c1::O(n log n)}}，空间 {{c1::O(log n)}}(递归栈)

## 关键技巧
归并排序链表的两种实现：
1. 递归：快慢指针找中点（fast从head.next开始），断开，递归排序左右，合并
2. 迭代：步长intv从1翻倍到len，每轮截取两个长度为intv的段合并
关键细节：迭代法中pre.next=h不能丢，否则余下链表会丢失

## 题解(递归归并)
快慢指针找中点（fast从head.next开始保证偶长时中点在左侧），递归断开并排序，最后合并。

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null)
            return head;
        // 快慢指针找中点，fast从head.next开始保证偶数长度时中点在左侧
        ListNode fast = head.next, slow = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // 断开链表
        ListNode tmp = slow.next;
        slow.next = null;
        // 递归排序左右
        ListNode left = sortList(head);
        ListNode right = sortList(tmp);
        // 合并两个有序链表
        ListNode h = new ListNode(0);
        ListNode res = h;
        while (left != null && right != null) {
            if (left.val < right.val) {
                h.next = left;
                left = left.next;
            } else {
                h.next = right;
                right = right.next;
            }
            h = h.next;
        }
        // 链接剩余部分
        h.next = left != null ? left : right;
        return res.next;
    }
}
```

## 题解(迭代归并)
自底向上：步长从1开始翻倍，每轮截取两个长度为intv的段进行合并。

```java
class Solution {
    public ListNode sortList(ListNode head) {
        int intv = 1; // 归并步长
        int len = 0;
        ListNode h1, h2, pre, res;
        res = new ListNode(0);
        res.next = head;
        // 获取链表长度
        ListNode h = head;
        while (h != null) {
            h = h.next;
            len++;
        }
        // 自底向上归并排序
        while (intv < len) {
            pre = res;
            h = res.next;
            while (h != null) {
                int i = intv;
                h1 = h;
                // 截取h1段（长度为intv）
                while (i > 0 && h != null) {
                    i--;
                    h = h.next;
                }
                if (i > 0) break; // 只有h1没有h2了
                // 截取h2段
                i = intv;
                h2 = h;
                while (i > 0 && h != null) {
                    h = h.next;
                    i--;
                }
                int c1 = intv, c2 = intv - i;
                // 合并h1和h2
                while (c1 > 0 && c2 > 0) {
                    if (h1.val < h2.val) {
                        pre.next = h1;
                        h1 = h1.next;
                        c1--;
                    } else {
                        pre.next = h2;
                        h2 = h2.next;
                        c2--;
                    }
                    pre = pre.next;
                }
                // 链接剩余段
                pre.next = c1 == 0 ? h2 : h1;
                while (c1 > 0 || c2 > 0) {
                    pre = pre.next;
                    c1--;
                    c2--;
                }
                // 链接余下链表，防止丢失
                pre.next = h;
            }
            intv *= 2;
        }
        return res.next;
    }
}
```
