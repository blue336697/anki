# 经典例题：交替打印 1-100（四种解法）

## 题目
{{c1::两个线程交替打印 1-100}}，线程A打印奇数，线程B打印偶数。

## 解法1：synchronized + wait/notify
```java
class Solution1 {
    private static final Object lock = new Object();
    private static int num = 1;

    public static void main(String[] args) {
        new Thread(() -> {
            synchronized (lock) {
                while (num <= 100) {
                    if ((num & 1) == 0) { lock.wait(); continue; }
                    System.out.println("奇数: " + num++);
                    lock.notify();
                }
            }
        }).start();

        new Thread(() -> {
            synchronized (lock) {
                while (num <= 100) {
                    if ((num & 1) == 1) { lock.wait(); continue; }
                    System.out.println("偶数: " + num++);
                    lock.notify();
                }
            }
        }).start();
    }
}
```
关键：{{c2::wait() 在 while 中自旋}}，防止虚假唤醒；{{c2::print 完 notify 对方}}。

## 解法2：Lock + Condition
```java
class Solution2 {
    private static final Lock lock = new ReentrantLock();
    private static final Condition cond = lock.newCondition();
    private static int num = 1;

    public static void main(String[] args) {
        new Thread(() -> print(true)).start();
        new Thread(() -> print(false)).start();
    }

    static void print(boolean isOdd) {
        lock.lock();
        try {
            while (num <= 100) {
                if ((num & 1) == 1 != isOdd) { cond.await(); continue; }
                if (num > 100) break;
                System.out.println(Thread.currentThread().getName() + ": " + num++);
                cond.signal();
            }
        } finally { lock.unlock(); }
    }
}
```

## 解法3：LockSupport.park/unpark（最轻量）
```java
class Solution3 {
    static Thread t1, t2;
    static int num = 1;

    public static void main(String[] args) {
        t1 = new Thread(() -> {
            while (num <= 100) {
                if ((num & 1) == 0) { LockSupport.park(); continue; }
                System.out.println("奇数: " + num++);
                LockSupport.unpark(t2);
            }
        });
        t2 = new Thread(() -> {
            while (num <= 100) {
                if ((num & 1) == 1) { LockSupport.park(); continue; }
                System.out.println("偶数: " + num++);
                LockSupport.unpark(t1);
            }
        });
        t1.start(); t2.start();
    }
}
```

## 解法4：Semaphore（最简洁）
```java
class Solution4 {
    public static void main(String[] args) {
        Semaphore s1 = new Semaphore(1);
        Semaphore s2 = new Semaphore(0);

        new Thread(() -> print(s1, s2, 1, "奇数")).start();
        new Thread(() -> print(s2, s1, 2, "偶数")).start();
    }

    static void print(Semaphore cur, Semaphore next, int start, String name) {
        for (int i = start; i <= 100; i += 2) {
            cur.acquireUninterruptibly();
            System.out.println(name + ": " + i);
            next.release();
        }
    }
}
```
{{c3::Semaphore(0) 初始许可为 0 → acquire 立即阻塞}}，等对方 release 才通过。

## 解法选型
| 解法 | 适合场景 |
|------|------|
| wait/notify | {{c1::面试第一问，必须会}} |
| Lock/Condition | {{c2::需要多条件队列时}} |
| LockSupport | {{c3::最轻量，无需锁对象}} |
| Semaphore | {{c4::代码最短，直观易懂}} |
