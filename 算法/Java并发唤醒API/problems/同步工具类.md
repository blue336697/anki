# Semaphore / CountDownLatch / CyclicBarrier / BlockingQueue

## Semaphore（信号量）
控制 {{c1::同时访问资源的线程数}}。acquire() 获取许可，release() 归还。

```java
Semaphore sem = new Semaphore(1); // 1→互斥锁
sem.acquire();  // 获取许可，无许可则阻塞
// critical section
sem.release();  // 归还许可
```

交替打印关键思想：{{c2::Semaphore(0) → acquire 阻塞，等对方 release}}

## CountDownLatch（倒计时门闩）
一个线程等待 {{c3::N 个事件完成}}。**一次性的，不可重置**。

```java
CountDownLatch latch = new CountDownLatch(3);
// 3个worker完成后各自 countDown()
latch.await(); // 等计数归零
```

典型场景：{{c4::主线程等所有子线程就绪再开始}}。

## CyclicBarrier（循环栅栏）
N 个线程 {{c5::互相等待}}，都到齐后一起出发。**可重复使用**。

```java
CyclicBarrier barrier = new CyclicBarrier(3, () ->
    System.out.println("全部到齐，出发！"));
barrier.await(); // 等其他人，都到了才继续
```

vs CountDownLatch：
- CyclicBarrier：{{c6::多方互相等}} + {{c6::可复用}}
- CountDownLatch：{{c6::一方等多方}} + {{c6::一次性}}

## BlockingQueue（阻塞队列）
生产者-消费者模式的最简方案。

```java
BlockingQueue<String> queue = new LinkedBlockingQueue<>(10);
queue.put(item);   // 满则阻塞
String item = queue.take(); // 空则阻塞
```

SynchronousQueue 妙用：{{c7::容量为 0，put 必须等 take，天然线程间直接传递}}

交替打印：
```java
SynchronousQueue<Integer> q1 = new SynchronousQueue<>();
SynchronousQueue<Integer> q2 = new SynchronousQueue<>();
// 奇数: q1.put(num); q2.take(); → 放一个，等偶数确认
// 偶数: q1.take(); q2.put(1);  → 取一个，通知奇数
```

## 工具类选型速查
| 需求 | 工具 |
|------|------|
| 限流/控制并发数 | {{c1::Semaphore}} |
| 主线程等N个子线程完成 | {{c1::CountDownLatch}} |
| N个线程互相等待同时出发 | {{c1::CyclicBarrier}} |
| 生产者-消费者 | {{c1::BlockingQueue}} |
| 线程间精确唤醒 | {{c1::LockSupport.unpark(t)}} |
| 一个资源多条件等待 | {{c1::Lock + 多个 Condition}} |
