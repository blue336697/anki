# 验证回文串

## 题干
给定一个字符串，验证它是否是回文串，只考虑字母和数字字符，可以忽略字母的大小写。

## 复杂度
时间：{{c1::O(n)}} — 双指针一次遍历
空间：{{c1::O(1)}}

## 关键技巧
双指针+跳过非字母数字字符。
字符大小写统一：& 0xDF（小写转大写）或 Character.toLowerCase()。
基础模板：isPalindrome(s, start, end) — 双指针从两端向中间比较。

## 题解(双指针+过滤)
双指针跳过非字母数字字符，& 0xDF 将小写转大写统一比较。

```java
class Solution {
    public boolean isPalindrome(String s) {
        char[] ss = s.toCharArray();
        int len = ss.length, i = 0, j = len - 1;
        while (i < j) {
            while (i < j && !Character.isLetterOrDigit(ss[i]))
                ++i;
            while (i < j && !Character.isLetterOrDigit(ss[j]))
                --j;
            if ((ss[i++] & 0xDF) != (ss[j--] & 0xDF))
                return false;
        }
        return true;
    }
}
```
