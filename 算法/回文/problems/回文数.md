# 回文数

## 题干
判断一个整数是否是回文数。回文数是指正序和倒序读都是一样的整数。

![image 3.png](image%203.png)

## 复杂度
全反转法：时间 {{c1::O(log n)}}，空间 {{c1::O(1)}}
半反转法：时间 {{c1::O(log n)}}，空间 {{c1::O(1)}}

## 关键技巧
半反转法：只反转数字的后半部分，与前半部分比较。
退出条件 x <= revertedNumber 表示已经处理了一半以上。
特殊情况：负数不是回文；末位为0的非零数不是回文。

## 题解(全反转)
将整数完全反转后与原数比较，注意处理溢出和不合法输入。

```java
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0 || x > Integer.MAX_VALUE)
            return false;
        int i = 0, j = 0;
        int temp = x;
        while (temp != 0) {
            i = temp % 10;
            j = j * 10 + i;
            temp /= 10;
        }
        return j == x;
    }
}
```

## 题解(半反转)
只反转数字的后半部分，与前半部分比较。偶数位完全相等，奇数位去掉中间位。

```java
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0 || (x % 10 == 0 && x != 0))
            return false;
        int revertedNumber = 0;
        while (x > revertedNumber) {
            revertedNumber = revertedNumber * 10 + x % 10;
            x /= 10;
        }
        return revertedNumber == x || revertedNumber / 10 == x;
    }
}
```
