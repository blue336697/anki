# 回文子串

## 题干
给定一个字符串 s，计算这个字符串中有多少个回文子串。具有不同开始位置或结束位置的子串，即使是由相同的字符组成，也会被视作不同的子串。
![image.png](image.png)

## 复杂度
DP：时间 {{c1::O(n²)}}，空间 {{c1::O(n²)}}
中心扩散：时间 {{c1::O(n²)}}，空间 {{c1::O(1)}}

## 关键技巧
回文子串问题的三种解法可互相迁移：
1. DP：适合求个数/最长，dp[i][j] 依赖 dp[i+1][j-1]，注意遍历顺序 j 外层 i 内层
2. 中心扩散：center 公式统一奇偶，空间最优 O(1)
3. 马拉车(Manacher)：O(n)，面试较少要求

## 题解(DP)
dp[i][j] 表示 s[i..j] 是否为回文串。转移：s[i]==s[j] && (j-i<2 || dp[i+1][j-1])。

```java
class Solution {
    public int countSubstrings(String s) {
        int len = s.length();
        boolean[][] dp = new boolean[len][len];
        int ans = 0;

        for (int j = 0; j < len; j++) {
            for (int i = 0; i <= j; i++) {
                if (s.charAt(i) == s.charAt(j) && (j - i < 2 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

## 题解(中心扩散)
center 从 0 到 2*len-1 统一奇偶，left=center/2, right=left+center%2 向两侧扩展。

```java
class Solution {
    public int countSubstrings(String s) {
        int res = 0, len = s.length();
        for (int center = 0; center < len * 2 - 1; center++) {
            int left = center / 2;
            int right = left + center % 2;
            while (left >= 0 && right < len && s.charAt(left) == s.charAt(right)) {
                res++;
                left--;
                right++;
            }
        }
        return res;
    }
}
```
