# 最长回文子序列

## 题干
给定一个字符串 s，找出其中最长的回文子序列的长度。子序列不要求连续。

## 复杂度
LCS 法：时间 {{c1::O(n²)}}，空间 {{c1::O(n²)}}
区间DP：时间 {{c1::O(n²)}}，空间 {{c1::O(n²)}}
核心区别：子序列不连续，dp[i][j] 不要求 s[i]==s[j]

## 关键技巧
方法1：s 与 reverse(s) 求 LCS（最长公共子序列），巧妙利用回文对称性。
方法2：区间 DP，dp[i][j] 定义为 s[i..j] 的最长回文子序列长度。
与最长回文子串区别：子序列不要求连续，不等时可以跳过一侧继续。

## 题解(LCS 法)
将 s 与 reverse(s) 求最长公共子序列。巧妙利用回文对称性：正着反着读一样。

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int len = s.length();
        if (len == 0)
            return 0;
        if (len == 1)
            return 1;

        int[][] dp = new int[len + 1][len + 1];
        String s2 = reverse(s);
        for (int i = 1; i <= len; i++) {
            for (int j = 1; j <= len; j++) {
                if (s.charAt(i - 1) == s2.charAt(j - 1))
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                else
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[len][len];
    }

    public String reverse(String s) {
        char[] chars = s.toCharArray();
        int i = 0, j = chars.length - 1;
        while (i < j) {
            char temp = chars[i];
            chars[i] = chars[j];
            chars[j] = temp;
            i++;
            j--;
        }
        return new String(chars);
    }
}
```

## 题解(区间DP)
dp[i][j] 定义为 s[i..j] 的最长回文子序列长度。s[i]==s[j] 时 +2，不等时取左右较大者。

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int len = s.length();
        int[][] dp = new int[len][len];
        for (int i = 0; i < len; i++) {
            dp[i][i] = 1;
        }
        for (int i = len - 1; i >= 0; i--) {
            for (int j = i + 1; j < len; j++) {
                if (s.charAt(i) == s.charAt(j))
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                else
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
        return dp[0][len - 1];
    }
}
```
