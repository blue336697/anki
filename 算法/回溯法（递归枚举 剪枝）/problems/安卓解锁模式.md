# 安卓解锁模式

## 题干
安卓 3×3 解锁屏使用数字 1～9 表示九个点。给定模式的最小长度 `m` 和最大长度 `n`，求长度位于 `[m,n]` 的合法解锁模式数量。

每个点最多使用一次。如果从点 `a` 到点 `b` 的线段经过第三个点 `x`，那么 `x` 必须已经在当前路径中被访问过。例如：

- 1 → 3 必须先访问 2
- 1 → 9、3 → 7、4 → 6、2 → 8 必须先访问 5
- 1 → 6 不经过另一个网格点，因此不需要中间点

## 状态与约束
`visited[x]` 表示{{c1::点 x 是否已经出现在当前路径中}}。
`skip[a][b] = x` 表示{{c1::从 a 直达 b 必须先访问中间点 x}}；值为 0 表示没有强制中间点。
从 `cur` 到 `next` 合法，当且仅当 `next` 未访问，并且{{c1::skip[cur][next] == 0 或 visited[skip[cur][next]] 为 true}}。

## 中间点表
需要记录的无向跨点关系只有：

- `1 ↔ 3` 经过 2，`1 ↔ 7` 经过 4，`3 ↔ 9` 经过 6，`7 ↔ 9` 经过 8
- `1 ↔ 9`、`3 ↔ 7`、`4 ↔ 6`、`2 ↔ 8` 都经过 5

其余点对要么相邻，要么线段不穿过另一个网格点，所以 `skip` 保持 0。

## 对称性剪枝
九个起点可以分成三个对称类：

- 四个角 `1/3/7/9` 的答案相同，只搜索 1，再乘 {{c1::4}}
- 四条边的中点 `2/4/6/8` 的答案相同，只搜索 2，再乘 {{c1::4}}
- 中心点 5 单独搜索

对称性只减少首层的重复搜索，不改变后续合法性判断。

## 复杂度
长度为 `L` 时，不考虑跨点约束最多枚举 `P(9,L)` 条路径。
时间上界：{{c1::O(Σ(L=m..n) P(9,L))}}，当 `n=9` 时可粗略写为 O(9!)。
空间：{{c1::O(9)}} 的递归栈和访问数组；`skip[10][10]` 为固定大小，因此渐进空间 O(1)。

## 题解(回溯+对称性)
`dfs(cur, remain)` 表示已经选择当前点 `cur`，还需要再选择 `remain` 个点时的合法路径数。进入本层时标记 `cur`，枚举下一点，返回前撤销标记。

```java
class Solution {
    private final int[][] skip = new int[10][10];
    private final boolean[] visited = new boolean[10];

    public int numberOfPatterns(int m, int n) {
        connect(1, 3, 2);
        connect(1, 7, 4);
        connect(3, 9, 6);
        connect(7, 9, 8);
        connect(1, 9, 5);
        connect(3, 7, 5);
        connect(4, 6, 5);
        connect(2, 8, 5);

        int answer = 0;
        for (int length = m; length <= n; length++) {
            answer += dfs(1, length - 1) * 4;
            answer += dfs(2, length - 1) * 4;
            answer += dfs(5, length - 1);
        }
        return answer;
    }

    private void connect(int a, int b, int middle) {
        skip[a][b] = middle;
        skip[b][a] = middle;
    }

    private int dfs(int current, int remain) {
        if (remain == 0) {
            return 1;
        }

        visited[current] = true;
        int count = 0;
        for (int next = 1; next <= 9; next++) {
            int middle = skip[current][next];
            if (!visited[next] && (middle == 0 || visited[middle])) {
                count += dfs(next, remain - 1);
            }
        }
        visited[current] = false;
        return count;
    }
}
```
