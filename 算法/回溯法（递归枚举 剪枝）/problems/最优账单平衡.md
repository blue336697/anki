# 最优账单平衡

## 题干
给定交易数组 `transactions[i] = [from, to, amount]`，表示 `from` 向 `to` 支付 `amount`。允许重新安排结算转账，求使所有人的净余额归零所需的最少转账次数。

问题只关心每个人最终应收或应付多少，不要求保留原交易的边。

## 净额压缩
对交易 `[from,to,amount]`：

- `balance[from] -= amount`，负数表示{{c1::净应付}}
- `balance[to] += amount`，正数表示{{c1::净应收}}

处理全部交易后，余额为 0 的人已经结清，可以删除。原图可能有很多交易边，但搜索状态只需保留 m 个非零净余额。

## 回溯状态
跳过已经归零的位置，固定第一个非零余额 `current`，只尝试与后面{{c1::符号相反}}的余额结算。

若选择位置 i，就把 `current` 整体并入 `debt[i]`，相当于用一次转账结清当前位置；然后递归处理下一个非零位置，回溯时恢复 `debt[i]`。

## 剪枝
同值去重：{{c1::同一层中，多个相同的候选余额产生等价后续状态，只尝试一次}}。
精确抵消：如果 `current + debt[i] == 0`，该选择用一次转账同时结清两人，是本层最理想匹配；其分支返回后可以停止尝试其他候选。
异号判断应比较正负，不要用两个 `int` 相乘判断，否则金额较大时可能溢出。

## 复杂度
设净额压缩后有 m 个非零余额。
时间：最坏 {{c1::O(m!)}}，剪枝通常会显著减少分支。
辅助空间：{{c1::O(m)}} — 净余额数组和递归栈，不计哈希表输入压缩。

## 题解(净额压缩+回溯)
使用 `long` 保存余额，避免多笔金额累计时溢出。

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public int minTransfers(int[][] transactions) {
        Map<Integer, Long> balance = new HashMap<>();
        for (int[] transaction : transactions) {
            int from = transaction[0];
            int to = transaction[1];
            long amount = transaction[2];
            balance.merge(from, -amount, Long::sum);
            balance.merge(to, amount, Long::sum);
        }

        List<Long> debt = new ArrayList<>();
        for (long value : balance.values()) {
            if (value != 0L) {
                debt.add(value);
            }
        }
        return dfs(debt, 0);
    }

    private int dfs(List<Long> debt, int start) {
        while (start < debt.size() && debt.get(start) == 0L) {
            start++;
        }
        if (start == debt.size()) {
            return 0;
        }

        long current = debt.get(start);
        int minimum = Integer.MAX_VALUE;
        Set<Long> tried = new HashSet<>();

        for (int i = start + 1; i < debt.size(); i++) {
            long candidate = debt.get(i);
            if ((current < 0) == (candidate < 0) || !tried.add(candidate)) {
                continue;
            }

            debt.set(i, candidate + current);
            minimum = Math.min(minimum, 1 + dfs(debt, start + 1));
            debt.set(i, candidate);

            if (candidate + current == 0L) {
                break;
            }
        }
        return minimum;
    }
}
```
