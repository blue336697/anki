# 全排列

## 题干
给定一个不含重复数字的数组 nums，返回其所有可能的全排列。
![image.png](image.png)

## 回溯-选择列表
选择列表 = {{c1::nums}}
通过 {{c1::list.contains(num)}} 判断当前元素是否已选，避免同一树枝重复使用

## 回溯-终止+剪枝
终止条件：{{c1::list.size() == nums.length}}
剪枝策略：{{c1::跳过 list 中已包含的元素}}（无重复元素，无需排序去重）

## 复杂度
时间：{{c1::O(n!)}} — n的全排列数
空间：{{c1::O(n)}} — 递归深度

## 关键技巧
排列问题不设begin索引，每层从0开始遍历全部元素。
list.contains(num) 防同枝重复：因为不含重复数字，只需判断是否已选。
回溯时 list.remove(list.size()-1) 恢复状态。

## 题解(回溯)
排列：不设begin，每次从0开始选，靠list.contains去重。

```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        if (nums.length == 1) {
            res.add(new ArrayList<Integer>(Arrays.asList(nums[0])));
            return res;
        }
        List<Integer> list = new ArrayList<>();
        backtrack(res, list, nums);
        return res;
    }

    public void backtrack(List<List<Integer>> res, List<Integer> list, int[] nums) {
        if (list.size() == nums.length) {
            res.add(new ArrayList<>(list));
            return;
        }
        for (int num : nums) {
            if (!list.contains(num)) {
                list.add(num);
                backtrack(res, list, nums);
                list.remove(list.size() - 1);
            }
        }
    }
}
```
