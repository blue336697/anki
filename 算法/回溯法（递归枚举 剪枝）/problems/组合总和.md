# 组合总和

## 题干
给定一个无重复元素的数组 candidates 和一个目标数 target，找出 candidates 中所有可以使数字和为 target 的组合。candidates 中的数字可以无限制重复被选取。
![image 5.png](image%205.png)

## 回溯-选择列表
选择列表 = {{c1::candidates[i..n-1]}}（从 begin 开始）
关键：{{c1::同数字可无限重复使用}} → 递归时传 i（不是 i+1）

## 回溯-终止+剪枝
终止条件：{{c1::target == 0}} → 加入结果
剪枝1：{{c1::target < nums[i]}} → break（排序后，后面更大直接跳出）
剪枝2：{{c1::排序}}保证剪枝1生效，从begin开始防止重复组合

## 复杂度
时间：{{c1::O(n^(target/min))}} — 上界
空间：{{c1::O(target/min)}} — 递归深度

## 题解(DFS)
可重复选取同一数字 → 递归传 i；不可重复 → 传 i+1。排序后用 target < nums[i] 剪枝。

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    Deque<Integer> list = new LinkedList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        dfs(candidates, 0, target, list);
        return res;
    }

    public void dfs(int[] nums, int begin, int target, Deque<Integer> list) {
        if (target == 0) {
            res.add(new ArrayList<>(list));
            return;
        }
        for (int i = begin; i < nums.length; i++) {
            if (target < nums[i])
                break;
            list.addLast(nums[i]);
            dfs(nums, i, target - nums[i], list);
            list.removeLast();
        }
    }
}
```

## 对比
与组合总和 II 区别：I 可无限重复用同一个数字(传i)，II 每个数字只能用一次(传i+1+排序去重)。
与零钱兑换区别：零钱兑换是DP求最少硬币数，本题是回溯求所有组合。
