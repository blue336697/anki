# 字典序排数

## 题干
给定一个整数 n，按字典序返回范围 [1, n] 内的所有整数。
![image 6.png](image%206.png)

## 回溯-选择列表
选择列表 = {{c1::cur*10+0 ~ cur*10+9}}（在 cur 后面拼 0~9）
起始值：{{c1::1~9}} 分别作为首位开始 DFS

## 回溯-终止+剪枝
终止条件：{{c1::cur > n}} → 直接return
剪枝策略：{{c1::cur > limit}} 时剪掉该分支
本质是十叉树的DFS遍历

## 复杂度
时间：{{c1::O(n)}} — 每个数字访问一次
空间：{{c1::O(log10 n)}} — 递归深度

## 题解(DFS递归)
字典序本质是十叉树的先序遍历。1~9作为根，每个节点后排0~9作为子节点。

```java
class Solution {
    List<Integer> list = new ArrayList<>();
    public List<Integer> lexicalOrder(int n) {
        for (int i = 1; i <= 9; i++) {
            dfs(i, n);
        }
        return list;
    }

    public void dfs(int cur, int limit) {
        if (cur > limit)
            return;
        list.add(cur);
        for (int i = 0; i <= 9; i++)
            dfs(cur * 10 + i, limit);
    }
}
```

## 对比
与普通回溯不同：不是选/不选问题，而是树的先序遍历。
迭代解法更省空间：j*10、j%10==9回退、j++。
