# 括号生成

## 题干
数字 n 代表生成括号的对数，设计一个函数生成所有可能的并且有效的括号组合。
![image 4.png](image%204.png)

## 回溯-选择列表
选择列表：{{c1::左括号}}（剩余left>0时）和 {{c1::右括号}}（剩余right>0时）
变量含义：left=剩余可用左括号数，right=剩余可用右括号数

## 回溯-终止+剪枝
终止条件：{{c1::left==0 && right==0}} → 加入结果
剪枝策略：{{c1::left > right}} → 直接return（右括号多于左括号必无效）
注意：每次用新字符串 curRes + "("，{{c1::无需显式回溯}}

## 复杂度
时间：{{c1::O(4^n / sqrt(n))}} — 卡特兰数
空间：{{c1::O(n)}} — 递归深度

## 关键技巧
left > right 是最核心的剪枝：右括号剩余多于左括号时，已生成的串必无效。
每次传 curRes + "(" 而非修改 StringBuilder，利用字符串不可变性天然回溯。
left 和 right 表示剩余可用数量（而非已用数量），终止条件为两者皆为0。

## 题解(DFS)
字符串不可变性使得每次递归自动创建新对象，天然回溯，无需显式 remove。

```java
class Solution {
    List<String> list = new ArrayList<>();
    public List<String> generateParenthesis(int n) {
        if (n == 0)
            return list;
        dfs("", n, n);
        return list;
    }

    public void dfs(String curRes, int left, int right) {
        if (left == 0 && right == 0) {
            list.add(curRes);
            return;
        }
        if (left > right)
            return;
        if (left > 0) {
            dfs(curRes + "(", left - 1, right);
        }
        if (right > 0) {
            dfs(curRes + ")", left, right - 1);
        }
    }
}
```
