# 字符串全排列（含重复字符）
<!-- anki-deck: 字符串的排列 -->

## 题干
输入一个可能含有重复字符的字符串，返回所有不同的全排列，顺序任意。

本题是“枚举所有排列”，返回值为 `String[]`；不要与滑动窗口中的“判断一个字符串是否包含另一个字符串的某个排列”混为一题。

## 回溯-选择列表
选择列表 = {{c1::尚未使用的字符下标}}
状态 = {{c1::当前路径 StringBuilder + used 数组}}
去重前提 = {{c1::先对字符数组排序，让相同字符相邻}}

## 回溯-终止+剪枝
终止条件：{{c1::path.length() == chars.length}}，把当前路径复制为字符串加入结果。
已在当前路径使用的下标：{{c1::used[i]}} 为 true 时跳过。
同一树层去重：{{c1::i > 0 && chars[i] == chars[i - 1] && !used[i - 1]}} 时跳过当前字符。

`!used[i - 1]` 表示前一个相同字符还没有被当前路径选择，因此二者处于同一树层的候选位置；若前一个相同字符已经被使用，则它属于当前路径的上一层，不能剪掉。

## 复杂度
最坏时间：{{c1::O(n · n!)}} — 最多生成 n! 个结果，每次构造长度为 n 的字符串。
辅助空间：{{c1::O(n)}} — 递归深度、路径和 used 数组，不计输出。
输出空间：最坏 {{c1::O(n · n!)}}。

## 题解(DFS+剪枝)
排序后使用 `used` 区分“同一字符的不同下标”，并用“同层只选第一个未使用的相同字符”消除重复结果。

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    private final List<String> result = new ArrayList<>();

    public String[] permutation(String s) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        dfs(chars, new boolean[chars.length], new StringBuilder());
        return result.toArray(new String[0]);
    }

    private void dfs(char[] chars, boolean[] used, StringBuilder path) {
        if (path.length() == chars.length) {
            result.add(path.toString());
            return;
        }

        for (int i = 0; i < chars.length; i++) {
            if (used[i]) {
                continue;
            }
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) {
                continue;
            }

            used[i] = true;
            path.append(chars[i]);
            dfs(chars, used, path);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

## 与全排列 II 的关系
两题的搜索树、`used` 状态和同层去重条件完全相同，区别只是：

- 本题输入为 `char[]`，叶子节点把路径转成 `String`
- 全排列 II 输入为 `int[]`，叶子节点复制整数列表

因此它们应共享一个“排序 + used + 同层去重”模板，但仍保留各自的题目源文件和代码接口。
