# 单词缩写枚举

## 题干
给定一个单词，生成它的所有广义缩写。缩写可以把一段或多段连续字符替换成其长度，例如 `word` 可以生成 `word`、`w1rd`、`2rd`、`w2d` 和 `4`。

数字表示连续省略的字符数，因此不能产生相邻数字片段；例如省略 `o` 和 `r` 应写成 `2`，而不是 `11`。

## 回溯状态
位置 `index`：{{c1::下一个待决定保留还是缩写的字符下标}}。
计数 `abbreviated`：{{c1::尚未写入路径的连续缩写字符数}}。
路径 `path`：{{c1::已经确定的缩写前缀}}。

对每个字符有两个选择：

1. 缩写当前字符：不修改路径，只令 `abbreviated + 1`
2. 保留当前字符：先把非零 `abbreviated` 写入路径，再写当前字符，并把计数清零

## 为什么延迟写数字
如果每缩写一个字符就立即追加 `1`，连续缩写会得到错误的相邻数字，如 `11rd`。维护累计计数并在“遇到保留字符”或“到达字符串末尾”时一次写入，才能得到 `2rd`。

回溯前必须记录旧的 `path.length()`，两个分支结束后都恢复到该长度，避免兄弟分支互相污染。

## 复杂度
每个字符都有“保留/缩写”两种选择，共产生 {{c1::2^n}} 个结果。
时间：{{c1::O(n · 2^n)}} — 每个叶子需要构造最长 O(n) 的字符串。
辅助空间：{{c1::O(n)}} — 递归深度和路径，不计输出。
输出空间：{{c1::O(n · 2^n)}}。

## 题解(二叉决策回溯)
叶子节点若仍有累计缩写数，先追加该数字，保存答案后再把路径回滚。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateAbbreviations(String word) {
        List<String> result = new ArrayList<>();
        dfs(word, 0, 0, new StringBuilder(), result);
        return result;
    }

    private void dfs(
            String word,
            int index,
            int abbreviated,
            StringBuilder path,
            List<String> result) {
        int oldLength = path.length();

        if (index == word.length()) {
            if (abbreviated > 0) {
                path.append(abbreviated);
            }
            result.add(path.toString());
            path.setLength(oldLength);
            return;
        }

        // 选择一：缩写当前字符，暂不把数字写入路径。
        dfs(word, index + 1, abbreviated + 1, path, result);

        // 选择二：保留当前字符，先结算此前连续缩写的数量。
        if (abbreviated > 0) {
            path.append(abbreviated);
        }
        path.append(word.charAt(index));
        dfs(word, index + 1, 0, path, result);
        path.setLength(oldLength);
    }
}
```
