# 添加运算符

## 题干
给定只包含数字的字符串 `num` 和目标值 `target`，在数字之间插入二元运算符 `+`、`-` 或 `*`，返回所有计算结果等于 `target` 的合法表达式。

- 可以不在某个相邻数字之间切分，例如 `"123"` 可取操作数 123、12 和 3 等
- 多位操作数不能有前导零，因此 `"05"` 非法，但单独的 `"0"` 合法
- 表达式不能改变数字原有顺序

## 搜索树
从位置 `index` 开始枚举操作数的右端点，得到当前数 `current`。第一个操作数前不添加运算符；后续分别尝试 `+current`、`-current`、`*current`。

每个数字间隙可理解为“不断开、加、减、乘”四种选择，因此搜索规模是指数级。

## 乘法优先级
`value` 表示{{c1::当前表达式按正常优先级计算后的值}}。
`last` 表示{{c1::最近一个加到 value 中、带符号的乘法项}}。

加入乘法时，不能直接计算 `value * current`。应先撤销旧的最后一项，再加入扩展后的乘法项：

`newValue = {{c1::value - last + last * current}}`

例如 `1 + 2 * 3` 在处理 3 前 `value=3,last=2`，修正后为 `3-2+2*3=7`。减法分支必须令 `last=-current`，这样后续乘法才能保持符号。

## 前导零与数值类型
枚举片段时，如果首字符是 `'0'` 且片段长度大于 1，应立即 `break`，因为继续扩展出的所有片段都有前导零。

中间值和操作数使用 `long`，避免 `int` 在拼接数字或连续乘法时过早溢出。

## 复杂度
n 个数字有 n-1 个间隙，每个间隙最多有“拼接/+/-/*”四种状态。
时间上界：{{c1::O(n · 4^(n-1))}}，其中 n 来自构造结果字符串。
辅助空间：{{c1::O(n)}} — 递归深度与表达式路径，不计输出。

## 题解(回溯+末项修正)
每次分支结束后把 `StringBuilder` 恢复到进入本层时的长度。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> addOperators(String num, int target) {
        List<String> result = new ArrayList<>();
        dfs(num, target, 0, 0L, 0L, new StringBuilder(), result);
        return result;
    }

    private void dfs(
            String num,
            long target,
            int index,
            long value,
            long last,
            StringBuilder expression,
            List<String> result) {
        if (index == num.length()) {
            if (value == target) {
                result.add(expression.toString());
            }
            return;
        }

        int oldLength = expression.length();
        long current = 0L;
        for (int end = index; end < num.length(); end++) {
            if (end > index && num.charAt(index) == '0') {
                break;
            }
            current = current * 10 + (num.charAt(end) - '0');

            if (index == 0) {
                expression.append(current);
                dfs(num, target, end + 1, current, current, expression, result);
                expression.setLength(oldLength);
                continue;
            }

            expression.append('+').append(current);
            dfs(num, target, end + 1, value + current, current, expression, result);
            expression.setLength(oldLength);

            expression.append('-').append(current);
            dfs(num, target, end + 1, value - current, -current, expression, result);
            expression.setLength(oldLength);

            expression.append('*').append(current);
            dfs(
                    num,
                    target,
                    end + 1,
                    value - last + last * current,
                    last * current,
                    expression,
                    result);
            expression.setLength(oldLength);
        }
    }
}
```
