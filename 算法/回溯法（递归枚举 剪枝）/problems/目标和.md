# 目标和

## 题干
给定一个非负整数数组 nums 和一个目标数 target。在数组的每个整数前添加 + 或 -，串联起来构造一个表达式，返回运算结果等于 target 的不同表达式的数目。

## 回溯-选择列表
选择列表 = {{c1::+ 或 -}}（每个数字前可以加 + 或 -）
两个分支：{{c1::cur + nums[count]}} 和 {{c1::cur - nums[count]}}

## 回溯-终止+剪枝
终止条件：{{c1::count == nums.length}} → 判断 cur == target
剪枝策略：{{c1::记忆化搜索}} — key = count + "_" + cur，避免重复计算
记忆化将时间从 O(2^n) 降到 {{c1::O(n*sum)}}

## 复杂度
DFS+记忆化：时间 {{c1::O(n*sum)}}，空间 {{c1::O(n*sum)}}
裸DFS：时间 O(2^n)，空间 O(n)

## 关键技巧
记忆化 key 设计：count + "_" + cur，用下划线分隔避免歧义（如 count=1,cur=23 与 count=12,cur=3）。
两条分支求和 left+right 后缓存，后续相同状态直接返回。
也可用 DP 转化为 01背包：sum(P) = (target + sum)/2。

## 题解(DFS+记忆化)
每个数字前选择+或-，两条分支。用 HashMap 记忆化(count, cur)避免重复计算。

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        return dfs(nums, target, 0, 0);
    }

    Map<String, Integer> cache = new HashMap<>();
    public int dfs(int[] nums, int target, int count, int cur) {
        String key = count + "_" + cur;
        if (cache.containsKey(key))
            return cache.get(key);
        if (count == nums.length) {
            cache.put(key, cur == target ? 1 : 0);
            return cache.get(key);
        }
        int left = dfs(nums, target, count + 1, cur + nums[count]);
        int right = dfs(nums, target, count + 1, cur - nums[count]);
        cache.put(key, left + right);
        return cache.get(key);
    }
}
```
