# 饿汉式（Eager Initialization）

## 核心思想
类加载时立即创建实例，利用 JVM 类加载机制的线程安全性天然保证单例。

## 实现代码
```java
public class Singleton {
    // 类加载时就创建实例
    private static final Singleton INSTANCE = new Singleton();

    // 私有构造器，防止外部 new
    private Singleton() {}

    // 直接返回
    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

## 关键要点
- 实例创建时机：{{c1::类加载时（static 变量初始化阶段）}}
- 线程安全性：{{c2::由 JVM 类加载机制保证，绝对线程安全}}
- static final 组合：{{c3::final 保证引用不可变，static 保证类级别唯一}}

## 优缺点
- 优点：{{c1::实现简单、JVM保证线程安全、无同步开销}}
- 缺点：{{c2::类加载时就创建，即使未使用也占用内存（浪费）}}；无法延迟初始化

## 适用场景
{{c1::单例对象轻量、一定会被使用 }} 的情况。如：配置文件读取器、数据库连接池的配置对象。
