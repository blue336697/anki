# 枚举单例（Enum Singleton）

## 核心思想
Java 枚举类型天然{{c1::每个枚举值都是单例}}，由 JVM 保证线程安全，且自动防御{{c2::反射攻击}}和{{c3::序列化破坏}}。

## 标准实现（《Effective Java》推荐）
```java
public enum Singleton {
    INSTANCE;

    // 业务方法
    public void doSomething() {
        // ...
    }
}

// 使用：Singleton.INSTANCE.doSomething();
```

## 为什么枚举最安全
1. **防反射**：{{c1::枚举没有无参构造器}}，Constructor.newInstance() 会抛出 IllegalArgumentException（JDK 内部做了保护）
2. **防序列化破坏**：{{c2::枚举默认实现了 readResolve}}，反序列化返回同一个 INSTANCE
3. **线程安全**：{{c3::枚举值的初始化由 JVM 类加载保证}}

## 枚举展开等价代码
```java
// enum Singleton { INSTANCE } 编译后近似于：
public final class Singleton extends Enum<Singleton> {
    public static final Singleton INSTANCE = new Singleton();
    private Singleton() { super("INSTANCE", 0); }
    // ...
}
```

## 优缺点
- 优点：{{c1::最安全（防反射+防序列化）、代码最少、线程安全}}
- 缺点：{{c2::不能继承其他类（枚举隐式继承Enum）}}；语义不够直观

## 适用场景
{{c1::需要绝对安全的单例}}，尤其是会被序列化/反射的场景。

## 各方式安全性对比
| 实现方式 | 线程安全 | 防反射 | 防序列化 |
|------|:--:|:--:|:--:|
| 饿汉式 | ✅ | ❌ | ❌ |
| DCL | ✅ | ❌ | ❌ |
| 静态内部类 | ✅ | ❌ | ❌ |
| 枚举 | ✅ | ✅ | ✅ |
