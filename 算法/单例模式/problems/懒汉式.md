# 懒汉式（Lazy Initialization）

## 线程不安全版
```java
public class Singleton {
    private static Singleton instance;

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {          // ① 线程A执行到这里
            instance = new Singleton();   // ② 线程B也执行到这里 → 创建两个实例！
        }
        return instance;
    }
}
```

问题：{{c1::多线程同时通过 if(instance==null) 检查，创建多个实例}}

## 线程安全版（synchronized 方法）
```java
public class Singleton {
    private static Singleton instance;

    private Singleton() {}

    public static synchronized Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

{{c2::对整个方法加锁}}，保证线程安全。

## 优缺点对比
| | 线程不安全 | synchronized |
|------|:--:|:--:|
| 延迟加载 | ✅ | ✅ |
| 线程安全 | ❌ | ✅ |
| 性能 | 高（无锁） | 差（每次调用都加锁） |

synchronized 瓶颈：{{c3::每次 getInstance() 都要获取锁，即使实例已创建}}

## 适用场景
- 线程不安全版：{{c1::仅单线程环境}}，几乎不用于生产
- synchronized版：{{c2::对性能要求不高 }} 的简单场景

## 关键问题
synchronized 懒汉式的缺陷催生了 {{c3::双重检查锁定（DCL）}}
