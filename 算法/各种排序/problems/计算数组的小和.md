# 计算数组的小和

## 题干
数组小和定义：对于数组中每个数，累加其左侧所有比它小的数的和。
示例：[1,3,4,2,5] 的小和 = 0 + 1 + (1+3) + 1 + (1+3+4+2) = 16。

## 复杂度
时间 {{c1::O(n log n)}}
推导：归并排序每层merge遍历n个元素，共log n层 → O(n log n)
空间 {{c1::O(n)}}
推导：需要与数组等长的临时数组用于merge

## 关键技巧
核心：归并时若 nums[i] <= nums[j]，右侧[j, right]共(right-j+1)个数>=nums[i]
贡献小和 = (right-j+1) × nums[i]
注意相等时必须用<=计算(不能漏)，否则丢失贡献
本质是归并排序的"副产品"——利用合并时两侧已排序的性质直接累计

## 题解(归并排序求小和)
归并时若 nums[i] <= nums[j]，右侧[j, right]共(right-j+1)个数都>=nums[i]，贡献小和。

```java
public class Main {
    static int[] temp;

    public static long sortAndMerge(int[] nums, int left, int right) {
        if (left >= right) return 0;
        int mid = left + (right - left) / 2;
        long res = sortAndMerge(nums, left, mid)
                 + sortAndMerge(nums, mid + 1, right);
        int i = left, j = mid + 1, k = 0;
        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) {
                res += (right - j + 1) * nums[i];
                temp[k++] = nums[i++];
            } else {
                temp[k++] = nums[j++];
            }
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];
        for (i = left, k = 0; i <= right; i++)
            nums[i] = temp[k++];
        return res;
    }
}
```
