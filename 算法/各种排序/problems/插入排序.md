# 插入排序

## 题干
插入排序：将数组分为已排序前缀和未排序后缀，每次取后缀第一个元素，在已排序前缀中找到正确位置插入。
类似于打牌时摸到一张新牌，插入到手中有序牌的合适位置。

## 关键技巧
插入排序在数据基本有序时极快(O(n))，是希尔排序的基础
稳定：用arr[j] > key(不用>=)保证相等元素不交换
对小型数组(约<20个元素)，插入排序比快排/归并更快(常数因子小)
Java的Arrays.sort对小于47个元素的数组使用插入排序

## 题解
标准插入排序（逆序比较+移位）

```java
public void insertionSort(int[] arr) {
    int n = arr.length;
    // 第一个元素已有序，从第二个开始
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        // 将大于key的元素右移
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        // 插入key到正确位置
        arr[j + 1] = key;
    }
}
```

## 核心思想
**核心机制：向已排序前缀中插入新元素**

1. 默认第一个元素为已排序前缀
2. 从i=1开始，取出arr[i]暂存为key
3. 在[0, i-1]已排序区域逆序遍历，将大于key的元素右移一位
4. 找到第一个不大于key的位置(j+1)，插入key
5. 逆序遍历比正序遍历更高效：可以边比较边移动

## 复杂度分析
**时间复杂度推导：**
最坏(逆序)：每轮需将已排序部分全部右移
→ 1+2+...+(n-1) = {{c1::n(n-1)/2}} = O(n²)
最好(已有序)：每轮只比较1次无需移动 → {{c1::O(n)}}
平均：每个元素需要比较/移动一半的长度 → 约n²/4 → O(n²)

**空间复杂度推导：**
只用一个变量key暂存当前元素 → {{c1::O(1)}}

**稳定性：**{{c1::稳定}}(只有严格大于才右移，相等时不移动)
