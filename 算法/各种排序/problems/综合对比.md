# 综合对比

## 排序算法选择决策树
**数据量小(n<50)** → 插入排序（简单高效）
**数据基本有序** → 插入排序（接近O(n)）
**需要稳定** → 归并排序 / 插入排序
**内存严格受限** → 堆排序（O(1)空间）
**通用大数据** → 快速排序（实际最快）
**数据范围小** → 计数排序（O(n)）
**外部排序(磁盘)** → 归并排序
**链表排序** → 归并排序（不需要随机访问）
**数据均匀分布** → 桶排序（平均O(n)）

## 各排序算法本质理解
冒泡：相邻比较交换，O(n²)，{{c1::稳定}}，最简单
选择：选最小放前面，O(n²)，{{c1::不稳定}}，交换最少
插入：插入已排序前缀，O(n²)，{{c1::稳定}}，基本有序时最快
希尔：分组预排序+插入排序，{{c1::O(n^1.3)}}，不稳定
快排：partition分治，O(n log n)，{{c1::不稳定}}，实际最快
归并：分治合并有序数组，O(n log n)，{{c1::稳定}}，需O(n)空间
堆排：建堆+反复交换堆顶，O(n log n)，{{c1::不稳定}}，O(1)空间
计数：统计频率+前缀和，O(n+k)，{{c1::稳定}}，需值域小
桶排：分桶+桶内排序+合并，O(n+k)，取决于均匀性
基数：逐位排序(LSD/MSD)，O(nk)，{{c1::稳定}}，用计数排序做子程序

## 面试高频排序对比
为什么快排比归并快？快排{{c1::原地排序}}缓存友好，常数因子小；归并需{{c1::O(n)额外空间}}
为什么快排比堆排快？快排{{c1::局部性好}}，堆排跳跃访问{{c1::缓存不友好}}
为什么归并排序最稳定？比较次数固定{{c1::n log n}}，不受输入影响，且{{c1::稳定}}
堆排序最大优势：{{c1::O(1)空间}}的O(n log n)算法
计数/基数为什么能O(n)？{{c1::不基于比较}}，利用数据范围信息

## 排序可视化对比
冒泡/选择/插入 → 适合学习和理解排序概念
快排 → partition是核心，理解才能写对
归并 → merge是核心，分治思想典型
堆排 → heapify是核心，理解堆结构
计数 → 前缀和是稳定版的关键
基数 → 计数排序的应用，逐位思想
希尔 → gap序列影响性能，理解"预排序"思想
