# 计数排序

## 题干
计数排序：非比较排序。统计每个值出现的次数，然后按值的大小顺序依次输出。
适用于数据范围有限(很小)的整数排序。不是基于比较，可以突破O(n log n)下限。

## 关键技巧
计数排序是基数排序的基础，突破比较排序O(n log n)下限
前提条件：数据范围小且已知。范围太大则浪费空间
稳定版本的关键三步：统计→前缀和→逆序回填
逆序遍历原数组是稳定性的保证：相同元素后面的先放
只能排整数，不能排浮点数或字符串(可转为基数排序)

## 题解(稳定版)
前缀和+逆序回填，保持稳定性

```java
public void countingSort(int[] arr) {
    if (arr.length == 0) return;
    // 1. 找数据范围
    int min = arr[0], max = arr[0];
    for (int num : arr) {
        if (num < min) min = num;
        if (num > max) max = num;
    }
    // 2. 计数
    int range = max - min + 1;
    int[] count = new int[range];
    for (int num : arr) count[num - min]++;
    // 3. 前缀和：count[i] = 值i+min的最后一个位置+1
    for (int i = 1; i < range; i++)
        count[i] += count[i - 1];
    // 4. 逆序回填（保证稳定）
    int[] output = new int[arr.length];
    for (int i = arr.length - 1; i >= 0; i--) {
        int idx = --count[arr[i] - min];
        output[idx] = arr[i];
    }
    System.arraycopy(output, 0, arr, 0, arr.length);
}
```

## 题解(简化版/不稳定)
直接按计数输出，代码简单但不稳定

```java
public void countingSortSimple(int[] arr) {
    int max = arr[0];
    for (int num : arr) max = Math.max(max, num);
    int[] count = new int[max + 1];
    for (int num : arr) count[num]++;
    int idx = 0;
    for (int i = 0; i <= max; i++)
        while (count[i]-- > 0) arr[idx++] = i;
}
```

## 核心思想
**核心机制：计数 + 前缀和确定位置**

1. 找到数据范围[min, max]
2. 创建计数数组count[max-min+1]，统计每个值的出现次数
3. 对count做前缀和：count[i] += count[i-1]，此时count[i]表示值i+min排序后的最后位置+1
4. 逆序遍历原数组，根据count确定每个元素的最终位置
5. **逆序遍历是稳定版本的关键**：保证相等元素的原顺序

**稳定版本 vs 不稳定版本：**
不稳定版：直接按计数输出即可。
稳定版：需前缀和+逆序回填，代码稍复杂但保持稳定性。

## 复杂度分析
**时间复杂度推导：**
统计频率：遍历n个元素 → O(n)
计算前缀和：遍历k个桶 → O(k)，k = 值域大小
回填结果：逆序遍历n个元素 → O(n)
总时间 = {{c1::O(n+k)}}
当k << n时线性O(n)，当k很大时退化为O(k)

**空间复杂度推导：**
计数数组大小k + 结果数组大小n → {{c1::O(n+k)}}
如果原地排序可省去结果数组 → 空间降为O(k)但不稳定

**稳定性：**{{c1::稳定}}(前缀和+逆序遍历版本)
