# 快速排序

## 题干
快速排序：分治算法。每轮选一个基准(pivot)，通过partition将数组分为"小于基准"和"大于基准"两部分，再递归排序左右子数组。
是实际应用中最快的通用排序算法。

## 关键技巧
partition是快排的灵魂：双指针从两端向中间扫描
取最左为基准时必须先从右扫描，否则基准归位错误
最坏O(n²)发生在已排序数组取最左/最右为基准 → 可随机化避免
实际使用中快排常数因子小，通常比归并和堆排快2-3倍
Java的Arrays.sort对基本类型用快排变体(DualPivotQuickSort)

## 题解(经典快排)
取最左为基准，双指针partition

```java
class Solution {
    public int[] sortArray(int[] nums) {
        quickSort(nums, 0, nums.length - 1);
        return nums;
    }

    private int partition(int[] nums, int left, int right) {
        int i = left, j = right;
        int pivot = nums[left];
        while (i < j) {
            // 必须先从右向左扫描
            while (i < j && nums[j] >= pivot) j--;
            nums[i] = nums[j];
            while (i < j && nums[i] <= pivot) i++;
            nums[j] = nums[i];
        }
        nums[i] = pivot;
        return i;
    }

    private void quickSort(int[] nums, int left, int right) {
        if (left >= right) return;
        int p = partition(nums, left, right);
        quickSort(nums, left, p - 1);
        quickSort(nums, p + 1, right);
    }
}
```

## 题解(简化版快排)
更简洁的写法，同样取最左为基准

```java
public void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int i = left, j = right;
    int pivot = arr[left];
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        if (i < j) arr[i++] = arr[j];
        while (i < j && arr[i] < pivot) i++;
        if (i < j) arr[j--] = arr[i];
    }
    arr[i] = pivot;
    quickSort(arr, left, i - 1);
    quickSort(arr, i + 1, right);
}
```

## 核心思想
**核心机制：partition划分 + 分治递归**

1. 选择一个基准元素(pivot)，这里取最左元素
2. partition：双指针i(左)和j(右)，j先向左扫描找小于基准的元素，i向右扫描找大于基准的元素，交换
3. 当i==j时，将基准放到该位置 → 左边都<=基准，右边都>=基准
4. 递归排序左右两个子数组
5. 递归终止条件：区间长度<=1

**为什么必须先从右向左扫描：**
取最左为基准时，最后i和j相遇的位置才是基准的正确位置。
如果先从左扫描，i会停在大于基准的位置，交换后基准左侧会出现大于它的元素。

## 复杂度分析
**时间复杂度推导(平均)：**
每次partition将数组大致平分 → 递归树深度约 log n
每层partition遍历n个元素 → 每层O(n)
总时间 = 层数×每层工作量 = {{c1::O(n log n)}}

**时间复杂度推导(最坏)：**
每次partition只排除1个元素(如已排序数组取最左为基准)
递归深度变为n → 总时间=n+(n-1)+...+1 = {{c1::O(n²)}}
随机化选择基准可以避免最坏情况

**空间复杂度推导：**
递归栈深度：平均{{c1::O(log n)}}层，最坏{{c1::O(n)}}层 → O(log n)

**稳定性：**{{c1::不稳定}}(partition中的交换会打乱相等元素的相对顺序)
