# 基数排序

## 题干
基数排序：非比较排序。从最低位(LSD)或最高位(MSD)开始，依次按每一位数字进行稳定排序(通常用计数排序作为子程序)。
适用于整数或定长字符串排序，可以处理较大数据范围。

## 关键技巧
基数排序每次按一位排序，必须用稳定排序作为子排序
LSD更常用（代码简单），MSD可以提前终止(适合字符串)
基数r可以取16(十六进制)、256(字节)等，r大则位数少但计数数组大
复杂度和元素个数n、数字位数d、基数r都相关：O(d(n+r))
适合定长数据(固定位数整数、定长字符串)，不适合变长数据

## 题解(LSD)
从最低位到最高位，每位用计数排序

```java
public void radixSort(int[] arr) {
    if (arr.length == 0) return;
    // 1. 找最大值确定位数
    int max = arr[0];
    for (int num : arr) max = Math.max(max, num);
    // 2. 从个位开始，按每位排序
    int[] output = new int[arr.length];
    for (int exp = 1; max / exp > 0; exp *= 10) {
        int[] count = new int[10];
        // 统计当前位的数字频率
        for (int num : arr)
            count[(num / exp) % 10]++;
        // 前缀和
        for (int i = 1; i < 10; i++)
            count[i] += count[i - 1];
        // 逆序回填（保证稳定）
        for (int i = arr.length - 1; i >= 0; i--) {
            int digit = (arr[i] / exp) % 10;
            output[--count[digit]] = arr[i];
        }
        System.arraycopy(output, 0, arr, 0, arr.length);
    }
}
```

## 核心思想
**核心机制：逐位排序(LSD) + 计数排序作为稳定子程序**

LSD(Least Significant Digit)基数排序：
1. 从最低位(个位)开始，到最高位结束
2. 每一位使用计数排序(10个桶，对应0-9数字)
3. 每次按当前位排序后收集回原数组
4. 由于计数排序是稳定的，高位的排序不会破坏低位的顺序

**为什么LSD是稳定的关键：**
先按个位排→再按十位排→再按百位排...
当十位相同时，之前按个位排好的顺序得以保留 → 正确排序。

## 复杂度分析
**时间复杂度推导：**
设最大数字有d位，每位数范围k(十进制k=10)
共d轮，每轮用计数排序O(n+k) → {{c1::O(d × (n+k))}}
通常k固定(如k=10)，d=log₁₀(max)
简写为：{{c1::O(nk)}}（k为位数）
当k较小时近似线性O(n)

**空间复杂度推导：**
每轮计数排序需要temp(n) + count(k) → {{c1::O(n+k)}}

**稳定性：**{{c1::稳定}}(每轮计数排序是稳定的)
