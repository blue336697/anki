# 希尔排序

## 题干
希尔排序：插入排序的改进版。先以较大步长(gap)分组进行插入排序，让元素快速接近最终位置；然后逐步缩小步长直到gap=1，即标准插入排序。
此时数组已基本有序，插入排序效率大幅提升。

## 关键技巧
希尔排序的唯一参数是gap序列，直接影响性能
gap=1时退化为插入排序，但数据已基本有序所以很快
gap序列有多种选择：Shell原始(n/2)、Hibbard(2^k-1)、Sedgewick等
面试记住n/2递减即可，关键是理解"分组预排序"的思想

## 题解
希尔排序（gap = n/2, n/4, ..., 1）

```java
public void shellSort(int[] arr) {
    int n = arr.length;
    // gap逐步缩小
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个gap分组做插入排序
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i - gap;
            // 组内元素间隔为gap
            while (j >= 0 && arr[j] > key) {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = key;
        }
    }
}
```

## 核心思想
**核心机制：分组插入排序 + 缩小增量**

1. 选择初始步长gap = n/2
2. 将所有距离为gap的元素分为一组，组内进行插入排序
3. gap = gap/2，重复步骤2
4. 当gap=1时，就是标准插入排序，但此时数据已基本有序

**为什么比插入排序快：**
大步长时元素少交换快，小步长时数据已基本有序
本质是让元素"跳着"逼近目标位置，减少总的移动次数

## 复杂度分析
**时间复杂度推导：**
希尔排序的时间复杂度取决于gap序列的选择
使用最简gap=n/2, n/4, ..., 1时：
最坏约{{c1::O(n²)}}(如gap=1时才有效排序)
使用Hibbard序列(1,3,7,15,...,2^k-1)最坏可降至{{c1::O(n^1.5)}}
平均复杂度经验值为 O(n^1.3)，但没有精确证明

**空间复杂度推导：**
原地排序，只有几个临时变量 → {{c1::O(1)}}

**稳定性：**{{c1::不稳定}}(同组内插入排序虽然稳定，但不同组之间可能打乱顺序)
