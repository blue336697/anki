# 选择排序

## 题干
选择排序：每轮从未排序部分选出最小元素，放到已排序部分的末尾。
类似于打牌时每次从牌堆中选出最小的牌放到手中。

## 关键技巧
选择排序的交换次数最少(n-1次)，但比较次数固定O(n²)
不稳定：跨位置交换会改变相等元素的相对顺序
性能与数据初始状态无关，适合交换成本高的场景
实际项目中几乎不用，但它是最直观的排序之一

## 题解
标准选择排序

```java
public void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        // 在未排序区域[i, n-1]找最小值
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // 将最小值交换到已排序区域末尾
        if (minIdx != i) {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

## 核心思想
**核心机制：选择最小值 + 交换到前面**

1. 外层循环i从0到n-2，i之前是已排序区域
2. 每轮在[i, n-1]范围内找到最小值的索引min
3. 交换arr[i]和arr[min]，将最小值归位
4. 重复直到全部有序
5. 无论数据初始状态如何，比较次数固定

## 复杂度分析
**时间复杂度推导：**
外层n-1轮，每轮在剩余元素中找最小值
比较次数：(n-1)+(n-2)+...+1+0 = {{c1::n(n-1)/2}}
无论数据是否有序，比较次数不变 → 始终 {{c1::O(n²)}}
交换次数：每轮最多1次 → 共n-1次交换

**空间复杂度推导：**
只需min和temp两个变量 → {{c1::O(1)}}

**稳定性：**{{c1::不稳定}}(交换可能打乱相等元素的相对顺序)
例：[5, 5, 2] 第一轮选最小2与第一个5交换 → 两个5的顺序改变了
