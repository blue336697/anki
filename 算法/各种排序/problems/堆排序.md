# 堆排序

## 题干
堆排序：利用二叉最大堆(或最小堆)进行排序。
先建堆，然后反复将堆顶(最大元素)与堆末尾交换，缩小堆并向下调整，直到堆大小为1。
是空间最优的O(n log n)排序算法。

## 关键技巧
堆排序是唯一一个同时满足O(n log n)时间和O(1)空间的算法
索引计算：父→左子2i+1，右子2i+2；子→父(i-1)/2
最后一个非叶节点 = n/2-1（叶子节点从n/2开始）
建堆O(n)的关键：底层节点多但下沉少，顶层节点少但下沉多
实际速度通常慢于快排（常数因子大、缓存不友好）
大根堆得升序，小根堆得降序

## 题解(递归版heapify)
建大根堆 → 交换堆顶和末尾 → 向下调整

```java
public void heapSort(int[] nums) {
    int n = nums.length;
    // 建初堆：从最后一个非叶节点向上
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(nums, n, i);
    }
    // 排序：依次将堆顶换到末尾
    for (int i = n - 1; i > 0; i--) {
        int temp = nums[0];
        nums[0] = nums[i];
        nums[i] = temp;
        heapify(nums, i, 0);
    }
}

private void heapify(int[] nums, int heapSize, int root) {
    int largest = root;
    int left = 2 * root + 1;
    int right = 2 * root + 2;
    if (left < heapSize && nums[left] > nums[largest])
        largest = left;
    if (right < heapSize && nums[right] > nums[largest])
        largest = right;
    if (largest != root) {
        int temp = nums[root];
        nums[root] = nums[largest];
        nums[largest] = temp;
        heapify(nums, heapSize, largest);
    }
}
```

## 题解(迭代版heapify)
迭代版本避免递归开销

```java
private void heapifyIterative(int[] nums, int heapSize, int root) {
    while (true) {
        int largest = root;
        int left = 2 * root + 1;
        int right = 2 * root + 2;
        if (left < heapSize && nums[left] > nums[largest])
            largest = left;
        if (right < heapSize && nums[right] > nums[largest])
            largest = right;
        if (largest == root) break;
        int temp = nums[root];
        nums[root] = nums[largest];
        nums[largest] = temp;
        root = largest;
    }
}
```

## 核心思想
**核心机制：建堆 + 反复交换堆顶和末尾**

1. **建初堆**：从最后一个非叶节点(len/2-1)向上，对每个节点做向下调整(heapify)
   → 确保每个子树满足大根堆性质(父>=子)
2. **排序过程**：重复n-1次
   a. 交换堆顶(索引0，最大值)和堆末尾(索引i)
   b. 堆大小减1，对新的堆顶做向下调整
3. **heapify向下调整**：比较父节点与左右子节点，与最大的子节点交换，递归向下
4. 堆顶始终是当前堆中的最大值

## 复杂度分析
**时间复杂度推导：**
建堆：每个节点最多调整log n次，但大部分节点在底层 → 实际是{{c1::O(n)}}
证明：第k层共2^k个节点，每个最多下沉(h-k)层，级数求和得O(n)
排序：n-1次heapify，每次{{c1::O(log n)}} → O(n log n)
总时间：O(n) + O(n log n) = {{c1::O(n log n)}}
无论数据如何，堆排序的时间稳定在O(n log n)

**空间复杂度推导：**
全部操作在原数组上进行 → {{c1::O(1)}}
递归heapify可以改为while循环，消除递归栈

**稳定性：**{{c1::不稳定}}(交换堆顶和末尾会打乱顺序)
