# 桶排序

## 题干
桶排序：将数据均匀分配到多个桶(bucket)中，每个桶内用其他排序算法(如插入排序)排序，最后按桶的顺序依次取出所有元素。
适用于数据均匀分布的场景。

## 关键技巧
桶排序性能高度依赖数据的均匀分布程度
桶数量≈元素数量时效率最高，平均O(n)
映射函数的设计直接影响性能：要尽量均匀分配
桶内排序通常用插入排序(桶内元素少时最快)
本质是"分而治之"思想在不同维度上的应用

## 题解
桶排序（桶内使用插入排序）

```java
public void bucketSort(int[] arr) {
    if (arr.length == 0) return;
    int n = arr.length;
    // 1. 找数据范围
    int min = arr[0], max = arr[0];
    for (int num : arr) {
        if (num < min) min = num;
        if (num > max) max = num;
    }
    // 2. 创建n个桶
    List<Integer>[] buckets = new List[n];
    for (int i = 0; i < n; i++)
        buckets[i] = new ArrayList<>();
    // 3. 分配到桶
    double range = (double)(max - min + 1);
    for (int num : arr) {
        int idx = (int)((num - min) * n / range);
        buckets[idx].add(num);
    }
    // 4. 桶内排序并合并
    int k = 0;
    for (List<Integer> bucket : buckets) {
        Collections.sort(bucket);
        for (int num : bucket) arr[k++] = num;
    }
}
```

## 核心思想
**核心机制：分桶 + 桶内排序 + 合并**

1. 确定桶的数量n和每个桶的范围
2. 遍历数组，根据映射函数将元素分配到对应的桶
3. 对每个非空桶内部进行排序(通常用插入排序，因为桶内数据少)
4. 按桶的顺序，将所有桶中的元素依次放回原数组

**映射函数：**桶索引 = (元素值 - 最小值) × (桶数 - 1) / (最大值 - 最小值)
确保元素均匀分布在各桶中。

## 复杂度分析
**时间复杂度推导：**
最坏情况：所有元素落入同一个桶 → 桶内排序退化为O(n²)
即 {{c1::O(n²)}}（使用插入排序时）
平均情况：n个元素均匀分布在k个桶中，每桶n/k个元素
桶内排序O((n/k)²)，k个桶共k×(n/k)² = n²/k
当k≈n时 → {{c1::O(n)}}
（k取n时每桶平均1个元素，则退化为计数排序）

**空间复杂度推导：**
k个桶存储n个元素 → {{c1::O(n+k)}}

**稳定性：**{{c1::取决于桶内排序算法}}（桶内用插入排序则稳定）
