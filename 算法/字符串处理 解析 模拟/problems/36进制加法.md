# 36进制加法

## 题干
36进制数的加法。36进制的数表示为 0-9 正常表，10-35 用 a-z 表示。例如 1b = 47，2x = 105。实现两个36进制字符串的加法。
![image 3.png](image%203.png)

## 复杂度
时间：{{c1::O(max(N, M))}} — 从末尾逐位相加
空间：{{c1::O(max(N, M))}} — StringBuilder

## 关键技巧
与「字符串相加」对比记忆：框架完全相同，仅有三个差异：
1. 基数：/10 和 %10 → /36 和 %36
2. 字符映射：ch-'0' ↔ n+'0' → 增加 ch-'a'+10 ↔ n-10+'a'
3. 本质上任何进制加法都可用此模板，只需替换基数和映射函数

## 题解(模拟)
与十进制加法完全相同的框架，仅基数从10变为36，增加字符映射函数。

```java
class Solution {
    private char getChar(int n) {
        if (n <= 9)
            return (char) (n + '0');
        else
            return (char) (n - 10 + 'a');
    }

    private int getInt(char ch) {
        if ('0' <= ch && ch <= '9')
            return ch - '0';
        else
            return ch - 'a' + 10;
    }

    public String addStrings(String num1, String num2) {
        StringBuilder res = new StringBuilder("");
        int i = num1.length() - 1, j = num2.length() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry != 0) {
            int n1 = i >= 0 ? getInt(num1.charAt(i)) : 0;
            int n2 = j >= 0 ? getInt(num2.charAt(j)) : 0;
            int tmp = n1 + n2 + carry;
            carry = tmp / 36;
            res.append(getChar(tmp % 36));
            i--; j--;
        }
        if (carry == 1) res.append(getChar(1));
        return res.reverse().toString();
    }
}
```
