# 找到字符串中所有字母异位词

## 题干
给定两个字符串 s 和 p，找到 s 中所有 p 的异位词的子串，返回这些子串的起始索引。异位词指由相同字母重排列形成的字符串（不区分大小写）。

## 复杂度
时间：{{c1::O(n)}} — 滑动窗口一次遍历
空间：{{c1::O(26)}} — window 和 needs 数组

## 关键技巧
滑动窗口解题三步：
1. 扩展右指针（加入新字符，更新 window 和 needCount）
2. 收缩判断（当窗口长度 ≥ p 的长度时，判断 needCount==pCount）
3. 收缩左指针（移出字符，更新 window 和 needCount）
关键优化：不比较整个 needs 和 window 数组，而是用 needCount 跟踪已满足条件的字符种类数。

## 题解(滑动窗口)
needCount 跟踪已满足条件的字符种类数，等于 pCount 时窗口是异位词。

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int[] window = new int[26], needs = new int[26];
        List<Integer> res = new ArrayList<>();
        int len1 = p.length(), len2 = s.length();
        for (int i = 0; i < len1; i++) {
            needs[p.charAt(i) - 'a']++;
        }
        int pCount = 0;
        for (int i = 0; i < 26; i++) {
            if (needs[i] > 0) {
                pCount++;
            }
        }
        int left = 0, right = 0;
        int needCount = 0;
        while (right < len2) {
            char ch = s.charAt(right);
            right++;
            if (needs[ch - 'a'] > 0) {
                window[ch - 'a']++;
                if (window[ch - 'a'] == needs[ch - 'a'])
                    needCount++;
            }
            while (right - left >= len1) {
                if (needCount == pCount)
                    res.add(left);
                char remove = s.charAt(left);
                left++;
                if (needs[remove - 'a'] > 0) {
                    if (window[remove - 'a'] == needs[remove - 'a'])
                        needCount--;
                    window[remove - 'a']--;
                }
            }
        }
        return res;
    }
}
```
