# 压缩字符串

## 题干
给定一个字符数组 chars，使用原地算法压缩它。压缩规则：如果字符连续出现 cnt 次，则压缩为 [字符] + [cnt]（cnt>1时）。返回压缩后数组的新长度。必须原地修改输入数组。

## 复杂度
时间：{{c1::O(n)}} — 一次遍历
空间：{{c1::O(1)}} — 原地修改

## 关键技巧
双指针原地压缩：i（读指针）扫描原数组，j（写指针）写入压缩结果。
数字写入的两种方式：
1. String.valueOf(cnt)：简洁但创建了额外字符串对象
2. 逆序取余+反转：真正原地，字符逐位写入后反转数字片段
注意：压缩后的长度可能比原数组短或长（计数为1时不变），j 始终表示新长度。

## 题解(双指针+数字反转)
数字逆序写入后再反转数组片段，避免使用 String 对象（更符合"原地"要求）。

```java
class Solution {
    public int compress(char[] cs) {
        int n = cs.length;
        int i = 0, j = 0;
        while (i < n) {
            int idx = i;
            while (idx < n && cs[idx] == cs[i]) idx++;
            int cnt = idx - i;
            cs[j++] = cs[i];
            if (cnt > 1) {
                int start = j, end = start;
                while (cnt != 0) {
                    cs[end++] = (char) ((cnt % 10) + '0');
                    cnt /= 10;
                }
                reverse(cs, start, end - 1);
                j = end;
            }
            i = idx;
        }
        return j;
    }
    void reverse(char[] cs, int start, int end) {
        while (start < end) {
            char t = cs[start];
            cs[start] = cs[end];
            cs[end] = t;
            start++; end--;
        }
    }
}
```

## 题解(双指针+直接转换)
i 用于扫描，j 用于写入。统计连续字符数后用 String.valueOf 写入数字。

```java
class Solution {
    public int compress(char[] cs) {
        int n = cs.length;
        int i = 0, j = 0;
        while (i < n) {
            int idx = i;
            while (idx < n && cs[idx] == cs[i]) idx++;
            int cnt = idx - i;
            cs[j++] = cs[i];
            if (cnt > 1) {
                int end = j;
                String str = String.valueOf(cnt);
                for (int k = 0; k < str.length(); k++) {
                    cs[end++] = str.charAt(k);
                }
                j = end;
            }
            i = idx;
        }
        return j;
    }
}
```
