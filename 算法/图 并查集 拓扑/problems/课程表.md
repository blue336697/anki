# 课程表

## 题干
你这个学期必须选修 numCourses 门课程，prerequisites[i]=[a,b] 表示先修课程 b 才能学 a。判断是否可能完成所有课程的学习。
![image.png](image.png)

## 复杂度
时间：{{c1::O(V+E)}} — 构建图+BFS遍历所有顶点和边
空间：{{c1::O(V+E)}} — 邻接表和入度数组

## 关键技巧
BFS拓扑排序：入度为0的课先学，BFS过程中减后继入度，最后 count==numCourses 则无环。
DFS三色标记：遍历过程中遇到状态为1（正在访问中）的节点说明存在环。
两者都能检测有向图中的环，BFS拓扑更直观，DFS三色标记更省空间（无需维护队列）。

## 题解(BFS拓扑排序)
BFS拓扑排序：构建入度表和邻接表，入度为0的课入队，BFS过程中减少后继入度，最后检查是否所有课都学完。

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1.课号和对应的入度
        Map<Integer, Integer> inDegree = new HashMap<>();
        // 将所有的课程先放入
        for (int i = 0; i < numCourses; i++) {
            inDegree.put(i, 0);
        }
        // 2.依赖关系, 依赖当前课程的后序课程
        Map<Integer, List<Integer>> adj = new HashMap<>();

        // 初始化入度和依赖关系
        for (int[] relate : prerequisites) {
            // (3,0), 想学3号课程要先完成0号课程, 更新3号课程的入度和0号课程的依赖(邻接表)
            int cur = relate[1];
            int next = relate[0];
            // 1.更新入度
            inDegree.put(next, inDegree.get(next) + 1);
            // 2.当前节点的邻接表
            if (!adj.containsKey(cur)) {
                adj.put(cur, new ArrayList<>());
            }
            adj.get(cur).add(next);
        }

        // 3.BFS, 将入度为0的课程放入队列, 队列中的课程就是没有先修, 可以学的课程
        Queue<Integer> q = new LinkedList<>();
        for (int key : inDegree.keySet()) {
            if (inDegree.get(key) == 0) {
                q.offer(key);
            }
        }
        int count = 0;
        // 取出一个节点, 对应学习这门课程.
        // 遍历当前邻接表, 更新其入度; 更新之后查看入度, 如果为0, 加入到队列
        while (!q.isEmpty()) {
            int cur = q.poll();
            count++;
            // 遍历当前课程的邻接表, 更新后继节点的入度
            if (!adj.containsKey(cur)) {
                continue;
            }
            List<Integer> successorList = adj.get(cur);

            for (int k : successorList) {
                inDegree.put(k, inDegree.get(k) - 1);
                if (inDegree.get(k) == 0) {
                    q.offer(k);
                }
            }
        }

        // 4.选了的课等于总课数，true，否则false
        return count == numCourses;
    }
}
```

## 题解(DFS环检测)
DFS三色标记检测环：0=未访问，1=正在访问，-1=已访问。遍历过程中遇到状态为1的节点说明存在环。

```java
class Solution {
    // 通过邻接表来表示图的每个节点的连接关系
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 设置一个存储总共课程的集合
        List<List<Integer>> adjacency = new ArrayList<>();
        // 总共有多少门课程，adjacency中就有多少个list
        for (int i = 0; i < numCourses; i++)
            adjacency.add(new ArrayList<>());
        // 对应每个节点的访问记录，标记是否已经访问过
        // 0：未被访问过
        // -1：已被其他节点为起点的遍历访问
        // 1：已被当前节点为起点的遍历访问
        int[] flags = new int[numCourses];
        for (int[] cp : prerequisites)
            // 将需要先学的课程的值得到，该值对应的邻接表的位置
            // 就是该节点的位置
            // 并将前置课程学习完后才能学习的课程加入到该位置
            adjacency.get(cp[1]).add(cp[0]);
        for (int i = 0; i < numCourses; i++)
            // 循环遍历以不同节点为起点的dfs 只要返回false，
            // if成立即说明有环，返回false
            if (!dfs(adjacency, flags, i)) return false;
        return true;
    }

    private boolean dfs(List<List<Integer>> adjacency,
                        int[] flags, int i) {
        if (flags[i] == 1) return false;
        if (flags[i] == -1) return true;
        // 如果未被访问过，则标记
        flags[i] = 1;
        // 然后遍历对应位置的后续学习课程
        for (Integer j : adjacency.get(i))
            if (!dfs(adjacency, flags, j)) return false;
        flags[i] = -1;
        return true;
    }
}
```
