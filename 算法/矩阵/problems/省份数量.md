# 省份数量

## 题干
有 n 个城市，其中一些彼此相连，另一些没有相连。省份是一组直接或间接相连的城市，组内不含其他没有相连的城市。给定 n x n 矩阵 isConnected，isConnected[i][j]=1 表示第 i 个城市和第 j 个城市直接相连。返回矩阵中省份的数量。

## 复杂度
并查集：时间 {{c1::O(n^2 * alpha(n))}}，空间 {{c1::O(n)}} -- father 映射表

## 关键技巧
并查集核心操作：
1. add(x)：加入孤立节点，连通分量数+1
2. merge(x,y)：若两个节点祖先不同，将一个祖先指向另一个，连通分量数-1
3. findAnc(x)：查找祖先 + 路径压缩，将所有子节点直接挂到根节点
遍历左下角矩阵即可，因为 isConnected[i][j]==isConnected[j][i]。

## 题解(并查集)
并查集模板：add/merge/findAnc，遍历左下角矩阵合并连通节点，连通分量数即省份数。

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        UnionFind uf = new UnionFind();
        int n = isConnected.length;
        for (int i = 0; i < n; i++) {
            uf.add(i);
            for (int j = 0; j < i; j++) {
                if (isConnected[i][j] == 1) {
                    uf.merge(i, j);
                }
            }
        }
        return uf.getProvinces();
    }

    class UnionFind {
        Map<Integer, Integer> father;
        int numsOfProvince;

        public UnionFind() {
            this.father = new HashMap<>();
            this.numsOfProvince = 0;
        }

        public void add(int x) {
            if (!father.containsKey(x)) {
                father.put(x, null);
                numsOfProvince++;
            }
        }

        public void merge(int x, int y) {
            int rootX = findAnc(x);
            int rootY = findAnc(y);
            if (rootX != rootY) {
                father.put(rootX, rootY);
                numsOfProvince--;
            }
        }

        public int findAnc(int x) {
            int rootX = x;
            while (father.get(rootX) != null) {
                rootX = father.get(rootX);
            }
            while (father.get(x) != null) {
                int old_father = father.get(x);
                father.put(x, rootX);
                x = old_father;
            }
            return rootX;
        }

        public boolean isConnected(int x, int y) {
            return findAnc(x) == findAnc(y);
        }

        public int getProvinces() {
            return numsOfProvince;
        }
    }
}
```
