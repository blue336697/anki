# 对角线遍历

## 题干
给你一个大小为 m x n 的矩阵 mat，请以对角线遍历的顺序，用一个数组返回这个矩阵中的所有元素。
![image 5.png](image%205.png)

## 复杂度
时间：{{c1::O(mn)}} -- 每个元素访问一次
空间：{{c1::O(1)}} -- 除结果数组外

## 关键技巧
对角线遍历规律：
1. 对角线条数 = m + n（坐标和从 0 到 m+n-1）
2. 每条对角线上坐标和为定值 i，x 从大到小则 y 从小到大（或反过来）
3. 奇偶趟方向交替，用 bXFlag 标识
4. 起始坐标确定：x = min(i, pm-1)，y = i - x

## 题解(坐标和规律)
每条对角线坐标和为定值i，bXFlag交替方向，x从大到小则y从小到大。

```java
class Solution {
    public int[] findDiagonalOrder(int[][] matrix) {
        if (matrix == null || matrix.length == 0)
            return new int[0];
        int m = matrix.length;
        int n = matrix[0].length;
        int[] nums = new int[m * n];
        int k = 0;
        boolean bXFlag = true;
        for (int i = 0; i < m + n; i++) {
            int pm = bXFlag ? m : n;
            int pn = bXFlag ? n : m;
            int x = (i < pm) ? i : pm - 1;
            int y = i - x;
            while (x >= 0 && y < pn) {
                nums[k++] = bXFlag ? matrix[x][y]
                                     : matrix[y][x];
                x--;
                y++;
            }
            bXFlag = !bXFlag;
        }
        return nums;
    }
}
```
