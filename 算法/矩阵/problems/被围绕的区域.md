# 被围绕的区域

## 题干
给你一个 m x n 的矩阵 board，由若干字符 X 和 O 组成，捕获所有被围绕的区域：将矩阵中被 X 围绕的 O 替换为 X，边界上的 O 以及与边界 O 相连的 O 不被围绕。

## 复杂度
DFS：时间 {{c1::O(mn)}}，空间 {{c1::O(mn)}} -- 递归栈

## 关键技巧
逆向思维：与其找被围绕的 O，不如先标记所有与边界相连的 O（它们不会被围绕）。
三步走：
1. 从边界 O 出发 DFS，标记为中间符号 '*'
2. 遍历整个矩阵：剩余的 O -> X（被围绕），* -> O（还原）
核心：边界上的 O 及其相邻 O 永远不会被围绕，它们是与外界连通的"安全区"

## 题解(DFS+逆向思维)
逆向思维：从边界O出发DFS标记为'*'，剩余O->X被围绕，'*'->O还原。

```java
class Solution {
    public void solve(char[][] board) {
        int m = board.length;
        int n = board[0].length;
        // Start DFS from edge O, mark as '*'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                boolean isEdge = i == 0 || j == 0
                    || i == m - 1 || j == n - 1;
                if (isEdge && board[i][j] == 'O')
                    dfs(board, i, j);
            }
        }
        // Second pass: capture surrounded, restore safe
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                }
                if (board[i][j] == '*') {
                    board[i][j] = 'O';
                }
            }
        }
    }

    public void dfs(char[][] board, int i, int j) {
        if (i < 0 || j < 0 || i >= board.length
            || j >= board[0].length || board[i][j] == 'X'
            || board[i][j] == '*')
            return;
        board[i][j] = '*';
        dfs(board, i - 1, j);
        dfs(board, i + 1, j);
        dfs(board, i, j - 1);
        dfs(board, i, j + 1);
    }
}
```
