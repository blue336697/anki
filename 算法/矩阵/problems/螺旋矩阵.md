# 螺旋矩阵

## 题干
给你一个 m 行 n 列的矩阵 matrix，请按照顺时针螺旋顺序，返回矩阵中的所有元素。
![image.png](image.png)

## 复杂度
时间：{{c1::O(mn)}} -- 每个元素访问一次
空间：{{c1::O(1)}} -- 除结果列表外

## 关键技巧
边界收缩法：定义 up, under, left, right 四个边界指针。
每次完成一个方向的遍历后，立即收缩对应边界（如 ++up），并检查是否与对侧边界交叉。
关键：使用 ++up > under 而非 up++ > under，确保先收缩再判断。
同一模板稍作修改即可用于螺旋矩阵 II（填充数字）。

## 题解(边界收缩)
边界收缩法：右->下->左->上循环，每完成一个方向立即收缩对应边界并检查是否交叉。

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        if (matrix == null || matrix[0].length == 0)
            return null;
        List<Integer> list = new ArrayList<>();
        int up = 0;
        int under = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;
        while (true) {
            // Right
            for (int i = left; i <= right; i++)
                list.add(matrix[up][i]);
            if (++up > under)
                break;
            // Down
            for (int i = up; i <= under; i++)
                list.add(matrix[i][right]);
            if (--right < left)
                break;
            // Left
            for (int i = right; i >= left; i--)
                list.add(matrix[under][i]);
            if (--under < up)
                break;
            // Up
            for (int i = under; i >= up; i--)
                list.add(matrix[i][left]);
            if (++left > right)
                break;
        }
        return list;
    }
}
```
