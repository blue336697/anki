# 矩阵置零

## 题干
给定一个 m x n 的矩阵，如果一个元素为 0，则将其所在行和列的所有元素都设为 0。请使用原地算法。进阶：一个直观的解决方案是使用 O(mn) 的额外空间，一个简单的改进方案是使用 O(m+n) 的额外空间。你能想出一个仅使用常量空间的解决方案吗？

## 复杂度
O(1)空间：时间 {{c1::O(mn)}}，空间 {{c1::O(1)}}
O(m+n)空间：时间 {{c1::O(mn)}}，空间 {{c1::O(m+n)}}

## 关键技巧
O(1)空间的精髓：复用矩阵的第一行和第一列作为标记数组。
但第一行和第一列自身也可能有0，所以用 rowZero 和 colZero 两个布尔变量单独记录。
顺序很重要：先标记 -> 再置零（1..m, 1..n 区域）-> 最后处理第一行和第一列。

## 题解(O(1)空间)
O(1)空间：用第一行和第一列作为标志位，rowZero/colZero 单独记录第一行/列自身的0。

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean rowZero = false, colZero = false;
        // Mark if first column has zero
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0)
                colZero = true;
        }
        // Mark if first row has zero
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0)
                rowZero = true;
        }
        // Use first row/col as markers
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[0][j] = matrix[i][0] = 0;
                }
            }
        }
        // Set zeros based on markers
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        // Fill first row
        if (rowZero) {
            for (int j = 0; j < n; j++)
                matrix[0][j] = 0;
        }
        // Fill first column
        if (colZero) {
            for (int i = 0; i < m; i++)
                matrix[i][0] = 0;
        }
    }
}
```
