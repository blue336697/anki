# 字符串的排列

## 题干
给定两个字符串 s1 和 s2，写一个函数来判断 s2 是否包含 s1 的排列。即判断 s1 的排列之一是 s2 的子串。

## 指针策略
right移动：{{c1::加入新字符到窗口，更新 window 数组}}，匹配时 needCount++
left移动：{{c1::当窗口大小 right-left >= len1 时}}，收缩 left，移出字符更新 window
匹配条件：{{c1::needCount == pCount}}（窗口中每种字符数量都满足 needs）
关键：使用 needCount 记录已匹配的{{c1::字符种类数}}（而非字符个数）

## 复杂度
时间：{{c1::O(n)}} — 每个字符最多进出窗口各一次
空间：{{c1::O(26)}} — 两个 count 数组

## 题解(固定窗口)
固定窗口大小 = len1，直接滑动窗口比较两个词频数组是否相等。

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int len1 = s1.length();
        int len2 = s2.length();
        if (len1 > len2)
            return false;
        int[] targetCount1 = new int[26];
        int[] targetCount2 = new int[26];
        for (int i = 0; i < len1; i++) {
            targetCount1[s1.charAt(i) - 'a']++;
            targetCount2[s2.charAt(i) - 'a']++;
        }
        for (int i = len1; i < len2; i++) {
            if (Arrays.equals(targetCount1, targetCount2)) {
                return true;
            }
            targetCount2[s2.charAt(i) - 'a']++;
            targetCount2[s2.charAt(i - len1) - 'a']--;
        }
        return Arrays.equals(targetCount1, targetCount2);
    }
}
```

## 题解(可变窗口)
通用滑动窗口模板（与438题通用）：needCount 记录已匹配字符种类数，right 扩张直到窗口大小>=len1，收缩 left。

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int[] window = new int[26], needs = new int[26];
        int len1 = s1.length(), len2 = s2.length();
        for (int i = 0; i < len1; i++) {
            needs[s1.charAt(i) - 'a']++;
        }
        // s1中不同字符的种类数
        int pCount = 0;
        for (int i = 0; i < 26; i++) {
            if (needs[i] > 0) {
                pCount++;
            }
        }
        int left = 0, right = 0;
        int needCount = 0;
        while (right < len2) {
            char ch = s2.charAt(right);
            right++;
            if (needs[ch - 'a'] > 0) {
                window[ch - 'a']++;
                if (window[ch - 'a'] == needs[ch - 'a'])
                    needCount++;
            }
            while (right - left >= len1) {
                if (needCount == pCount)
                    return true;
                char remove = s2.charAt(left);
                left++;
                if (needs[remove - 'a'] > 0) {
                    if (window[remove - 'a'] == needs[remove - 'a'])
                        needCount--;
                    window[remove - 'a']--;
                }
            }
        }
        return false;
    }
}
```
