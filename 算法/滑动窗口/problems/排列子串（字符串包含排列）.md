# 排列子串（字符串包含排列）
<!-- anki-deck: 字符串的排列 -->

## 题干
给定两个仅由小写英文字母组成的字符串 `s1` 和 `s2`，判断 `s2` 是否包含 `s1` 的某个排列作为连续子串。

本题只返回布尔值，等价于判断 `s2` 是否存在一个长度为 `s1.length()`、字符频次与 `s1` 完全相同的窗口；它不是“枚举字符串的全部排列”。

## 指针策略
固定窗口长度：{{c1::s1.length()}}。
右边界每右移一步：{{c1::加入一个新字符，并移除窗口最左字符}}。
命中条件：{{c1::窗口的 26 个字符频次与 s1 完全相同}}。

因为排列只改变字符顺序，不改变字符频次，所以无需生成任何排列。

## 复杂度
时间：{{c1::O(|s1| + 26 · |s2|)}}，字母表固定时记作 O(|s1| + |s2|)。
空间：{{c1::O(26)}}，固定小写字母表下记作 O(1)。

## 题解(固定窗口)
先统计 `s1` 和 `s2` 首个等长窗口的频次；此后每次加入右侧字符、移除左侧字符，再比较两个长度为 26 的频次数组。

```java
import java.util.Arrays;

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int windowSize = s1.length();
        if (windowSize > s2.length()) {
            return false;
        }

        int[] target = new int[26];
        int[] window = new int[26];
        for (int i = 0; i < windowSize; i++) {
            target[s1.charAt(i) - 'a']++;
            window[s2.charAt(i) - 'a']++;
        }

        if (Arrays.equals(target, window)) {
            return true;
        }
        for (int right = windowSize; right < s2.length(); right++) {
            window[s2.charAt(right) - 'a']++;
            window[s2.charAt(right - windowSize) - 'a']--;
            if (Arrays.equals(target, window)) {
                return true;
            }
        }
        return false;
    }
}
```

## 题解(差分计数)
用一个 `diff[26]` 记录“当前窗口频次减去目标频次”，再用 `nonZero` 记录其中非零项数量。窗口命中当且仅当 `nonZero == 0`，这样每次移动只更新两个字符，不必扫描 26 个槽位。

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int windowSize = s1.length();
        if (windowSize > s2.length()) {
            return false;
        }

        int[] diff = new int[26];
        for (int i = 0; i < windowSize; i++) {
            diff[s2.charAt(i) - 'a']++;
            diff[s1.charAt(i) - 'a']--;
        }

        int nonZero = 0;
        for (int count : diff) {
            if (count != 0) {
                nonZero++;
            }
        }
        if (nonZero == 0) {
            return true;
        }

        for (int right = windowSize; right < s2.length(); right++) {
            int add = s2.charAt(right) - 'a';
            int remove = s2.charAt(right - windowSize) - 'a';

            if (diff[add] == 0) nonZero++;
            diff[add]++;
            if (diff[add] == 0) nonZero--;

            if (diff[remove] == 0) nonZero++;
            diff[remove]--;
            if (diff[remove] == 0) nonZero--;

            if (nonZero == 0) {
                return true;
            }
        }
        return false;
    }
}
```
