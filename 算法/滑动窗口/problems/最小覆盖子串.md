# 最小覆盖子串

## 题干
给定字符串 s 和 t，在 s 中找出包含 t 所有字符的最小子串。如果不存在则返回空字符串。
![image.png](image.png)

## 指针策略
right移动：{{c1::每次循环 right++，加入新字符}}
left移动：{{c1::当 count==0（窗口已满足）时，while need[s[left]] < 0 收缩 left}}
need数组：正数={{c1::还需要}}，0={{c1::刚好满足}}，负数={{c1::多余}}

## 复杂度
时间：{{c1::O(m+n)}} — 每个字符被 left 和 right 各访问一次
空间：{{c1::O(128)}} — need 数组，常数级

## 题解(滑动窗口)
用 need 数组计数，right 扩张时 count--，count=0 时收缩 left 过滤多余字符，更新最小窗口。

```java
class Solution {
    public String minWindow(String s, String t) {
        // need数组: 正数=还需要, 负数=多余
        int[] need = new int[128];
        for (int i = 0; i < t.length(); i++) {
            need[t.charAt(i)]++;
        }
        int left = 0, right = 0, size = Integer.MAX_VALUE, count = t.length(), start = 0;
        while (right < s.length()) {
            char c = s.charAt(right);
            if (need[c] > 0) {
                count--;
            }
            need[c]--;
            if (count == 0) {
                // 收缩左边界，过滤多余字符
                while (left < right && need[s.charAt(left)] < 0) {
                    need[s.charAt(left)]++;
                    left++;
                }
                if (right - left + 1 < size) {
                    size = right - left + 1;
                    start = left;
                }
                // 移动左边界，寻找下一个满足条件的窗口
                need[s.charAt(left)]++;
                left++;
                count++;
            }
            right++;
        }
        return size == Integer.MAX_VALUE ? "" : s.substring(start, start + size);
    }
}
```
