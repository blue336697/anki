# 时间窗口请求统计（计数与峰值）
<!-- aliases: 最近时间窗口请求计数, 最近时间窗口请求峰值 -->
<!-- tags: source::字节 variant::工程滑动窗口 -->

## 题干
时间窗口请求统计有两个常见接口：

1. 在线计数器：`hit(timestamp)` 记录请求，`getHits(timestamp)` 返回最近 300 秒内的请求数；时间戳保证单调不减
2. 离线峰值：给定一批请求时间戳和窗口长度 `window`，求任意该长度窗口内最多包含多少次请求

二者共享“时间右边界单调推进、左侧过期数据永久无用”的滑动窗口性质，但一个维护在线状态，一个在排序后用双指针求全局最大值。

## 窗口边界
在线 300 秒窗口定义为：

`{{c1::(timestamp - 300, timestamp]}}`

因此时间戳 `<= timestamp - 300` 的请求已经过期，恰好发生在右边界 timestamp 的请求仍计入。

若时间戳以整数秒表示、离线窗口覆盖连续 `window` 个整数秒，则以 `times[right]` 为右端时，合法时间差满足：

`times[right] - times[left] < {{c1::window}}`

所以收缩条件为 `>= window`。

## 在线队列状态
时间戳单调不减时，队首永远是最早请求，可以不断弹出过期项。

直接为每个请求保存一个时间戳，在单秒突发流量很高时会浪费空间。可把相同时间戳压缩成 `[timestamp,count]` 桶，并额外维护窗口内总数：

- `hit` 遇到相同时间戳只增加末尾桶计数
- `getHits` 弹出过期桶，并从 total 中减去整桶计数

每个时间桶至多入队出队一次，因此操作是均摊 O(1)。

## 离线双指针状态
若输入未排序，先排序副本。`right` 依次作为窗口最晚请求；当时间跨度达到或超过 window 时右移 `left`，直到窗口恢复合法。

每次合法后用 `right-left+1` 更新峰值。两个指针都只向右移动。

## 复杂度
在线计数器：

- `hit` 均摊 O(1)，`getHits` 均摊 O(1)
- 空间 O(b)，b 为最近 300 秒内不同时间戳桶数，且 b 不超过 300（整数秒口径）

离线峰值：

- 未排序输入：排序 O(n log n)，双指针 O(n)；若已排序则总时间 O(n)
- 排序副本空间 O(n)；若允许原地排序，双指针额外空间 O(1)

## 题解(在线压缩队列)
```java
import java.util.ArrayDeque;
import java.util.Deque;

class HitCounter {
    private static final int WINDOW_SECONDS = 300;
    private final Deque<int[]> buckets = new ArrayDeque<>();
    private int total;

    public void hit(int timestamp) {
        if (!buckets.isEmpty() && buckets.peekLast()[0] == timestamp) {
            buckets.peekLast()[1]++;
        } else {
            buckets.offerLast(new int[] {timestamp, 1});
        }
        total++;
    }

    public int getHits(int timestamp) {
        int expiredAtOrBefore = timestamp - WINDOW_SECONDS;
        while (!buckets.isEmpty() && buckets.peekFirst()[0] <= expiredAtOrBefore) {
            total -= buckets.pollFirst()[1];
        }
        return total;
    }
}
```

## 题解(离线排序+双指针)
```java
import java.util.Arrays;

class Solution {
    public int maxRequestsInWindow(int[] times, int window) {
        if (window <= 0) {
            throw new IllegalArgumentException("window must be positive");
        }

        int[] sorted = times.clone();
        Arrays.sort(sorted);
        int left = 0;
        int maximum = 0;

        for (int right = 0; right < sorted.length; right++) {
            while ((long) sorted[right] - sorted[left] >= window) {
                left++;
            }
            maximum = Math.max(maximum, right - left + 1);
        }
        return maximum;
    }
}
```

## 工程边界
该队列方案依赖单机内时间戳单调不减。真实分布式请求统计还要处理：

- 乱序和迟到事件：需要 watermark、允许迟到窗口或按事件时间重排
- 多实例聚合：需要分桶后汇总，不能只看单进程内存
- 进程重启和水平扩容：需要外部状态或可重放日志
- 超高精度窗口：可用固定环形桶降低对象数量，但会引入桶粒度误差

这些是工程实现边界，不改变面试算法题中的单调时间假设。
