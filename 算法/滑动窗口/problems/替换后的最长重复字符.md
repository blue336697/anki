# 替换后的最长重复字符
<!-- tags: source::字节 pattern::可变滑动窗口 -->

## 题干
给定只包含大写英文字母的字符串 `s` 和非负整数 `k`。最多可以把 k 个字符替换成任意大写字母，求能够得到的最长全相同字符子串长度。

## 指针策略
设窗口长度为 `windowLength`，窗口内最高字符频次为 `maxFrequency`。

把窗口全部变成同一个字符所需的最少替换次数为：

`{{c1::windowLength - maxFrequency}}`

`right` 每加入一个字符就更新频次与 `maxFrequency`；当所需替换次数 `> k` 时，右移 `left` 并移除左端字符。

## maxFrequency 为什么可以不回退
代码维护的是扫描历史中出现过的窗口最高频次上界，而不是每次收缩后重新计算当前窗口最高频次。

旧的较大 `maxFrequency` 可能让当前窗口暂时看似合法，但不会制造更大的错误答案：只有当窗口长度超过历史答案时才可能更新，而要达到该长度，历史上已经存在一个拥有相应 `maxFrequency`、可用 k 次替换完成的窗口。

这种优化只适用于“求最大长度”。如果题目要求返回当前合法窗口的具体边界或内容，应重新计算真实最高频次或维护更严格的数据结构。

## 复杂度
时间：{{c1::O(n)}} — right 扫描 n 次，left 最多再移动 n 次，每次只做固定 26 字母表操作。
空间：{{c1::O(1)}} — 长度 26 的频次数组。

## 题解(滑动窗口)
```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] frequency = new int[26];
        int left = 0;
        int maxFrequency = 0;
        int answer = 0;

        for (int right = 0; right < s.length(); right++) {
            int added = s.charAt(right) - 'A';
            maxFrequency = Math.max(maxFrequency, ++frequency[added]);

            while (right - left + 1 - maxFrequency > k) {
                frequency[s.charAt(left) - 'A']--;
                left++;
            }
            answer = Math.max(answer, right - left + 1);
        }
        return answer;
    }
}
```
