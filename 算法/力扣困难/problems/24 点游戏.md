# 24 点游戏

## 题干
给定一个长度为4的整数数组 cards，判断是否能通过加、减、乘、除（可加括号）运算得到 24。除法运算为实数除法。
![image 11.png](image%2011.png)

## 复杂度
时间：{{c1::O(1)}} — 固定4张牌，有限组合
空间：{{c1::O(1)}} — 递归栈深固定

## 关键技巧
回溯核心思想：
1. 每次从数组中选两个不同的数，用四种运算符组合出一个新数
2. 新数放在 x 位置，删除 y 位置，数组长度减1
3. 递归直到数组长度为1，判断是否等于24
4. 关键：无需考虑括号 — 任选两数运算自然覆盖了所有括号组合
5. 精度陷阱：浮点运算用绝对值范围判断，除数为0要跳过

## 题解(回溯)
精度判断：用 23.999~24.001 范围代替 ==24。每次选两个数运算后数组缩减1。

```java
class Solution {
    public boolean judgePoint24(int[] nums) {
        double[] doubles = Arrays.stream(nums).asDoubleStream().toArray();
        return judgePoint24(doubles);
    }
    public boolean judgePoint24(double[] nums) {
        if (nums.length == 1) {
            return nums[0] > 23.999 && nums[0] < 24.001;
        }
        for (int x = 0; x < nums.length - 1; x++) {
            for (int y = x + 1; y < nums.length; y++) {
                boolean isValid = false;
                double[] temp = new double[nums.length - 1];
                System.arraycopy(nums, 0, temp, 0, y);
                System.arraycopy(nums, y + 1, temp, y, temp.length - y);
                temp[x] = nums[x] + nums[y];
                isValid = isValid || judgePoint24(temp);
                temp[x] = nums[x] - nums[y];
                isValid = isValid || judgePoint24(temp);
                temp[x] = nums[y] - nums[x];
                isValid = isValid || judgePoint24(temp);
                temp[x] = nums[x] * nums[y];
                isValid = isValid || judgePoint24(temp);
                if (nums[y] != 0) {
                    temp[x] = nums[x] / nums[y];
                    isValid = isValid || judgePoint24(temp);
                }
                if (nums[x] != 0) {
                    temp[x] = nums[y] / nums[x];
                    isValid = isValid || judgePoint24(temp);
                }
                if (isValid) {
                    return true;
                }
            }
        }
        return false;
    }
}
```
