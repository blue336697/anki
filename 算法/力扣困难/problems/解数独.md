# 解数独

## 题干
编写一个程序，通过填充空格来解决数独问题。数独的解法需遵循如下规则：
1. 数字 1-9 在每一行只能出现一次
2. 数字 1-9 在每一列只能出现一次
3. 数字 1-9 在每一个以粗实线分隔的 3x3 宫内只能出现一次
数独部分空格已填有数字，空白格用 "." 表示。
![image 23.png](image%2023.png)

## 复杂度
时间：最坏 {{c1::O(9^(n*n))}}，实际远小于此（剪枝有效）
空间：{{c1::O(1)}} — 原地修改board

## 关键技巧
与N皇后的区别：
1. 需要遍历所有空格（双重for），而非逐行放置
2. 三维剪枝：行、列、3x3宫格三个维度排除已用数字
3. 宫格起点计算：startRow = (row/3)*3，startCol = (col/3)*3
4. 贪心选择：优先填充可能性最少的格子可加速
5. 一旦找到解立即返回 true，利用短路效应剪枝

## 题解(DFS+回溯+三维剪枝)
三维剪枝：行、列、3x3宫格三个维度排除已用数字。宫格起点=(row/3)*3, (col/3)*3。

```java
class Solution {
    public void solveSudoku(char[][] board) {
        dfs(board);
    }
    public boolean dfs(char[][] board){
        for(int i = 0; i < board.length; i++){
            for(int j = 0; j < board[0].length; j++){
                if(board[i][j] != '.')
                    continue;
                for(char k = '1'; k <= '9'; k++){
                    if(isVaild(i, j, k, board)){
                        board[i][j] = k;
                        if(dfs(board))
                            return true;
                        board[i][j] = '.';
                    }
                }
                return false;
            }
        }
        return true;
    }
    public boolean isVaild(int row, int col, char val, char[][] board){
        for (int i = 0; i < 9; i++){
            if (board[row][i] == val){
                return false;
            }
        }
        for (int j = 0; j < 9; j++){
            if (board[j][col] == val){
                return false;
            }
        }
        int startRow = (row / 3) * 3;
        int startCol = (col / 3) * 3;
        for (int i = startRow; i < startRow + 3; i++){
            for (int j = startCol; j < startCol + 3; j++){
                if (board[i][j] == val){
                    return false;
                }
            }
        }
        return true;
    }
}
```
