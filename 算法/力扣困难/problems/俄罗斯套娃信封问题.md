# 俄罗斯套娃信封问题

## 题干
给你一个二维整数数组 envelopes，其中 envelopes[i] = [wi, hi]，表示第 i 个信封的宽度和高度。当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里。请计算最多能有多少个信封能组成一组"俄罗斯套娃"信封。

## 复杂度
时间：{{c1::O(n log n)}} — 排序+二分LIS
空间：{{c1::O(n)}} — top数组

## 关键技巧
二维LIS问题的转化：
1. 排序规则：宽度升序；宽度相同时，高度降序
2. 高度降序的意义：宽度相同的信封不能嵌套，降序保证同宽度的不会被选入LIS
3. 对高度数组求最长递增子序列（LIS），用二分法（扑克牌堆）O(n log n)
4. LIS二分法：top[]数组维护各堆堆顶，二分查找插入位置
5. 若 top[mid] >= poker → right=mid；否则 left=mid+1

## 题解(排序+二分LIS)
宽度升序、同宽高度降序后，对高度数组求LIS（二分扑克牌堆法）。宽度相同时高度降序防止同宽嵌套。

```java
class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        int n = envelopes.length;
        if(n < 2){
            return n;
        }
        Arrays.sort(envelopes, (a, b)->{
            if(a[0] == b[0])
                return b[1] - a[1];
            return a[0] - b[0];
        });
        int[] height = new int[n];
        for (int i = 0; i < n; i++)
            height[i] = envelopes[i][1];
        int piles = 0;
        int[] top = new int[n];
        for (int i = 0; i < n; i++) {
            int poker = height[i];
            int left = 0, right = piles;
            while (left < right) {
                int mid = (left + right) / 2;
                if (top[mid] >= poker)
                    right = mid;
                else
                    left = mid + 1;
            }
            if (left == piles) piles++;
            top[left] = poker;
        }
        return piles;
    }
}
```
