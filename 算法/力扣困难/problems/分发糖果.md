# 分发糖果

## 题干
n 个孩子站成一排，给你一个整数数组 ratings 表示每个孩子的评分。你需要按照以下要求给这些孩子分发糖果：
1. 每个孩子至少分配到 1 个糖果
2. 相邻两个孩子中评分高的必须获得更多的糖果
请你计算最少需要准备多少颗糖果。

## 复杂度
时间：{{c1::O(n)}} — 两次遍历
空间：{{c1::O(n)}} — dp 数组

## 关键技巧
贪心两遍扫描：
第一遍（左→右）：只处理左边邻居，保证比左边高的孩子多拿糖。
第二遍（右→左）：处理右边邻居，用 Math.max 避免覆盖第一遍已确定的更优值。
两遍可以交换顺序，但后面的遍历必须用前面的结果取 max 优化最终结果。

## 题解(贪心-两遍遍历)
贪心两遍扫描：左→右处理左边邻居，右→左用 Math.max 处理右边邻居。

```java
class Solution {
    public int candy(int[] ratings) {
        int len = ratings.length;
        if(len == 0)
            return 0;
        int[] dp = new int[len];
        Arrays.fill(dp, 1);
        for(int i = 1; i < len; i++){
            if(ratings[i] > ratings[i-1])
                dp[i] = dp[i-1] + 1;
        }
        for(int i = len - 2; i >= 0; i--){
            if(ratings[i] > ratings[i+1])
                dp[i] = Math.max(dp[i], dp[i+1] + 1);
        }
        int res = 0;
        for(int nums : dp)
            res += nums;
        return res;
    }
}
```
