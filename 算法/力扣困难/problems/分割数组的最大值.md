# 分割数组的最大值

## 题干
给定一个非负整数数组 nums 和一个整数 m，你需要将这个数组分成 m 个非空的连续子数组。设计一个算法使得这 m 个子数组各自和的最大值最小。
![image 24.png](image%2024.png)

## 复杂度
二分法：时间 {{c1::O(n*log(sum))}}，空间 {{c1::O(1)}}
DP法：时间 {{c1::O(n²*m)}}，空间 {{c1::O(n*m)}}

## 关键技巧
二分答案 + 贪心验证：
1. 答案具有二段性：若最大和为 X 时能分成 <=m 段，则更大的X也能
2. 下界 left = max(nums)（至少一段包含最大元素），上界 right = sum(nums)
3. split 函数贪心分割：当前和+num>mid时另起一段，段数+1
4. 分裂数 > m → mid太小，left=mid+1；否则 right=mid
5. DP法（O(n²*m)）适合理解，二分法才是最优解

## 题解(二分查找)
二分"子数组和的最大值"，贪心验证分割数。下界=max(nums)，上界=sum(nums)。

```java
public class Solution {
    public int splitArray(int[] nums, int m) {
        int max = 0;
        int sum = 0;
        for (int num : nums) {
            max = Math.max(max, num);
            sum += num;
        }
        int left = max;
        int right = sum;
        while (left < right) {
            int mid = left + (right - left) / 2;
            int splits = split(nums, mid);
            if (splits > m) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
    private int split(int[] nums, int maxIntervalSum) {
        int splits = 1;
        int curIntervalSum = 0;
        for (int num : nums) {
            if (curIntervalSum + num > maxIntervalSum) {
                curIntervalSum = 0;
                splits++;
            }
            curIntervalSum += num;
        }
        return splits;
    }
}
```
