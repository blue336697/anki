# 二维接雨水

## 题干
给定一个 `m × n` 的非负整数高度矩阵 `heightMap`，每个格子表示地形高度。下雨后水可以从矩阵外边界流走，求整个二维地形最多能蓄多少水。

与一维接雨水不同，一个格子的水可能从四个方向中的任意路径泄漏，不能只预计算上下左右四个方向的单独最大值。

## 核心模型
所有外圈格子都是初始泄水边界。维护当前未扩展边界中的最低格子：

1. 从最低边界向内访问相邻格子
2. 若邻居地面低于当前边界，二者高度差就是该邻居能蓄的水
3. 邻居加入新边界时的有效高度为 `max(邻居地面高度, 当前边界高度)`

小根堆保证每次扩展的是{{c1::全局最低的当前边界}}，这与 Dijkstra 每次确定最小距离节点的思路相同。

## 为什么入堆高度取 max
设当前边界有效高度为 `boundary`，邻居地面高度为 `ground`：

- 若 `ground < boundary`，邻居会蓄到 boundary，高度差计入答案；之后它的“地面 + 水面”有效高度是 boundary
- 若 `ground >= boundary`，邻居自身成为更高的新边界，有效高度是 ground

两种情况统一为：

`effectiveHeight = {{c1::max(boundary, ground)}}`

如果错误地把原始 `ground` 入堆，低洼格子会被当作新的泄水口，后续区域的水位被低估。

## visited 的时机
一个格子第一次从某个已确定的最低边界被发现时，就已经得到其最小可能有效边界高度，因此应在{{c1::入堆时}}标记 visited。

若等到出堆才标记，同一格子可能被多个邻居重复入堆、重复计水。

## 初始化边界
把四条外边界全部加入小根堆。左右两列包含四个角；再加入上下两行时只遍历列 `1..n-2`，避免角点重复入堆。

若 `m < 3` 或 `n < 3`，不存在被四周包围的内部格子，答案为 0。

## 正确性不变量
当格子从小根堆弹出时，它的 `height` 是从该格子通向矩阵外部的所有路径中，最小可能的“路径最高边界”，也就是该位置不会泄漏的最低水面上限。

由于堆总先处理最低边界，未来尚未处理的边界只会更高，不可能再给已访问格子提供更低的泄水通道。因此当前计水结果不会被之后的搜索推翻。

## 复杂度
每个格子至多入堆、出堆一次。
时间：{{c1::O(mn log(mn))}}。
空间：{{c1::O(mn)}} — visited 与优先队列。

## 题解(最小堆+边界扩张)
```java
import java.util.Comparator;
import java.util.PriorityQueue;

class Solution {
    private static final int[][] DIRECTIONS = {
        {1, 0}, {-1, 0}, {0, 1}, {0, -1}
    };

    public int trapRainWater(int[][] heightMap) {
        int rows = heightMap.length;
        int columns = heightMap[0].length;
        if (rows < 3 || columns < 3) {
            return 0;
        }

        boolean[][] visited = new boolean[rows][columns];
        PriorityQueue<Cell> boundary =
                new PriorityQueue<>(Comparator.comparingInt(cell -> cell.height));

        for (int row = 0; row < rows; row++) {
            offer(heightMap, visited, boundary, row, 0);
            offer(heightMap, visited, boundary, row, columns - 1);
        }
        for (int column = 1; column < columns - 1; column++) {
            offer(heightMap, visited, boundary, 0, column);
            offer(heightMap, visited, boundary, rows - 1, column);
        }

        int water = 0;
        while (!boundary.isEmpty()) {
            Cell current = boundary.poll();
            for (int[] direction : DIRECTIONS) {
                int nextRow = current.row + direction[0];
                int nextColumn = current.column + direction[1];
                if (nextRow < 0 || nextRow >= rows
                        || nextColumn < 0 || nextColumn >= columns
                        || visited[nextRow][nextColumn]) {
                    continue;
                }

                visited[nextRow][nextColumn] = true;
                int ground = heightMap[nextRow][nextColumn];
                water += Math.max(0, current.height - ground);
                boundary.offer(new Cell(
                        nextRow,
                        nextColumn,
                        Math.max(current.height, ground)));
            }
        }
        return water;
    }

    private void offer(
            int[][] heightMap,
            boolean[][] visited,
            PriorityQueue<Cell> boundary,
            int row,
            int column) {
        visited[row][column] = true;
        boundary.offer(new Cell(row, column, heightMap[row][column]));
    }

    private static class Cell {
        private final int row;
        private final int column;
        private final int height;

        private Cell(int row, int column, int height) {
            this.row = row;
            this.column = column;
            this.height = height;
        }
    }
}
```
