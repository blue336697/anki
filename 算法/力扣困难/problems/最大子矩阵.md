# 最大子矩阵

## 题干
给定一个正整数、负整数和 0 组成的 N × M 矩阵，编写代码找出元素总和最大的子矩阵。返回一个数组 [r1, c1, r2, c2]，其中 r1, c1 分别代表子矩阵左上角的行号和列号，r2, c2 分别代表右下角的行号和列号。若有多个满足条件的子矩阵，返回任意一个均可。

## 复杂度
时间：{{c1::O(n²*m)}} — 枚举上下边界+一维Kadane
空间：{{c1::O(m)}} — sumCol数组+常数

## 关键技巧
二维最大子矩阵 = 枚举上下边界 + 一维最大子数组（Kadane算法变形）。
关键步骤：
1. sumCol[z] 记录第z列在行i到行j之间的累加和
2. 内层对sumCol用Kadane算法，找最大子数组和及其起止位置
3. 每次更新最大值时同时记录左上角(row=i, col=leftCol)和右下角(row=j, col=z)
4. 注意 sum<=0 时重新自立门户，记录新的左上角起始位置

## 题解(前缀和+Kadane)
纵向压缩：枚举上下行i~j，将列累加成一维数组sumCol，再用Kadane求最大子数组和及其起止位置。

```java
class Solution {
    public int[] getMaxMatrix(int[][] matrix) {
        int[] res = new int[4];
        int n = matrix.length;
        int m = matrix[0].length;
        int[] sumCol = new int[m];
        int sum;
        int maxsum = Integer.MIN_VALUE;
        int leftRowNum = 0, leftColNum = 0;
        for(int i = 0; i < n; i++){
            for(int k = 0; k < m; k++)
                sumCol[k] = 0;
            for(int j = i; j < n; j++){
                sum = 0;
                for(int z = 0; z < m; z++){
                    sumCol[z] += matrix[j][z];
                    if(sum > 0)
                        sum += sumCol[z];
                    else{
                        sum = sumCol[z];
                        leftRowNum = i;
                        leftColNum = z;
                    }
                    if(sum > maxsum){
                        maxsum = sum;
                        res[0] = leftRowNum;
                        res[1] = leftColNum;
                        res[2] = j;
                        res[3] = z;
                    }
                }
            }
        }
        return res;
    }
}
```
