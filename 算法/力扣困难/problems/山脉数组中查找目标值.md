# 山脉数组中查找目标值

## 题干
给你一个山脉数组 mountainArr，返回使得 mountainArr.get(index) 等于 target 的最小下标。如果不存在这样的下标，返回 -1。
山脉数组：先严格递增后严格递减的数组（长度>=3），只有一个峰顶。

## 复杂度
时间：{{c1::O(log n)}} — 三次二分查找
空间：{{c1::O(1)}}

## 关键技巧
三步二分：
1. 找峰顶：mid > mid+1 → 峰顶在左（含mid），否则峰顶在右（不含mid）
2. 升序区二分：target < mid → right=mid-1，否则 left=mid
3. 降序区二分：target < mid → left=mid-1（降序，小数在右），否则 right=mid
核心：将山脉数组分为两段有序数组，分别二分查找。总复杂度 O(log n)。

## 题解(三次二分)
三步二分：1.找峰顶 2.升序区二分 3.降序区二分。找峰顶：mid>mid+1→峰顶在左（含mid），否则在右。

```java
class Solution {
    public int findInMountainArray(int target, MountainArray m) {
        int len = m.length();
        if(len < 3)
            return -1;
        int topIndex = findTop(m, 0, len - 1);
        int addIndex = findAdd(m, 0, topIndex, target);
        if(addIndex != -1)
            return addIndex;
        int reduceIndex = findReduce(m, topIndex + 1, len - 1, target);
        return reduceIndex;
    }
    public int findAdd(MountainArray m, int i, int j, int target){
        int left = i, right = j;
        while(left < right){
            int mid = (left + right) / 2;
            if(target < m.get(mid))
                right = mid - 1;
            else
                left = mid;
        }
        return m.get(left) == target ? left : -1;
    }
    public int findReduce(MountainArray m, int i, int j, int target){
        int left = i, right = j;
        while(left < right){
            int mid = (left + right) / 2;
            if(target < m.get(mid))
                left = mid - 1;
            else
                right = mid;
        }
        return m.get(left) == target ? left : -1;
    }
    public int findTop(MountainArray m, int i, int j){
        while(i < j){
            int mid = (i + j) / 2;
            if(m.get(mid) > m.get(mid + 1))
                j = mid;
            else
                i = mid + 1;
        }
        return i;
    }
}
```
