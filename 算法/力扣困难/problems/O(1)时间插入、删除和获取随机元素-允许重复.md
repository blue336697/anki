# O(1)时间插入、删除和获取随机元素-允许重复

## 题干
RandomizedCollection 是一种包含数字集合的数据结构，支持重复元素。
实现以下功能，每个函数的平均时间复杂度为 O(1)：
insert(val)：向集合中插入 val（允许重复）
remove(val)：从集合中移除一个 val（如果有多个，只移除一个）
getRandom()：从当前集合中随机获取一个数字

## 复杂度
insert：{{c1::O(1)}}，remove：{{c1::O(1)}}，getRandom：{{c1::O(1)}}
空间：{{c1::O(n)}} — 数组+HashMap

## 关键技巧
数据结构设计题的关键思想：
1. 数组保证 O(1) 随机访问（getRandom用随机下标）
2. HashMap保证 O(1) 查找（val→索引集合，Set处理重复元素）
3. 删除技巧：将要删除的元素与数组末尾交换，再删除末尾（O(1)而非O(n)）
4. 难点：删除后需更新被移动元素的索引映射，否则查找会出错
5. 与不重复版本的区别：不重复版用 Map<Integer,Integer>；重复版用 Map<Integer,Set<Integer>>

## 题解(HashMap+Array)
数组保证O(1)随机访问，HashMap(val→索引Set)保证O(1)查找。删除时与末尾交换再删末尾。

```java
public class RandomizedCollection {
    Map<Integer, Set<Integer>> map;
    int[] arr;
    int size;
    public RandomizedCollection() {
        map = new HashMap<>();
        arr = new int[20000];
        size = 0;
    }
    public boolean insert(int val) {
        arr[size++] = val;
        Set<Integer> indexs = map.getOrDefault(val, new HashSet<>());
        boolean result = indexs.isEmpty();
        indexs.add(size-1);
        map.put(val, indexs);
        return result;
    }
    public boolean remove(int val) {
        Set<Integer> indexs = map.getOrDefault(val, new HashSet<>());
        boolean result = indexs.isEmpty();
        if(!result){
            int maxIndex = Integer.MIN_VALUE;
            for(int index : indexs){
                maxIndex = Math.max(maxIndex, index);
            }
            indexs.remove(maxIndex);
            if(indexs.size() == 0)
                map.remove(val);
            else
                map.put(val, indexs);
            System.arraycopy(arr, maxIndex + 1, arr, maxIndex, size - maxIndex + 1);
            size--;
            if(size != maxIndex)
                adjustMap(maxIndex);
            return true;
        }else
            return false;
    }
    public int getRandom() {
        int random = (int)(Math.random() * size);
        return arr[random];
    }
    public void adjustMap(int index){
        int pre = Integer.MIN_VALUE;
        for (int i = index; i < size; i++) {
            if(pre == arr[i])
                continue;
            Set<Integer> integers = map.get(arr[i]);
            Set<Integer> newIndexs = new HashSet<>();
            for (Integer integer : integers) {
                if(integer > index)
                    newIndexs.add(integer-1);
                else
                    newIndexs.add(integer);
            }
            map.put(arr[i], newIndexs);
            pre = arr[i];
        }
    }
}
```
