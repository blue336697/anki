# 矩阵中的最长递增路径

## 题干
给定一个 m x n 整数矩阵 matrix，找出其中最长递增路径的长度。对于每个单元格，你可以往上、下、左、右四个方向移动。不能在对角线方向上移动，也不能移动到边界外。

## 复杂度
时间：{{c1::O(m*n)}} — 每个格子只计算一次（记忆化）
空间：{{c1::O(m*n)}} — visited 数组

## 关键技巧
核心：DFS + 记忆化搜索(memoization)，每个格子计算后存入 visited 数组。
visited[i][j] 表示以(i,j)为起点的最长递增路径长度。
关键条件：matrix[i][j] <= preVal 时剪枝（非严格递增直接返回0）。
四个方向取最大值 + 1，记忆化保证每个格子只算一次。

## 题解(DFS+记忆化)
DFS + 记忆化搜索，preVal 记录上一步的值，只有严格递增 matrix[i][j] > preVal 才继续搜索。

```java
class Solution {
    int[][] visited;
    int n, m;
    public int longestIncreasingPath(int[][] matrix) {
        int maxRes = 0;
        n = matrix.length;
        m = matrix[0].length;
        visited = new int[n][m];
        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){
                maxRes = Math.max(maxRes, dfs(matrix, i, j, Integer.MIN_VALUE));
            }
        }
        return maxRes;
    }

    public int dfs(int[][] matrix, int i, int j, int preTemp){
        if(i >= n || j >= m || i <0 || j < 0)
            return 0;
        if(matrix[i][j] <= preTemp)
            return 0;
        if(visited[i][j] > 0)
            return visited[i][j];
        int under = dfs(matrix, i + 1, j, matrix[i][j]);
        int top = dfs(matrix, i - 1, j, matrix[i][j]);
        int left = dfs(matrix, i, j - 1, matrix[i][j]);
        int right = dfs(matrix, i, j + 1, matrix[i][j]);
        visited[i][j] = Math.max(Math.max(under, top), Math.max(left, right)) + 1;
        return visited[i][j];
    }
}
```
