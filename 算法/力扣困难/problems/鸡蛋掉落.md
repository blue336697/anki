# 鸡蛋掉落

## 题干
给你 k 枚相同的鸡蛋，和一栋从第 1 层到第 n 层共有 n 层楼的建筑。已知存在楼层 f ，满足 0 <= f <= n ，任何从高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会碎。每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 x 扔下。请你计算并返回要确定 f 确切的值的最小操作次数是多少？

## 题解(数学法)
calcF(K,T)表示K个蛋T次操作最多能确定的楼层数。碎+K-1,T-1；不碎+K,T-1。

```java
class Solution {
    public int superEggDrop(int k, int n) {
        int T = 1;
        while (calcF(k, T) < n + 1)
            T++;
        return T;
    }
    public int calcF(int K, int T){
        if (T == 1 || K == 1)
            return T + 1;
        return calcF(K - 1, T - 1) + calcF(K, T - 1);
    }
}
```

## 题解(DP)
dp[k][m]表示k个蛋m次操作最多能确定的楼层数，达到N时返回m。

```java
class Solution {
    public int superEggDrop(int K, int N) {
        int[][] dp = new int[K + 1][N + 1];
        for (int m = 1; m <= N; m++) {
            dp[0][m] = 0;
            for (int k = 1; k <= K; k++) {
                dp[k][m] = dp[k][m - 1] + dp[k - 1][m - 1] + 1;
                if (dp[k][m] >= N) {
                    return m;
                }
            }
        }
        return N;
    }
}
```

## 复杂度-数学法
calcF(K,T) 递归：时间 {{c1::O(K*T)}}（T为结果值）
DP法：时间 {{c1::O(K*N)}} 或提前退出
空间：数学法 {{c1::O(1)}} 或 DP法 {{c1::O(K*N)}}
