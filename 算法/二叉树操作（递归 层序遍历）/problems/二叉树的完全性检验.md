# 二叉树的完全性检验

## 题干
给定二叉树根节点，判断它是否是一棵完全二叉树。完全二叉树要求除最后一层外全满，最后一层节点从左到右连续。

**完全二叉树就是最下面两层的节点度数可以小于2，并且最下面一层的叶子结点都依次排序在该层的最左侧的位置上**

## 遍历策略
BFS 判空洞：层序遍历中，一旦遇到 null，后续就不能再遇到非 null 节点；否则说明节点不是从左到右连续填充。

## 复杂度
时间 O(n)：层序遍历每个节点一次，出现 null 后若再遇到非 null 即返回 false，最坏需要扫完整棵树 -> O(n)<br>空间 O(w)：队列最多保存一层节点，w 为最大层宽，最坏 O(n)

## 题解(BFS判空洞)
创建节点辅助类完全二叉树就是最下面两层的节点度数可以小于2，并且最下面一层的叶子结点都依次排序在该层的最左侧的位置上

```java
//这个方法就是用了二叉树的性质，当根节点的序号为i，那么左孩子为2i
//右孩子为2i+1，那么当全部节点进去list，如果为完全二叉树，此时的size应该
//等于最后一个节点的序号
class Solution {
    public boolean isCompleteTree(TreeNode root) {
        List<ANode> nodes = new ArrayList();
        nodes.add(new ANode(root, 1));
        int i = 0;
        while (i < nodes.size()) {
            ANode anode = nodes.get(i++);
            if (anode.node != null) {
                nodes.add(new ANode(anode.node.left, anode.code * 2));
                nodes.add(new ANode(anode.node.right, anode.code * 2 + 1));
            }
        }
        //这里减一是因为i++，所以i-1才是最后一个
        return nodes.get(i-1).code == nodes.size();
    }
}

class ANode {  // Annotated Node
    TreeNode node;
    int code;
    ANode(TreeNode node, int code) {
        this.node = node;
        this.code = code;
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
