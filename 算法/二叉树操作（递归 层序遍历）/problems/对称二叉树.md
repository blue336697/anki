# 对称二叉树

## 题干
给定二叉树根节点，判断它是否关于中心轴镜像对称。需要比较左子树的左/右与右子树的右/左。

![image.png](image%202.png)


![image.png](image%203.png)

## 遍历策略
镜像递归：比较 root.left 与 root.right；每次要求外侧节点相等、内侧节点相等，即 left.left vs right.right，left.right vs right.left。

## 复杂度
时间 O(n)：每对镜像位置的节点比较一次，所有节点最多访问一次 -> O(n)<br>空间 O(h)：递归比较左右子树时调用栈深度为树高 h；若用队列迭代，空间为最大层宽 O(w)

## 题解(镜像递归)
使用dfs的方式使用队列的方式

```java
public boolean isSymmetric(TreeNode root) {
        if(root == null)
            return true;
        //递归入口
        return dfs(root.left, root.right);
    }

    public boolean dfs(TreeNode left, TreeNode right){
        //递归出口
        if(left == null && right == null)
            return true;
        //递归出口
        if(left == null || right == null)
            return false;
        //递归出口
        if(left.val != right.val)
            return false;

        //左树的左孩子跟右树的右孩子比较，左树的右孩子跟右树的左孩子比较
        return dfs(left.left, right.right) && dfs(left.right, right.left);
    }
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
