# 合并二叉树

## 题干
给定两棵二叉树，将重叠位置的节点值相加，不重叠位置直接接上原节点，返回合并后的树。

## 遍历策略
前序递归：如果两个节点都存在就相加并递归合并左右子树；如果某一侧为空，直接返回另一侧节点。

## 复杂度
时间 O(min(n,m))：两个节点都存在时才继续合并，访问范围为两棵树重叠部分；若把直接返回的子树也视作结果引用，不会逐节点复制<br>空间 O(h)：递归栈高度为两棵树重叠路径的最大高度，最坏 O(min(n,m))；原地合并不额外创建整棵树

## 题解(前序合并)
```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if(root1 == null && root2 == null)
            return null;
        //两者都不为空进行前序遍历，开始相加
        if(root1 != null && root2 != null){
            root1.val += root2.val;
            root1.left = mergeTrees(root1.left, root2.left);
            root1.right = mergeTrees(root1.right, root2.right);
            return root1;
        }else{
            //两者有一方不为空，返回不为空的
            return root1 == null ? root2 : root1;
        } 
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
