# 二叉树的直径

## 题干
给定二叉树根节点，返回任意两个节点之间最长路径的边数。每个节点处的候选直径是左深度加右深度。

## 遍历策略
后序 DFS：每个节点返回最大深度，同时用 leftDepth + rightDepth 更新全局直径。直径是边数，不是节点数。

## 复杂度
时间 O(n)：后序 DFS 每个节点计算一次左右深度，并用 leftDepth+rightDepth 更新直径 -> O(n)<br>空间 O(h)：递归调用栈高度为 h，平衡树 O(log n)，退化树 O(n)

## 题解(后序深度)
```java
class Solution {
    int ans;
    public int diameterOfBinaryTree(TreeNode root) {
        ans = 1;
        depth(root);
        return ans - 1;
    }
    public int depth(TreeNode node) {
        if (node == null) {
            return 0; // 访问到空节点了，返回0
        }
        int L = depth(node.left); // 左儿子为根的子树的深度
        int R = depth(node.right); // 右儿子为根的子树的深度
        ans = Math.max(ans, L+R+1); // 计算d_node即L+R+1 并更新ans
        return Math.max(L, R) + 1; // 返回该节点为根的子树的深度
    }
}
```

## 关键技巧
自底向上递归：先计算子树结果，再汇总返回当前层
