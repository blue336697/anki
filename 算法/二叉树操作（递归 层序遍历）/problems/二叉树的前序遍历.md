# 二叉树的前序遍历

## 题干
给定二叉树根节点，返回它的前序遍历结果，即根节点、左子树、右子树。

## 遍历策略
前序遍历：递归写法是 root -> left -> right；迭代写法用栈，先压右再压左，保证左子树先被访问。

## 复杂度
时间 O(n)：前序遍历每个节点访问一次，按根、左、右顺序加入结果 -> O(n)<br>空间 O(h+n)：递归栈或显式栈最多 O(h)，结果列表保存 n 个值；不计输出时为 O(h)

## 题解(前序遍历)
```java
class Solution {

    List<Integer> list = new ArrayList<>();
    public List<Integer> preorderTraversal(TreeNode root) {
        inOrder(root);
        return list;
    }

    //先根，在左，在右
    public void inOrder(TreeNode root){
        if(root == null)
            return;
        list.add(root.val);
        if(root.left!=null)
            inOrder(root.left);

        if(root.right!=null)
            inOrder(root.right);

    }
}
```

## 关键技巧
prev指针记录前驱节点，用于中序遍历线索化或节点交换
