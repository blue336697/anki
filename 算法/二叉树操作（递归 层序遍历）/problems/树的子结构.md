# 树的子结构

## 题干
给定两棵二叉树 A 和 B，判断 B 是否是 A 的子结构。子结构要求从 A 的某个节点开始，能匹配 B 的全部结构和值。

## 遍历策略
双递归匹配：外层在 A 中寻找可能的起点；内层从该起点开始判断 B 的结构和值是否全部匹配。B 为空时匹配完成。

## 复杂度
时间 O(n*m)：主递归枚举 A 树中可能匹配 B 根的节点，辅助递归向下比较 B 的结构，最坏每个候选比较 m 个节点 -> O(n*m)<br>空间 O(hA+hB)：递归栈包含 A 的遍历深度和匹配 B 时的深度，最坏退化为 O(n+m)

## 题解(双递归匹配)
DFS

```java
class Solution {
    public boolean isSubStructure(TreeNode A, TreeNode B) {
        if(A == null || B == null)
            return false;
        //从父的根节点就开始比较，如果不是就开始比左子树或右子树只要有一个满足就返回
        return dfs(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B);
    }

    public boolean dfs(TreeNode parent, TreeNode child){
        if(child == null)   //如果孩子提前比没了就证明是子树
            return true;
        if(parent == null)  //如果父树提前比完了就证明不是子树，因为父树的节点数量大于子树
            return false;
        return parent.val == child.val && dfs(parent.left, child.left)
                    && dfs(parent.right, child.right);
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
