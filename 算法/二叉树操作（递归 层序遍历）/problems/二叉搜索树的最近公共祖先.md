# 二叉搜索树的最近公共祖先

## 题干
给定一棵二叉搜索树和两个节点 p、q，返回它们的最近公共祖先。利用 BST 左小右大的性质可以从根节点一路缩小范围。

## 遍历策略
BST 分叉点：如果 p、q 都小于 root，答案在左子树；都大于 root，答案在右子树；第一次分叉或命中节点时 root 就是 LCA。

## 复杂度
时间 O(h)：利用 BST 有序性每次只向左或右走一边，最多走树高 h 层；平衡树 O(log n)，退化树 O(n)<br>空间 O(h)：递归实现需要 h 层调用栈；若改成迭代写法可降为 O(1)

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        while(root != null) {
            if(root.val < p.val && root.val < q.val) // p,q 都在 root 的右子树中
                root = root.right; // 遍历至右子节点
            //一直判断，直到不满足这个条件这个公共最近的祖先结点
            else if(root.val > p.val && root.val > q.val) // p,q 都在 root 的左子树中
                root = root.left; // 遍历至左子节点
            else break;
        }
        //如果上面的两个判断都不满足那自然而然这两个结点就是分别居于左子树和右子树上面
        return root;
    }
    

    //采用递归的方法
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if(root == null)
            return null;
        //如果全在左子树
        if(root.val < p.val && root.val < q.val)
            return lowestCommonAncestor(root.right, p, q);
        if(root.val > p.val && root.val > q.val)
            return lowestCommonAncestor(root.left, p, q); 

        return root;
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
