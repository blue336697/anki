# 平衡二叉树

## 题干
给定二叉树根节点，判断它是否高度平衡。每个节点的左右子树高度差都不能超过 1。

![image.png](image%204.png)


![image.png](image%205.png)

## 遍历策略
后序剪枝：递归返回子树高度；如果左右高度差超过 1，返回 -1 表示不平衡，并向上传播失败状态。

## 复杂度
时间 O(n)：自底向上每个节点只计算一次高度，并在返回时判断左右高度差 -> O(n)<br>空间 O(h)：递归栈深度为树高 h，平衡树 O(log n)，退化树 O(n)

## 题解(后序高度)
```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        //如果最后返回的个非负则是一颗平衡二叉树
        return depth(TreeNode root) != -1;

    }

    //自底向上，可以避免很多重复的递归，本质上是一个先序遍历
    public int depth(TreeNode root){
        //根结点为空则返回0
        if(root == null)
            return 0;
        //将左边子树的深度记录
        int i = depth(root.left);
        //不满足是平衡二叉树，则返回-1
        if(i == -1)
            return -1;
        //与上面同理
        int j = depth(root.right);
        if(j == -1)
            return -1;

        return Math.abs(i - j) < 2 ? Math.max(i, j) : -1; 
    }
}
```

## 关键技巧
自底向上递归：先计算子树结果，再汇总返回当前层
