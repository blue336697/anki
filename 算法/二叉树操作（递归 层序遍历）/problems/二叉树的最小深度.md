# 二叉树的最小深度

## 题干
给定二叉树根节点，返回根节点到最近叶子节点路径上的节点数。注意只有没有左右孩子的节点才是叶子。

## 遍历策略
BFS 最早叶子 / DFS 特判单子树：BFS 第一次遇到叶子即最小深度；DFS 中如果某侧为空，不能用 0 参与取 min。

## 复杂度
时间 O(n)：最坏需要访问所有节点才能确认最近叶子；BFS 在首次遇到叶子时可提前结束，但上界仍为 O(n)<br>空间 O(h) 或 O(w)：递归 DFS 使用 O(h) 调用栈；BFS 使用队列，最多 O(w) 个同层节点

## 题解(DFS最小深度)
DFSBFS

```java
class Solution {
    //1.递归条件（就是会出现的各种情况）
    //2.只在意本层的逻辑
    //3.需要返回什么，（根据条件你需要返回什么）
    /*叶子节点的定义是左孩子和右孩子都为 null 时叫做叶子节点
    当 root 节点左右孩子都为空时，返回 1
    当 root 节点左右孩子有一个为空时，返回不为空的孩子节点的深度
    当 root 节点左右孩子都不为空时，返回左右孩子较小深度的节点值
    */
    public int minDepth(TreeNode root) {
        //根节点位0，树为空
        if(root == null)
            return 0;
        //左右子树都为空，返回自身的长度
        if(root.left == null && root.right == null)
            return 1;
        //当左子树为空，返回右子树+自身的长度
        if(root.left == null)
            return minDepth(root.right) + 1;
        //与上面同理
        if(root.right == null)
            return minDepth(root.left) + 1;
        //左右子树都不为空，那就看谁小
        return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
    }
}
```

## 关键技巧
自底向上递归：取左右子树的最小值+1向上传递
