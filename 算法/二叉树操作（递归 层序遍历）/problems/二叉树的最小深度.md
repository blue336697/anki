# 二叉树的最小深度

## 题干
给定二叉树根节点，返回根节点到最近叶子节点路径上的节点数。注意只有没有左右孩子的节点才是叶子。

## 遍历策略
BFS 最早叶子 / DFS 特判单子树：BFS 第一次遇到叶子即最小深度；DFS 中如果某侧为空，不能用 0 参与取 min。

## 复杂度
时间 O(n)：最坏需要访问所有节点才能确认最近叶子；BFS 在首次遇到叶子时可提前结束，但上界仍为 O(n)<br>空间 O(h) 或 O(w)：递归 DFS 使用 O(h) 调用栈；BFS 使用队列，最多 O(w) 个同层节点

## 题解(DFS最小深度)
DFS 的关键不是简单计算 `min(left, right) + 1`：当一侧为空时，深度 0 不能被当作到达叶子的有效路径，必须沿非空子树继续计算。

```java
class Solution {
    public int minDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        if (root.left == null) {
            return minDepth(root.right) + 1;
        }
        if (root.right == null) {
            return minDepth(root.left) + 1;
        }
        return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
    }
}
```

## 题解(BFS)
BFS 按深度从小到大访问节点，第一次遇到左右孩子都为空的叶子时，当前层数就是答案，可以立即返回。

```java
class Solution {
    public int minDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 1;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left == null && node.right == null) {
                    return depth;
                }
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            depth++;
        }
        throw new IllegalStateException("unreachable");
    }
}
```

## 关键技巧
最小深度的终点必须是叶子，而不是空指针。DFS 必须特判单子树；BFS 则天然适合“第一次到达目标即最短”的问题。
