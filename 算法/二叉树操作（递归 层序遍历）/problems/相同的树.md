# 相同的树

## 题干
给定两棵二叉树，判断它们是否结构相同且对应节点值相等。

## 遍历策略
同步递归：两个节点都空则相同；一个空或值不同则不同；否则递归比较左子树和右子树。

## 复杂度
时间 O(min(n,m))：同步递归比较两棵树，遇到结构或值不同可提前返回；最坏两棵树相同或前缀相同，需要比较较小树所有节点<br>空间 O(h)：递归栈深度为两棵树同步下降的最大高度，最坏退化为 O(min(n,m))

## 题解(同步递归)
```java
class Solution {

    boolean isSameTree(TreeNode root1, TreeNode root2) {
    // 都为空的话，显然相同
    if (root1 == null && root2 == null) return true;
    // 一个为空，一个非空，显然不同
    if (root1 == null || root2 == null) return false;
    // 两个都非空，但 val 不一样也不行
    if (root1.val != root2.val) return false;

    // root1 和 root2 该比的都比完了
    return isSameTree(root1.left, root2.left)
        && isSameTree(root1.right, root2.right);
	}
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
