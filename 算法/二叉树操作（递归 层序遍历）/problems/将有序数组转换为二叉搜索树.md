# 将有序数组转换为二叉搜索树

## 题干
给定升序数组，构造一棵高度平衡的二叉搜索树。每次选择中点作为根可以保证左右规模接近。

## 遍历策略
二分递归：每次选当前区间中点作为根，左半区间构造左子树，右半区间构造右子树，从而保证高度平衡。

## 复杂度
时间 O(n)：每个数组元素都会被选作一次根节点并创建一个 TreeNode -> O(n)<br>空间 O(log n)：递归每次取中点构造平衡 BST，调用栈高度为 O(log n)；新建的 n 个树节点属于输出，不计额外空间

## 题解(二分建树)
就是利用折半的特效两边分别建立二叉树

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return buildTree(nums, 0, nums.length - 1);
    }

    public TreeNode buildTree(int[] nums, int left, int right){
        if(left > right);
            return null;
        int mid = left + (right - left) / 2;
        //由于数组是升序的其谁做根节点都无所谓
        TreeNode root = new TreeNode(nums[mid]);
        //构建其左子树和右子树
        root.left = buildTree(nums, left, mid - 1);
        root.right = buildTree(nums, mid + 1, right);
        return root
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
