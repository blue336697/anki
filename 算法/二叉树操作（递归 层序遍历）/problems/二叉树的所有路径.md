# 二叉树的所有路径

## 题干
给定二叉树根节点，返回所有从根节点到叶子节点的路径字符串。

## 遍历策略
DFS 回溯：维护当前路径字符串或列表；到叶子节点时生成一条完整路径，非叶子继续递归左右子树。

## 复杂度
时间 O(n*h)：DFS 访问每个节点一次；到叶子时需要把当前路径拼接成字符串，单条路径长度最多 h，最坏输出拼接总成本 O(n*h)<br>空间 O(h+r)：递归栈和当前路径为 O(h)，r 为所有输出路径字符串的总长度；不计输出时为 O(h)

## 题解(DFS路径)
递归就完事了

```java
class Solution {
    List<String> res;
    public List<String> binaryTreePaths(TreeNode root) {
        res = new ArrayList<>();
        if(root == null)
            return null;
        dfs(root, "");
        return res;

    }

    public void dfs(TreeNode root, String curRoad){
        if(root == null)
            return;
        //自己这里自动的拆包装包最好现式的自己转换，提高效率
        curRoad += Integer.valueOf(root.val);
        if(root.left == null && root.right == null){
            res.add(curRoad);
            return;
        }
        curRoad += "->";
        dfs(root.left, curRoad);
        dfs(root.right, curRoad);
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
