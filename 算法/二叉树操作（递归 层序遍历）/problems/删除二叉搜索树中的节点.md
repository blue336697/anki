# 删除二叉搜索树中的节点

## 题干
给定二叉搜索树根节点和 key，删除值为 key 的节点，并保持删除后的树仍然是二叉搜索树。

**这个代码会让树高变高，从而破坏二叉搜索树的效率，面试中会要求优化成AVL（二叉查找树，即两个子树的高度差不能超过1）这样效率就不会收到影响**

> 如果删除这个节点可以清楚的看到树的高度变了
>

## 遍历策略
BST 删除：先按大小关系查找 key；找到后分三类处理：无子/单子直接接上，双子用右子树最小节点或左子树最大节点替换。

## 复杂度
时间 O(h)：根据 BST 大小关系向一侧查找目标节点，删除时若找后继/前驱也沿一条路径走，最多 O(h)<br>空间 O(h)：递归实现需要 O(h) 调用栈；平衡树 O(log n)，退化树 O(n)，迭代实现可为 O(1)

## 题解(BST删除)
这个代码会让树高变高，从而破坏二叉搜索树的效率，面试中会要求优化成AVL（二叉查找树，即两个子树的高度差不能超过1）这样效率就不会收到影响> 如果删除这个节点可以清楚的看到树的高度变了

```java
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
                if (root == null)return null;

        if (key > root.val)
            root.right = deleteNode(root.right, key); // 去右子树删除

        else if(key < root.val)    
            root.left = deleteNode(root.left, key);  // 去左子树删除

        else  {  // 当前节点就是要删除的节点

            if (root.left == null)   return root.right;      // 情况1，欲删除节点无左子
            else if (root.right == null)  return root.left;  // 情况2，欲删除节点无右子
            else if (root.left!=null && root.right !=null){  // 情况3，欲删除节点左右子都有 
                TreeNode node = root.right;   
                while (node.left != null)      // 寻找欲删除节点右子树的最左节点
                    node = node.left;

                //这样待删除节点的左子树，可以全部移植到我们找到的待删除节点的右子树的
                //最左节点的左孩子
                //node保存的就是待删除节点右子树的最左节点
                node.left = root.left;     // 将欲删除节点的左子树成为其右子树的最左节点的左子树
                root = root.right;         // 欲删除节点的右子顶替其位置，节点被删除
            }
        }
        return root;    
    }
}
```

## 题解(BST删除-交换值递归删后继)
不移动子树，而是将待删节点与后继节点交换值，再递归删除后继。代码更简洁，且保持了 BST 结构。

```java
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        if (root == null) {
            return null;
        }
        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else {
            // 找到待删除节点
            if (root.left == null) {
                return root.right;  // 无左子，右子直接顶替
            }
            if (root.right == null) {
                return root.left;   // 无右子，左子直接顶替
            }
            // 左右子树都存在：找后继节点（右子树的最小节点）
            TreeNode successor = root.right;
            while (successor.left != null) {
                successor = successor.left;
            }
            // 将后继节点的值赋给当前节点，然后递归删除后继
            root.val = successor.val;
            root.right = deleteNode(root.right, successor.val);
        }
        return root;
    }
}
```

## 题解(BST删除-AVL自平衡)
删除后自底向上检查平衡因子，若左右子树高度差超过1则通过旋转恢复AVL平衡。包含四种旋转情况：LL(右旋)、RR(左旋)、LR(左旋左子再右旋)、RL(右旋右子再左旋)。

```java
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        if (root == null) {
            return null;
        }
        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else {
            // 找到待删除节点
            if (root.left == null) {
                return root.right;
            }
            if (root.right == null) {
                return root.left;
            }
            // 找后继节点，交换值后递归删除后继
            TreeNode successor = root.right;
            while (successor.left != null) {
                successor = successor.left;
            }
            root.val = successor.val;
            root.right = deleteNode(root.right, successor.val);
        }

        // AVL自平衡：计算平衡因子
        int balance = height(root.left) - height(root.right);

        // LL：左子树的左子树过高 → 右旋
        if (balance > 1 && height(root.left.left) >= height(root.left.right)) {
            return rotateRight(root);
        }
        // LR：左子树的右子树过高 → 先左旋左子，再右旋
        if (balance > 1 && height(root.left.right) > height(root.left.left)) {
            root.left = rotateLeft(root.left);
            return rotateRight(root);
        }
        // RR：右子树的右子树过高 → 左旋
        if (balance < -1 && height(root.right.right) >= height(root.right.left)) {
            return rotateLeft(root);
        }
        // RL：右子树的左子树过高 → 先右旋右子，再左旋
        if (balance < -1 && height(root.right.left) > height(root.right.right)) {
            root.right = rotateRight(root.right);
            return rotateLeft(root);
        }

        return root;
    }

    private int height(TreeNode node) {
        if (node == null) {
            return 0;
        }
        return Math.max(height(node.left), height(node.right)) + 1;
    }

    // 右旋（LL情况）
    private TreeNode rotateRight(TreeNode y) {
        TreeNode x = y.left;
        TreeNode T2 = x.right;
        x.right = y;
        y.left = T2;
        return x;
    }

    // 左旋（RR情况）
    private TreeNode rotateLeft(TreeNode x) {
        TreeNode y = x.right;
        TreeNode T2 = y.left;
        y.left = x;
        x.right = T2;
        return y;
    }
}
```

> **优化提示**：上述 height() 每次调用需 O(n) 遍历子树，生产中应在 TreeNode 中存储高度字段并在旋转后维护，将平衡检查降到 O(1)。此处为面试清晰展示 AVL 四个旋转 case 的完整逻辑。

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树<br>
交换值法：找后继→交换值→递归删后继，比移动子树更简洁<br>
AVL自平衡：删后检查 balance = height(left)-height(right)，四种旋转恢复平衡
