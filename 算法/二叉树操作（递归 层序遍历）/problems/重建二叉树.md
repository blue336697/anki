# 重建二叉树

## 题干
给定前序遍历和中序遍历结果，重建原二叉树。前序定位根，中序划分左右子树。

注意：本文方法只适用于 “无重复节点值” 的二叉树。**PythonJavaC++**

## 遍历策略
前序 + 中序建树：前序第一个元素是根；中序根左侧为左子树、右侧为右子树；HashMap 加速根下标定位。

## 复杂度
时间 O(n)：使用 HashMap 记录中序下标后，每个节点只被定位并构造一次 -> O(n)<br>空间 O(n)：HashMap 保存 n 个节点位置，递归栈最坏 O(n)，平衡时 O(log n)；重建出的树作为输出不计额外空间

## 题解(前序+中序建树)
注意：本文方法只适用于 “无重复节点值” 的二叉树。PythonJavaC++

```java
class Solution {
    int[] preorder;
    HashMap<Integer, Integer> hmap = new HashMap<>();
    public TreeNode deduceTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        for(int i = 0; i < inorder.length; i++)
            hmap.put(inorder[i], i);
        return recur(0, 0, inorder.length - 1);
    }
    TreeNode recur(int root, int left, int right) {
        if(left > right) return null;                          // 递归终止
        TreeNode node = new TreeNode(preorder[root]);          // 建立根节点
        int i = hmap.get(preorder[root]);                      // 划分根节点、左子树、右子树
        node.left = recur(root + 1, left, i - 1);              // 开启左子树递归
        node.right = recur(root + i - left + 1, i + 1, right); // 开启右子树递归
        return node;                                           // 回溯返回根节点
    }
}
```

## 关键技巧
HashMap存储中序val→index映射，O(1)定位根节点位置；prev指针记录前驱节点，用于中序遍历线索化或节点交换
