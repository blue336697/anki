# 二叉树的最近公共祖先

## 题干
给定普通二叉树和两个节点 p、q，返回它们的最近公共祖先。普通二叉树没有有序性，需要在左右子树中分别查找。

![image.png](image%206.png)

## 遍历策略
后序查找：若当前节点为空或等于 p/q，直接返回；左右子树都找到时当前节点是 LCA；只有一侧找到就向上传那一侧。

## 复杂度
时间 O(n)：普通二叉树没有有序性，最坏需要在左右子树中查找 p 和 q，所有节点最多访问一次 -> O(n)<br>空间 O(h)：递归栈深度为树高 h，最坏退化为 O(n)，平衡时 O(log n)

## 题解(后序LCA)
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        //开始先序遍历 先根，在左，在右
        //根据题意，当p，q某一个是root时，该点就是最近公共祖先
        if(root == null || root == p || root == q)
            return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        //第一种情况：当一直遍历到最后一层，未遍历到p和q，则公共祖先为root
        if(left == null && right == null)
            return null;
        //第二种情况：遍历到右子树有q，左子树的p可能在右子树，
        if(left == null)
            return right;
        //第三种情况：与第二种相反
        if(right == null)
            return left;

        //此时其实p和q分别在左右子树都已经找到了，有一个隐含条件
        //if(left != null and right != null)
        return root;
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
