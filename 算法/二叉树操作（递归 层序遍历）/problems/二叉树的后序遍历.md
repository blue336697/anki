# 二叉树的后序遍历

## 题干
给定二叉树根节点，返回它的后序遍历结果，即左子树、右子树、根节点。

## 遍历策略
后序遍历：递归写法是 left -> right -> root；迭代写法可用栈和 prev 指针判断右子树是否已访问。

## 复杂度
时间 O(n)：后序遍历每个节点访问一次，按左、右、根顺序加入结果 -> O(n)<br>空间 O(h+n)：递归栈或显式栈最多 O(h)，结果列表保存 n 个值；不计输出时为 O(h)

## 题解(后序遍历)
```java
class Solution {
    List<Integer> list = new ArrayList<>();
    public List<Integer> postorderTraversal(TreeNode root) {
        inOrder(root);
        return list;
    }

    //先左，后右，在根
    public void inOrder(TreeNode root){
        if(root == null)
            return;
        if(root.left != null)
            inOrder(root.left);
        if(root.right != null)
            inOrder(root.right);
        list.add(root.val);
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
