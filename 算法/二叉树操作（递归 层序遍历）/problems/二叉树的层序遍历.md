# 二叉树的层序遍历

## 题干
给定二叉树根节点，返回按层从上到下、每层从左到右的节点值。

## 遍历策略
BFS 分层：队列保存当前待访问节点；每轮先记录 size，只处理这一层的 size 个节点，形成一个层列表。

## 复杂度
时间 O(n)：BFS 每个节点入队、出队一次，并加入对应层结果 -> O(n)<br>空间 O(w+n)：队列最多保存最大层宽 w，结果列表保存所有 n 个节点值；不计输出时为 O(w)

## 题解(BFS层序)
BFS

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> returnList = new ArrayList<>();
        if(root==null)
            return returnList;
        TreeNode temp;
        Deque<TreeNode> queue = new LinkedList<>();
        queue.add(root);    //根结点入队
        while(queue.size()!=0){
            List<Integer> list = new ArrayList<>();
            int size = queue.size();
            for(int i = 0; i < size; i++){
                temp = queue.poll();
                list.add(temp.val);
                if(temp.left != null)
                    queue.add(temp.left);
                if(temp.right != null)
                    queue.add(temp.right);   
            }
            returnList.add(list);

        }
        return returnList;
    }
}
```

## 关键技巧
BFS层序遍历：队列+每层size循环；List<List<Integer>>收集每层结果，new ArrayList<>()创建临时列表
