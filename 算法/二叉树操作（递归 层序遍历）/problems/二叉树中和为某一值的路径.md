# 二叉树中和为某一值的路径

## 题干
给定二叉树根节点和目标和，找出所有从根节点到叶子节点、路径节点值之和等于目标和的路径。

## 遍历策略
DFS 回溯：沿根到叶路径累加剩余目标值；到叶子时检查是否等于目标。路径加入结果前要复制，返回上一层时撤销当前节点。

## 复杂度
时间 O(n)：DFS 每个节点访问一次，进入节点加入路径、离开节点回溯删除，节点级操作合计 O(n)；命中叶子时复制路径，所有复制总量受结果规模影响<br>空间 O(h+r)：递归栈和当前路径长度最多为树高 h，r 为答案路径保存的总节点数；不计输出时为 O(h)

## 题解(DFS回溯)
DFS+回溯+递归

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> pathSum(TreeNode root, int target) {
        dfs(root, target);
        return res;
    }

    List<Integer> list = new ArrayList<>();
    public void dfs(TreeNode cur, int target){
        //不满足则返回回溯，注意存在负数的情况 cur.val > target的条件需要丢弃
        if(cur == null)
            return;
        target -= cur.val;
        list.add(cur.val);
        //叶子节点并且满足target=0才能加入哦，中途半道满足target但不满足叶子的
        //情况需要考虑到
        if(target == 0 && cur.left == null && cur.right == null){
            res.add(new ArrayList<>(list));
        }
        dfs(cur.left, target);
        dfs(cur.right, target);
        //这里就是回溯到基础，丢弃节点
        list.remove(list.size() - 1);
    }
}
```

## 关键技巧
List<List<Integer>>收集每层结果，new ArrayList<>()创建临时列表；DFS+回溯：递归后撤销选择（path.removeLast()）
