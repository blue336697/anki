# 验证二叉搜索树

## 题干
给定二叉树根节点，判断它是否是有效二叉搜索树。每个节点必须满足左子树所有值小于它，右子树所有值大于它。

## 遍历策略
中序递增 / 上下界递归：中序遍历时值必须严格递增；或递归传入每个节点允许的开区间 (low, high)。

## 复杂度
时间 O(n)：中序遍历或上下界递归都需要在最坏情况下检查每个节点一次 -> O(n)<br>空间 O(h)：递归栈或显式栈保存从根到当前节点的路径，平衡树 O(log n)，退化树 O(n)

## 题解(中序/上下界)
递归+中序遍历

```java
class Solution {
    public boolean isValidBST(TreeNode root) {

        return inOrder(root);
    }

    long preTemp = Long.MIN_VALUE;
    //使用中序遍历来比较当前遍历结点与前一个遍历结点的值，中序遍历的当前结点肯定是比前一个结点大的
    public boolean inOrder(TreeNode root){
        if(root == null)
            return true;
        if(!inOrder(root.left))
            return false;
        //关键就是用一个变量保存前一个结点的值
        if(preTemp >= root.val)
            return false;
        preTemp = root.val;

        //如果在添加if语句来判断的话，就缺少总体的返回语句来，所以这样处理
        return inOrder(root.right);

    }

}
```

## 关键技巧
prev指针记录前驱节点，用于中序遍历线索化或节点交换；使用long类型防止int溢出
