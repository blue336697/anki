# 二叉树的中序遍历

## 题干
给定二叉树根节点，返回它的中序遍历结果，即左子树、根节点、右子树。

## 遍历策略
中序遍历：递归写法是 left -> root -> right；迭代写法用栈一路压左链，弹出节点后转向右子树。

## 复杂度
时间 O(n)：中序遍历每个节点访问一次，加入结果列表一次 -> O(n)<br>空间 O(h+n)：递归栈或显式栈最多 O(h)，结果列表保存 n 个节点值；若不计输出额外空间为 O(h)

## 题解(中序遍历)
```java
class Solution {
//先左，在根，在右
    List<Integer> list = new ArrayList<>();
    public List<Integer> inorderTraversal(TreeNode root) {
        inOrder(root);
        return list;
    }

    public void inOrder(TreeNode root){
        if(root == null)
            return;
        if(root.left!=null)
            inOrder(root.left);
        list.add(root.val);
        if(root.right!=null)
            inOrder(root.right);
    }
}
```

## 关键技巧
递归三部曲：1.终止条件 2.处理当前层逻辑 3.递归调用左右子树
