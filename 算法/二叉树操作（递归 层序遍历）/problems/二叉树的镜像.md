# 二叉树的镜像
<!-- anki-deck: 二叉树的镜像（反转二叉树） -->

## 题干
给定二叉树根节点，返回它的镜像树，也就是递归交换每个节点的左右子树。

## 遍历策略
递归交换：先交换当前节点左右孩子，再递归处理左右子树；也可 BFS 遍历所有节点并交换。

## 复杂度
时间 O(n)：递归访问每个节点一次并交换左右子树，节点级操作为常数 -> O(n)<br>空间 O(h)：递归栈高度为树高 h，平衡树 O(log n)，退化树 O(n)；原地交换不额外创建节点

## 题解(递归交换)
```java
class Solution {
    public TreeNode mirrorTree(TreeNode root) {
        if (root == null) {
            return null;
        }

        TreeNode oldLeft = root.left;
        root.left = mirrorTree(root.right);
        root.right = mirrorTree(oldLeft);
        return root;
    }
}
```

## 关键技巧
不要分别枚举“只有左孩子、只有右孩子、两个孩子都有”三种情况。交换两个引用本身就能统一处理 `null`；递归函数返回翻转后的子树根节点，再接回当前节点即可。
