# 数字转换为十六进制数

## 题干
给定一个整数，编写一个算法将这个数转换为十六进制数。对于负整数，使用补码运算方法。
十六进制中所有字母(a-f)都必须是小写。
![image 8.png](image%208.png)

## 复杂度
时间：{{c1::O(log n)}} — 每次右移4位
空间：{{c1::O(1)}}

## 关键技巧
两种方法对比：
1. 取余法：num % 16 取每位，num /= 16 移位，负数需 +2^32 偏移
2. 位运算法（推荐）：num & 15 取低4位，num >>>= 4 无符号右移
位运算法优势：无需额外处理负数，>>> 保证无符号右移，补码自动正确
结果需 reverse()，因为从低位到高位构造。

## 题解(取余法)
num % 16 取每位，num /= 16 移位，负数需 +2^32 偏移后计算。

```java
class Solution {
    public String toHex(int num) {
        if (num == 0)
            return "0";
        long res = num;
        StringBuilder sb = new StringBuilder();
        if (res < 0)
            res = (long) (Math.pow(2, 32) + res);
        while (res != 0) {
            long temp = res % 16;
            char c = (char) (temp + '0');
            if (temp >= 10) {
                c = (char) (temp - 10 + 'a');
            }
            sb.append(c);
            res /= 16;
        }
        return sb.reverse().toString();
    }
}
```

## 题解(位运算法)
&15取低4位（等价%16），>>>4无符号右移，负数用补码自动处理。

```java
class Solution {
    public String toHex(int num) {
        if (num == 0)
            return "0";
        StringBuilder sb = new StringBuilder();
        while (num != 0) {
            int temp = num & 15;
            char c = (char) (temp + '0');
            if (temp >= 10) {
                c = (char) (temp - 10 + 'a');
            }
            sb.append(c);
            num >>>= 4;
        }
        return sb.reverse().toString();
    }
}
```
