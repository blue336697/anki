# 分数到小数

## 题干
给定两个整数，分别表示分子 numerator 和分母 denominator，以字符串形式返回小数。
如果小数部分为循环小数，则将循环的部分括在括号内。

## 复杂度
时间：{{c1::O(denominator)}} — 余数最多有 denominator 种可能
空间：{{c1::O(denominator)}} — HashMap 记录余数位置

## 关键技巧
模拟长除法步骤：
1. 先处理符号和整数部分 a/b，若能整除直接返回
2. 添加小数点后，每次：余数 *= 10 作为新被除数，商 append 到结果
3. 用 HashMap<余数, 位置> 检测循环：若余数已存在，说明开始循环
4. 在循环起始位置插入 "("，末尾追加 ")"
关键：转 long 防止溢出；Math.abs() 取绝对值计算。

## 题解(模拟除法)
模拟长除法：每次余数*10作为新被除数，HashMap记录余数首次出现位置以检测循环。

```java
class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        StringBuilder sb = new StringBuilder();
        long a = numerator, b = denominator;
        if (a < 0 && b > 0 || a > 0 && b < 0)
            sb.append('-');
        a = Math.abs(a);
        b = Math.abs(b);
        sb.append(a / b);
        if (a % b == 0)
            return sb.toString();
        sb.append('.');
        Map<Long, Integer> memory = new HashMap<>();
        while ((a = (a % b) * 10) > 0 && !memory.containsKey(a)) {
            memory.put(a, sb.length());
            sb.append(a / b);
        }
        if (a == 0)
            return sb.toString();
        return sb.insert(memory.get(a).intValue(), '(')
                 .append(')').toString();
    }
}
```
