# 二进制中1的个数

## 题干
编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 "1" 的个数（汉明重量）。

## 复杂度
逐位法：时间 {{c1::O(32)}}，空间 {{c1::O(1)}}
n&(n-1)法：时间 {{c1::O(k)}}（k为1的个数），空间 {{c1::O(1)}}

## 关键技巧
两种方法对比：
1. 逐位判断法：n & 1 判断最低位 + n >>>= 1 右移，固定 O(32) 次循环
2. n&(n-1) 法：每次消除最低位的 1，循环次数 = 1 的个数（更优）
原理：n-1 会把最低位的 1 变成 0，其右边的 0 全部变 1，与 n 做 AND 运算即消除最低位的 1。
使用 >>> 无符号右移，避免负数高位补 1 导致的无限循环。

## 题解(逐位判断)
n & 1判断最低位是否为1（结果为0或1），然后无符号右移1位，循环32次。

```java
public class Solution {
    public int hammingWeight(int n) {
        int res = 0;
        while (n != 0) {
            res += n & 1;
            n >>>= 1;
        }
        return res;
    }
}
```

## 题解(n&(n-1))
n & (n-1) 消除最低位的1，每次消除一个1并计数，循环次数等于1的个数。

```java
public class Solution {
    public int hammingWeight(int n) {
        int res = 0;
        while (n != 0) {
            res++;
            n &= n - 1;
        }
        return res;
    }
}
```
