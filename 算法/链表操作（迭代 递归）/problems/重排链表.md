# 重排链表

## 题干
给定 L0->L1->...->Ln-1->Ln，重排为 L0->Ln->L1->Ln-1->L2->...
![image 2.png](image%202.png)

![image 3.png](image%203.png)

## 复杂度
方法一（中点+反转+合并）：
时间：O(n)
空间：O(1)

方法二（ArrayList）：
时间：O(n)
空间：O(n)

## 关键技巧
方法一（最优O(1)空间）：
1. 快慢指针找中点
2. 反转后半部分链表
3. 交替合并前后两部分

方法二（暴力O(n)空间）：ArrayList存所有节点后双指针重排

方法三：递归（类似暴力，用递归找尾节点）
![image 4.png](image%204.png)

## 题解(中点+反转+合并)
三步走：找中点、反转后半、交替合并。O(1)空间最优解。

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null || head.next.next == null) {
            return;
        }
        // 1. find middle
        ListNode slow = head;
        ListNode fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode newHead = slow.next;
        slow.next = null;
        // 2. reverse second half
        newHead = reverseList(newHead);
        // 3. interleave merge
        while (newHead != null) {
            ListNode temp = newHead.next;
            newHead.next = head.next;
            head.next = newHead;
            head = newHead.next;
            newHead = temp;
        }
    }

    private ListNode reverseList(ListNode head) {
        if (head == null) {
            return null;
        }
        ListNode tail = head;
        head = head.next;
        tail.next = null;
        while (head != null) {
            ListNode temp = head.next;
            head.next = tail;
            tail = head;
            head = temp;
        }
        return tail;
    }
}
```

## 题解(暴力-ArrayList)
将所有节点存入ArrayList，双指针从两端向中间重连。

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null)
            return;
        List<ListNode> list = new ArrayList<>();
        while (head != null) {
            list.add(head);
            head = head.next;
        }
        int left = 0, right = list.size() - 1;
        while (left < right) {
            list.get(left).next = list.get(right);
            left++;
            if (left == right)
                break;
            list.get(right).next = list.get(left);
            right--;
        }
        list.get(left).next = null;
    }
}
```

## 题解(递归)
递归找尾节点并重连，类似暴力但用递归替代尾节点查找。

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null || head.next.next == null) {
            return;
        }
        int len = 0;
        ListNode h = head;
        while (h != null) {
            len++;
            h = h.next;
        }
        reorderListHelper(head, len);
    }

    private ListNode reorderListHelper(ListNode head, int len) {
        if (len == 1) {
            ListNode outTail = head.next;
            head.next = null;
            return outTail;
        }
        if (len == 2) {
            ListNode outTail = head.next.next;
            head.next.next = null;
            return outTail;
        }
        ListNode tail = reorderListHelper(head.next, len - 2);
        ListNode subHead = head.next;
        head.next = tail;
        ListNode outTail = tail.next;
        tail.next = subHead;
        return outTail;
    }
}
```

## 对比
与 奇偶链表 相似：都是交替取节点重排
但奇偶链表不反转，本题需要先反转后半部分
与 回文链表 相似：都用到找中点+反转后半部分
