# 奇偶链表

## 题干
给定一个单链表，将所有奇数节点和偶数节点分别排在一起。
奇数节点指索引为奇数的节点，偶数节点指索引为偶数的节点。
保持奇数节点和偶数节点的相对顺序。
![image 7.png](image%207.png)

## 复杂度
时间：O(n) — 一次遍历
空间：O(1)

## 关键技巧
1. 分离奇数链表和偶数链表
2. odd指针串联所有奇数索引节点
3. even指针串联所有偶数索引节点
4. evenHead = head.next（偶数链表头保存起来用于拼接）
5. odd.next = evenHead 拼接两链表

## 题解
odd串奇数位，even串偶数位，最后odd尾连even头。

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null)
            return head;
        ListNode dummy = head;
        ListNode evenHead = head.next;
        ListNode even = evenHead;
        while (even != null && even.next != null) {
            dummy.next = even.next;
            dummy = dummy.next;
            even.next = dummy.next;
            even = even.next;
        }
        dummy.next = evenHead;
        return head;
    }
}
```

## 对比
与 排序奇升偶降链表 的关系：
本题 = 奇偶分离；后者 = 奇偶分离 + 反转偶数链表 + 合并两个有序链表
