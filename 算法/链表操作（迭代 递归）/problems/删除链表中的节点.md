# 删除链表中的节点

## 题干
给定单向链表的头指针和一个要删除的节点的值，定义一个函数删除该节点。
返回删除后的链表的头节点。
![image 10.png](image%2010.png)

## 复杂度
时间：O(n) — 最坏遍历到末尾
空间：O(1)

## 关键技巧
1. 特判：head.val == val → return head.next
2. pre 记录前驱节点，temp 遍历
3. 找到目标节点后：pre.next = temp.next
4. 断开连接：temp.next = null

## 题解
pre记录前驱，找到目标后跳过该节点并断开。

```java
class Solution {
    public ListNode deleteNode(ListNode head, int val) {
        if (head == null)
            return null;
        if (head.val == val)
            return head.next;
        ListNode temp = head;
        ListNode pre = head;
        while (temp != null) {
            if (temp.val != val) {
                pre = temp;
                temp = temp.next;
            } else
                break;
        }
        pre.next = temp.next;
        temp.next = null;
        return head;
    }
}
```
