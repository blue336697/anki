# 链表求和

## 题干
给定两个用链表表示的非负整数，每个节点只存一位数字，数字按逆序存储。
求两数之和，以相同链表形式返回。

## 复杂度
时间：O(max(m,n)) — 遍历较长链表长度
空间：O(max(m,n)) — 结果链表

## 关键技巧
1. 逆序存储（个位在头）：直接从头遍历相加
2. 进位 carry = sum / 10
3. 短链表补0处理
4. 最后如果进位为1，需额外添加节点

## 题解
逐位相加+进位，短链表补0，最后额外处理进位。

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        if (l1 == null || l2 == null)
            return null;
        ListNode res = new ListNode(0);
        ListNode cur = res;
        int one = 0;
        while (l1 != null || l2 != null) {
            int num1 = l1 != null ? l1.val : 0;
            int num2 = l2 != null ? l2.val : 0;
            cur.next = new ListNode((num1 + num2 + one) % 10);
            one = (num1 + num2 + one) / 10;
            l1 = l1.next;
            l2 = l2.next;
            cur = cur.next;
        }
        if (one == 1)
            cur.next = new ListNode(1);
        return res.next;
    }
}
```

## 对比
与 两数相加II 的区别：
本题数字逆序存储，可直接从低位加
II 是正向存储，需要先反转再相加再反转回来
