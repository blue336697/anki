# 合并两个有序链表

## 题干
将两个升序链表合并为一个新的升序链表并返回。新链表由原链表的节点组成。

## 复杂度
时间：O(m+n) — 两个链表长度之和
空间：O(1) — 迭代；O(m+n) — 递归栈

## 关键技巧
迭代：
1. dummy节点连接合并后链表
2. 比较 cur1.val 和 cur2.val，取较小者接到 dummy 后
3. 剩余节点直接拼接

递归：
if list1.val < list2.val: list1.next = merge(list1.next, list2)
else: list2.next = merge(list1, list2.next)

## 题解(迭代)
dummy节点 + 双指针比较，取较小者接入结果链。

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null && list2 == null)
            return null;
        ListNode dummy = new ListNode(0);
        ListNode res = dummy;
        ListNode cur1 = list1;
        ListNode cur2 = list2;
        while (cur1 != null && cur2 != null) {
            if (cur1.val < cur2.val) {
                dummy.next = cur1;
                cur1 = cur1.next;
            } else {
                dummy.next = cur2;
                cur2 = cur2.next;
            }
            dummy = dummy.next;
        }
        dummy.next = cur1 == null ? cur2 : cur1;
        return res.next;
    }
}
```

## 题解(递归)
递归比较头节点，较小者的next指向子问题结果。

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }
        if (list1.val < list2.val) {
            list1.next = mergeTwoLists(list1.next, list2);
            return list1;
        }
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}
```

## 对比
与 分隔链表 的区别：分隔是按值x分成大小两组，不要求有序
本题是两个已有序链表的合并（归并排序的merge步骤）
