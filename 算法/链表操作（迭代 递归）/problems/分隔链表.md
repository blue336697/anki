# 分隔链表

## 题干
给定一个链表和一个特定值 x，对链表进行分隔，使得所有小于 x 的节点都在大于或等于 x 的节点之前，且保持原有相对顺序。

## 复杂度
时间：O(n) — 一次遍历
空间：O(1) — 原地重连（仅用了两个dummy节点）

## 关键技巧
1. 创建两个dummy链表：small（存 <x）和 large（存 >=x）
2. 遍历原链表，根据val分配节点到small或large
3. 关键：每次连接后设 curNode.next = null，避免成环
4. smallTail.next = largeHead.next 拼接
5. 返回 smallHead.next

## 题解
两个dummy分别存大小节点，每次连接后置null防止成环。

```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode dummy01 = new ListNode(0);
        ListNode curNodeDummy01 = dummy01;
        ListNode dummy02 = new ListNode(0);
        ListNode curNodeDummy02 = dummy02;
        while (head != null) {
            if (head.val < x) {
                curNodeDummy01.next = head;
                head = head.next;
                curNodeDummy01 = curNodeDummy01.next;
                curNodeDummy01.next = null;
            } else {
                curNodeDummy02.next = head;
                head = head.next;
                curNodeDummy02 = curNodeDummy02.next;
                curNodeDummy02.next = null;
            }
        }
        curNodeDummy01.next = dummy02.next;
        return dummy01.next;
    }
}
```

## 对比
与 合并两个有序链表 的区别：
本题按值x分成两组保持相对顺序，无需排序
合并两个有序链表是将已排序的两链合并为一个
