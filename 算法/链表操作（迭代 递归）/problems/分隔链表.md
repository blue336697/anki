# 分隔链表

## 题干
给定一个链表和一个特定值 x，对链表进行分隔，使得所有小于 x 的节点都在大于或等于 x 的节点之前，且保持原有相对顺序。

## 复杂度
时间：O(n) — 一次遍历
空间：O(1) — 原地重连（仅用了两个dummy节点）

## 关键技巧
1. 创建两个dummy链表：small（存 &lt;x）和 big（存 &gt;=x）
2. 遍历原链表，根据val分配节点到small或big
3. `head = head.next` 提取到公共位置，if-else 不重复
4. 遍历结束后：`curBig.next = null` 切断大链表尾部（防环）
5. `curSmall.next = dummyBig.next` 拼接 → 返回 dummySmall.next

## 题解
两个dummy分别存大小节点；head=next 提到公共行避免重复；最后只切一次大链表尾部而非每节点都切。
```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode dummySmall = new ListNode(0);
        ListNode curSmall = dummySmall;
        ListNode dummyBig = new ListNode(0);
        ListNode curBig = dummyBig;

        while (head != null) {
            if (head.val < x) {
                curSmall.next = head;
                curSmall = curSmall.next;
            } else {
                curBig.next = head;
                curBig = curBig.next;
            }
            head = head.next; // 提取出来，不用写两遍
        }
        // 关键：大链表最后节点切断，防止链表环
        curBig.next = null;
        // 小链表尾部拼接大链表头部
        curSmall.next = dummyBig.next;
        return dummySmall.next;
    }
}
```

## 对比
与 合并两个有序链表 的区别：
本题按值x分成两组保持相对顺序，无需排序
合并两个有序链表是将已排序的两链合并为一个
