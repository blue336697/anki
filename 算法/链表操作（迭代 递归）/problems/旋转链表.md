# 旋转链表

## 题干
给定一个链表，将链表每个节点向右移动 k 个位置。
![image 5.png](image%205.png)

![image 6.png](image%206.png)

## 复杂度
时间：O(n) — 遍历两次（求长度+找断开点）
空间：O(1)

## 关键技巧
1. 先遍历求出链表长度 count
2. k %= count — 消除重复移动
3. 闭合为环：tail.next = head
4. 找到断开位置：第 count - k 个节点
5. 新头 = 断开点的next；断开点.next = null

## 题解
闭合为环→找新断开点→断开返回新头。

```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || k == 0)
            return head;
        ListNode tail = head;
        int count = 1;
        while (tail.next != null) {
            tail = tail.next;
            count++;
        }
        k %= count;
        ListNode p = head;
        for (int i = 0; i < count - k - 1; i++) {
            p = p.next;
        }
        tail.next = head;
        head = p.next;
        p.next = null;
        return head;
    }
}
```
