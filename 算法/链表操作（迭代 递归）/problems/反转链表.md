# 反转链表

## 题干
反转一个单链表。
![34457_k3RMIiHpYvey41CJ.png](34457_k3RMIiHpYvey41CJ.png)

## 复杂度
时间：O(n) — 遍历一次
空间：O(1) — 迭代；O(n) — 递归栈

## 关键技巧
双指针迭代：pre/cur/tail 三指针
1. 保存 cur.next 到 tail
2. cur.next 指向 pre
3. pre 和 cur 各前进一步
4. 最后返回 pre（原尾节点，现头节点）

递归：head.next.next = head; head.next = null;
头插法（不创建新节点）：循环将 head.next 摘下插到头部

## 题解(迭代-双指针)
pre/cur/next 三指针迭代反转。

```java
class Solution {
    public ListNode reverse(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode preNode = null;
        ListNode curNode = head;
        ListNode nextNode = null;
        while (curNode != null) {
            nextNode = curNode.next;
            curNode.next = preNode;
            preNode = curNode;
            curNode = nextNode;
        }
        return preNode;
    }
}
```

## 题解(递归)
递归到最后一个节点，回溯时反转指向。

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null)
            return head;
        ListNode cur = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return cur;
    }
}
```

## 题解(头插法)
不创建新节点，循环将 head.next 摘下插入到头部。

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null)
        return head;
    ListNode cur = head;
    while (head.next != null) {
        ListNode tail = head.next.next;
        head.next.next = cur;
        cur = head.next;
        head.next = tail;
    }
    return cur;
}
```

## 对比
与 反转链表II 的区别：II 只反转指定区间 [m,n]
与 K个一组翻转链表 的区别：K个一组是分段反转
与 重排链表 的区别：重排需要先找中点，只反转后半部分
