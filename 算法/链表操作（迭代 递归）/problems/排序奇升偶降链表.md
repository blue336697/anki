# 排序奇升偶降链表

## 题干
给定一个奇数位升序、偶数位降序的链表，将其重新排序为全升序。
输入: 1->8->3->6->5->4->7->2->NULL
输出: 1->2->3->4->5->6->7->8->NULL

## 复杂度
时间：O(n) — 三次遍历（分离+反转+合并）
空间：O(1)

## 关键技巧
组合题 = 奇偶链表 + 反转链表 + 合并两个有序链表
1. 分离奇数链表（升序）和偶数链表（降序）
2. 反转偶数链表（降序→升序）
3. 合并两个升序链表（同 合并两个有序链表）

## 题解
三步组合：分离奇偶、反转偶数、合并有序。

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null)
            return head;
        ListNode dummy = head;
        ListNode evenHead = head.next;
        ListNode even = evenHead;
        while (even != null && even.next != null) {
            dummy.next = even.next;
            dummy = dummy.next;
            even.next = dummy.next;
            even = even.next;
        }
        evenHead = reverse(evenHead);
        head = mergeTwoLists(evenHead, head);
        return head;
    }

    public ListNode reverse(ListNode node) {
        ListNode pre = null;
        ListNode cur = node;
        ListNode tail = null;
        while (cur != null) {
            tail = cur.next;
            cur.next = pre;
            pre = cur;
            cur = tail;
        }
        return pre;
    }

    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode res = new ListNode(-1);
        ListNode preNode = res;
        if (l1 == null && l2 == null)
            return null;
        ListNode temp01 = l1;
        ListNode temp02 = l2;
        while (temp01 != null && temp02 != null) {
            if (temp01.val < temp02.val) {
                preNode.next = temp01;
                temp01 = temp01.next;
            } else {
                preNode.next = temp02;
                temp02 = temp02.next;
            }
            preNode = preNode.next;
        }
        preNode.next = temp01 == null ? temp02 : temp01;
        return res.next;
    }
}
```

## 对比
与 奇偶链表 的区别：后者只分离不反转不合并
本题集成了三个子问题的解法，是经典的综合题
