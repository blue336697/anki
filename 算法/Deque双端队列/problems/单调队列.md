# 单调队列（Monotonic Deque）

## 什么是单调队列
队列中元素{{c1::始终保持单调递增或单调递减}}。每次加入新元素时，从队尾弹出所有破坏单调性的元素再入队。

Deque 是实现单调队列的唯一选择 — {{c2::需要同时操作队头（弹出过期元素）和队尾（弹出破坏单调的元素）}}。

## 核心操作（以单调递减为例）
```java
Deque<Integer> dq = new ArrayDeque<>();

// 入队：从队尾弹出所有小于新元素的值
while (!dq.isEmpty() && dq.peekLast() < newVal) {
    dq.pollLast();            // 尾部弹出
}
dq.offerLast(newVal);         // 尾部入队

// 过期处理：队头元素超出窗口范围
if (!dq.isEmpty() && dq.peekFirst() == outOfWindowVal) {
    dq.pollFirst();           // 头部弹出
}

// 查询最大值：队头始终是当前窗口最大
int max = dq.peekFirst();
```

## 经典题目：滑动窗口最大值（239）
给定数组 nums 和窗口大小 k，返回每个窗口的最大值。

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n - k + 1];
    // 存下标，保证单调递减
    Deque<Integer> dq = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 1. 队头过期（超出窗口左边界）
        if (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
            dq.pollFirst();
        }
        // 2. 维护单调递减
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) {
            dq.pollLast();
        }
        // 3. 当前元素入队
        dq.offerLast(i);
        // 4. 窗口形成后记录答案
        if (i >= k - 1) {
            res[i - k + 1] = nums[dq.peekFirst()];
        }
    }
    return res;
}
```

## 为什么存下标而非值
{{c1::需要判断队头是否过期（下标 < i - k + 1），用值无法判断}}。

## 复杂度
时间：{{c1::O(n)}} — 每个元素入队一次、出队一次
空间：{{c2::O(k)}} — Deque 最多存 k 个元素

## 单调栈 vs 单调队列
| | 单调栈 | 单调队列 |
|------|------|------|
| 容器 | Deque/Stack | Deque（唯一） |
| 维护 | 一端进出 | 两端操作 |
| 典型题 | 下一个更大元素、每日温度 | 滑动窗口最大值 |
| 弹元素 | 栈顶弹 | {{c1::队尾弹（维护单调）+ 队头弹（处理过期）}} |

## 适用场景信号
- {{c1::"滑动窗口 + 最大值/最小值"}}
- {{c2::"区间最值 + 动态变化"}}
- {{c3::需要快速查询区间极值}} 但不需要线段树
