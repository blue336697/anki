# Deque 当栈和队列使用

## Deque 当栈用（替代 Stack）
Java 官方推荐用 Deque 替代旧的 `java.util.Stack` 类。

```java
Deque<Integer> stack = new ArrayDeque<>();

// 入栈
stack.push(1);          // addFirst
stack.push(2);
stack.push(3);          // 栈: 3 → 2 → 1 (顶→底)

// 出栈
int top = stack.pop();  // removeFirst, 返回3

// 查看栈顶（不弹出）
int peek = stack.peek(); // peekFirst, 返回2
```

{{c1::push(e) = addFirst(e); pop() = removeFirst(); peek() = peekFirst()}}

## Deque 当队列用（替代 LinkedList）
```java
Deque<Integer> queue = new ArrayDeque<>();

// 入队（尾部）
queue.offer(1);         // offerLast
queue.offer(2);
queue.offer(3);         // 队列: 1 → 2 → 3 (头→尾)

// 出队（头部）
int head = queue.poll(); // pollFirst, 返回1

// 查看队头（不弹出）
int front = queue.peek(); // peekFirst, 返回2
```

{{c2::offer(e) = offerLast(e); poll() = pollFirst(); peek() = peekFirst()}}

## Deque 当双端队列（完整能力）
```java
Deque<Integer> dq = new ArrayDeque<>();
dq.offerFirst(1);  // 头部插入: [1]
dq.offerLast(2);   // 尾部插入: [1, 2]
dq.offerFirst(3);  // 头部插入: [3, 1, 2]

int first = dq.pollFirst(); // 头部取出: 3
int last  = dq.pollLast();  // 尾部取出: 2
```

## 与传统类的对比
| | ArrayDeque | Stack | LinkedList(队列) |
|------|:--:|:--:|:--:|
| 推荐程度 | ✅ 推荐 | ❌ 不推荐 | ⚠️ 可用但笨重 |
| 线程安全 | ❌ | ✅ (synchronized) | ❌ |
| 性能 | 最快 | 慢（同步开销） | 中（Node开销） |

## 为什么 Stack 被淘汰
1. {{c1::继承自 Vector，方法都加了 synchronized，即使单线程也有锁开销}}
2. {{c2::基于数组，扩容策略不如 ArrayDeque 高效}}
3. {{c3::违反 LIFO 语义——它是 Vector 的子类，可以按索引访问}}

## 遍历 Deque
```java
// 正向（头→尾）
for (int x : dq) { }

// 反向（尾→头）
Iterator<Integer> it = dq.descendingIterator();
while (it.hasNext()) { int x = it.next(); }
```

## 算法中的选型
- 需要栈 → {{c1::ArrayDeque push/pop/peek}}
- 需要队列 → {{c2::ArrayDeque offer/poll/peek}}
- 需要双端操作 → {{c3::ArrayDeque offerFirst/pollLast 等}}
- 需要线程安全双端队列 → {{c4::LinkedBlockingDeque}}
