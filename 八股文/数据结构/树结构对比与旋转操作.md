# 树结构对比与旋转操作

> 面试中常被要求口头描述"删除BST节点怎么做？AVL怎么旋转？红黑树怎么rebalance？"
> 本文提供**对比总表 + 每种树的增删旋转伪代码**，覆盖 BST / AVL / 红黑树 / B树 / B+树。

---

## 1. 五种树结构对比总表

| 维度 | BST | AVL | 红黑树 | B树 | B+树 |
|------|-----|-----|--------|-----|------|
| **平衡方式** | 无 | 严格平衡，\|bf\|≤1 | 宽松平衡，黑高一致 | 所有叶子同层 | 所有叶子同层 |
| **节点结构** | val+left+right | val+left+right+height | val+left+right+color | keys[]+children[]+isLeaf | 内节点keys[]+children[]；叶子keys[]+data[]+next |
| **高度范围** | n ~ 1 | 1.44log(n+1)~log n | 2log(n+1)~log n | ≤ log_m(n) | ≤ log_m(n) |
| **查找** | O(n) | O(log n) | O(log n) | O(log n) | O(log n) |
| **插入** | O(n) | O(log n)，需旋转 | O(log n)，变色+≤2次旋转 | O(log n)，需分裂 | O(log n)，需分裂 |
| **删除** | O(n) | O(log n)，可能O(log n)次旋转 | O(log n)，变色+≤3次旋转 | O(log n)，需合并/借位 | O(log n)，需合并/借位 |
| **插入触发旋转上限** | 0 | 1次 | 2次 | 0（仅分裂） | 0（仅分裂） |
| **删除触发旋转上限** | 0 | O(log n)次 | 3次 | 0（仅合并） | 0（仅合并） |
| **存储位置** | 内存 | 内存 | 内存 | 磁盘 | 磁盘 |
| **工程实例** | 教学 | 查找密集场景 | Java TreeMap, Linux CFS, epoll | MongoDB 索引 | MySQL InnoDB, PostgreSQL |

### 平衡策略一句话

| 树 | 核心平衡手段 |
|----|-------------|
| **AVL** | 高度差>1立即旋转，严格平衡→查找快，写代价高 |
| **红黑树** | 最长路径≤2×最短路径，变色优先旋转兜底→写代价低 |
| **B树** | 节点key数∈[⌈m/2⌉-1, m-1]，溢出分裂，下溢合并/借位 |
| **B+树** | 同B树，但内节点仅存key（扇出更大），数据全在叶子，叶子有链表 |

## 2. 通用旋转操作（左旋/右旋）

AVL 和红黑树的旋转操作**完全一致**，仅触发条件不同。旋转前后**中序遍历不变**。

```
     y                                x
    / \     Right Rotate (y)         / \
   x   T3   ──────────────────>     T1   y
  / \       <──────────────────         / \
 T1  T2     Left Rotate (x)           T2   T3
```

### 右旋（Right Rotate）— LL 场景

```
ROTATE_RIGHT(y):
    x  = y.left          // x 是 y 的左孩子
    T2 = x.right         // 保存 x 的右子树（将被挂在 y 下）
    x.right = y          // y 成为 x 的右孩子
    y.left  = T2         // T2 成为 y 的左孩子
    // AVL 需更新 y 和 x 的高度（红黑树不需要）
    UPDATE_HEIGHT(y)
    UPDATE_HEIGHT(x)
    return x             // 返回新根
```

### 左旋（Left Rotate）— RR 场景

```
ROTATE_LEFT(x):
    y  = x.right         // y 是 x 的右孩子
    T2 = y.left          // 保存 y 的左子树（将被挂在 x 下）
    y.left   = x         // x 成为 y 的左孩子
    x.right  = T2        // T2 成为 x 的右孩子
    // AVL 需更新 x 和 y 的高度（红黑树不需要）
    UPDATE_HEIGHT(x)
    UPDATE_HEIGHT(y)
    return y             // 返回新根
```

> **T2 为什么挂得对？** T2 中的所有值在 x 和 y 之间（x < T2 < y），旋转后 T2 挂在 x.right（左旋）或 y.left（右旋），BST 性质不变。

## 3. BST 删除 — 三种情况

```
DELETE_BST(root, key):
    if root == null:
        return null

    if key < root.val:
        root.left = DELETE_BST(root.left, key)
    else if key > root.val:
        root.right = DELETE_BST(root.right, key)
    else:
        // ===== 找到待删除节点 =====
        // 情况1: 无左子 → 右子直接顶替
        if root.left == null:
            return root.right

        // 情况2: 无右子 → 左子直接顶替
        if root.right == null:
            return root.left

        // 情况3: 双子都存在 → 找后继，交换值，递归删后继
        successor = GET_MIN(root.right)          // 右子树最左节点
        root.val = successor.val                 // 交换值
        root.right = DELETE_BST(root.right, successor.val)  // 递归删后继
        // 后继一定没有左孩子，递归删它只会走情况1或2，最多递归一层

    return root

GET_MIN(node):
    while node.left != null:
        node = node.left
    return node
```

## 4. AVL 树 — 插入与删除

### 4.1 高度函数与平衡因子

```
HEIGHT(node):
    if node == null:  return 0
    return max(HEIGHT(node.left), HEIGHT(node.right)) + 1

BALANCE_FACTOR(node) = HEIGHT(node.left) - HEIGHT(node.right)
// BF ∈ {-1, 0, 1} → 平衡；超出 → 旋转
```

### 4.2 四种旋转场景速查

| 场景 | 条件 | 操作 | 形状特征 |
|------|------|------|---------|
| **LL** | BF(root)>1 且 BF(root.left)≥0 | 右旋(root) | 左子偏左 |
| **RR** | BF(root)<-1 且 BF(root.right)≤0 | 左旋(root) | 右子偏右 |
| **LR** | BF(root)>1 且 BF(root.left)<0 | 左旋(root.left)→右旋(root) | 左子偏右 |
| **RL** | BF(root)<-1 且 BF(root.right)>0 | 右旋(root.right)→左旋(root) | 右子偏左 |

> **记忆法**：场景名的第二个字母是"突出的方向"（L=左高, R=右高），第一个字母是"突出发生在哪边"。如 **LR = Left子树的Right侧突出** → 先左旋Left子（摆直）→再右旋根。

### 4.3 AVL 插入

```
INSERT_AVL(root, key):
    // 1. 标准BST插入
    if root == null:
        return NEW_NODE(key)
    if key < root.val:
        root.left = INSERT_AVL(root.left, key)
    else if key > root.val:
        root.right = INSERT_AVL(root.right, key)
    else:
        return root   // 不允许重复

    // 2. 更新高度
    UPDATE_HEIGHT(root)

    // 3. 检查平衡
    bf = BF(root)

    // LL
    if bf > 1 and key < root.left.val:
        return ROTATE_RIGHT(root)
    // RR
    if bf < -1 and key > root.right.val:
        return ROTATE_LEFT(root)
    // LR
    if bf > 1 and key > root.left.val:
        root.left = ROTATE_LEFT(root.left)
        return ROTATE_RIGHT(root)
    // RL
    if bf < -1 and key < root.right.val:
        root.right = ROTATE_RIGHT(root.right)
        return ROTATE_LEFT(root)

    return root
```

> 插入后最多 **1次旋转** 即可恢复平衡。

### 4.4 AVL 删除

```
DELETE_AVL(root, key):
    // 1. 标准BST删除
    if root == null:  return null
    if key < root.val:
        root.left = DELETE_AVL(root.left, key)
    else if key > root.val:
        root.right = DELETE_AVL(root.right, key)
    else:
        if root.left == null or root.right == null:
            root = root.left if root.left else root.right  // 单子/无子直接顶替
        else:
            successor = GET_MIN(root.right)
            root.val = successor.val
            root.right = DELETE_AVL(root.right, successor.val)

    if root == null:  return null

    // 2. 更新高度
    UPDATE_HEIGHT(root)

    // 3. 旋转（注意：删除时不能靠key判断，要直接看子树的BF）
    bf = BF(root)

    // LL
    if bf > 1 and BF(root.left) >= 0:
        return ROTATE_RIGHT(root)
    // LR
    if bf > 1 and BF(root.left) < 0:
        root.left = ROTATE_LEFT(root.left)
        return ROTATE_RIGHT(root)
    // RR
    if bf < -1 and BF(root.right) <= 0:
        return ROTATE_LEFT(root)
    // RL
    if bf < -1 and BF(root.right) > 0:
        root.right = ROTATE_RIGHT(root.right)
        return ROTATE_LEFT(root)

    return root
```

> 与插入的关键区别：删除可能需沿路径向上回溯旋转 **O(log n) 次**，因为子树高度-1可能破坏更高层的平衡。

## 5. 红黑树 — 插入与删除

### 5.1 五条性质（必须背）

1. 节点是红色或黑色
2. 根节点是黑色
3. 叶子（NIL）是黑色
4. 红色节点的两个孩子必须是黑色（**不能连续两个红**）
5. 从任意节点到其所有后代叶子的路径上，黑色节点数量相同（**黑高一致**）

### 5.2 红黑树插入

**策略**：新节点默认红色 → 父黑无事 → 父红则修复（变色为主，旋转兜底）。

```
INSERT_RBT(root, key):
    root = BST_INSERT(root, key)
    root.color = RED
    root = FIX_INSERT(root, root)    // 修复传入的是新节点
    root.color = BLACK               // 保证根始终黑
    return root

FIX_INSERT(root, node):
    while node.parent != null and node.parent.color == RED:

        if node.parent == node.parent.parent.left:   // 父是左孩子
            uncle = node.parent.parent.right

            // Case 1: 叔叔是红色 → 变色上推（不旋转）
            if uncle != null and uncle.color == RED:
                node.parent.color = BLACK
                uncle.color = BLACK
                node.parent.parent.color = RED
                node = node.parent.parent     // 问题上移
                continue

            // Case 2: LR → 左旋父节点，转为Case 3
            if node == node.parent.right:
                node = node.parent
                ROTATE_LEFT(node)

            // Case 3: LL → 父变黑、祖父变红、右旋祖父（终结）
            node.parent.color = BLACK
            node.parent.parent.color = RED
            ROTATE_RIGHT(node.parent.parent)

        else:   // 父是右孩子（镜像对称）
            uncle = node.parent.parent.left

            if uncle != null and uncle.color == RED:
                node.parent.color = BLACK
                uncle.color = BLACK
                node.parent.parent.color = RED
                node = node.parent.parent
                continue

            if node == node.parent.left:       // RL → 先右旋
                node = node.parent
                ROTATE_RIGHT(node)

            node.parent.color = BLACK          // RR → 父黑、祖父红、左旋
            node.parent.parent.color = RED
            ROTATE_LEFT(node.parent.parent)

    while root.parent != null:   // 确保root引用始终指向根
        root = root.parent
    return root
```

> 插入总结：**最多2次旋转**（LR/RL场景），多数情况仅变色。

### 5.3 红黑树删除

**策略**：先BST删除 → 若删了黑色节点，从兄弟"借黑"修复双黑。

```
DELETE_RBT(root, key):
    // 1. BST删除：找到要物理删除的节点
    node = FIND(root, key)
    if node.left != null and node.right != null:
        successor = GET_MIN(node.right)
        node.val = successor.val
        node = successor       // 实际删除后继（最多一个子节点）

    child = node.left if node.left != null else node.right
    deletedColor = node.color
    REPLACE(node, child)       // child顶替node（链表操作）

    // 2. 修复：删黑色才需修复
    if deletedColor == BLACK:
        if child != null and child.color == RED:
            child.color = BLACK           // 红孩子直接变黑补偿
        else:
            FIX_DELETE(root, child)       // 双黑修复

FIX_DELETE(root, node):    // node是"双黑"节点
    while node != root and (node == null or node.color == BLACK):
        if node == node.parent.left:
            sibling = node.parent.right

            // Case 1: 兄弟红色 → 兄弟变黑，父变红，左旋父 → 转Case 2/3/4
            if sibling.color == RED:
                sibling.color = BLACK
                node.parent.color = RED
                ROTATE_LEFT(node.parent)
                sibling = node.parent.right

            // Case 2: 兄弟黑+两侄都黑 → 兄弟变红，问题上推父节点
            if (sibling.left == null or sibling.left.color == BLACK) and
               (sibling.right == null or sibling.right.color == BLACK):
                sibling.color = RED
                node = node.parent
                continue

            // Case 3: 兄弟黑+左侄红+右侄黑 → 左侄变黑，兄弟变红，右旋兄弟 → 转Case 4
            if sibling.right == null or sibling.right.color == BLACK:
                sibling.left.color = BLACK
                sibling.color = RED
                ROTATE_RIGHT(sibling)
                sibling = node.parent.right

            // Case 4: 兄弟黑+右侄红 → 兄弟取父色，父变黑，右侄变黑，左旋父（终结）
            sibling.color = node.parent.color
            node.parent.color = BLACK
            sibling.right.color = BLACK
            ROTATE_LEFT(node.parent)
            node = root   // 修复完成

        else:   // node是右孩子（镜像对称，省略）
            // ...
            pass

    if node != null:
        node.color = BLACK
```

> 删除总结：**最多3次旋转**。最坏路径：Case1（旋转）→ Case2（不变，上推）→ Case3（旋转）→ Case4（旋转，终结）。

### 5.4 红黑树 vs AVL 工程选型

| | AVL | 红黑树 |
|---|-----|--------|
| 平衡严格度 | 极严格 | 宽松（最长≤2×最短） |
| 查找性能 | 略优（树更矮） | 略差 |
| 插入代价 | 每次维护高度+旋转 | 多数变色，少旋转 |
| 删除代价 | 可能 O(log n) 次旋转 | ≤3次旋转 |
| 适合场景 | 查找远多于写 | 读写混合/写多 |
| Java 实例 | — | TreeMap, TreeSet, HashMap(JDK8+) |

## 6. B树 — 插入与删除

### 6.1 B树定义（m阶）

- 根节点：至少2个子节点（非叶子时），至少1个key
- 内节点：key数 ∈ [⌈m/2⌉-1, m-1]，子节点数 = key数 + 1
- 所有叶子同层
- 节点内 key 升序

### 6.2 B树插入（分裂 Split）

```
INSERT_BTREE(root, key):
    // 根满了先分裂根
    if root.keyCount == m - 1:
        newRoot = NEW_NODE()
        newRoot.isLeaf = false
        newRoot.children[0] = root
        SPLIT_CHILD(newRoot, 0)
        root = newRoot

    INSERT_NONFULL(root, key)

INSERT_NONFULL(node, key):
    i = node.keyCount - 1
    if node.isLeaf:
        // 在合适位置插入（节点保证不满）
        while i >= 0 and key < node.keys[i]:
            node.keys[i+1] = node.keys[i]; i--
        node.keys[i+1] = key
        node.keyCount++
    else:
        // 找到对应子节点
        while i >= 0 and key < node.keys[i]:
            i--
        i++
        // 子节点满了先分裂
        if node.children[i].keyCount == m - 1:
            SPLIT_CHILD(node, i)
            if key > node.keys[i]:
                i++
        INSERT_NONFULL(node.children[i], key)


SPLIT_CHILD(parent, idx):
    // 将 children[idx] 一分为二，mid key上升到parent
    fullChild = parent.children[idx]
    newChild  = NEW_NODE()
    newChild.isLeaf = fullChild.isLeaf
    t = ceil(m / 2)

    midKey = fullChild.keys[t - 1]

    // 右半[t, 2t-2] → newChild
    COPY_KEYS(fullChild, t, newChild, 0, t - 1)
    if not fullChild.isLeaf:
        COPY_CHILDREN(fullChild, t, newChild, 0, t)
    fullChild.keyCount = t - 1
    newChild.keyCount  = t - 1

    // parent中插入midKey和newChild指针
    INSERT_KEY_AND_CHILD(parent, idx, midKey, newChild)
```

### 6.3 B树删除（借位 Borrow / 合并 Merge）

```
DELETE_BTREE(node, key):
    idx = FIND_KEY_INDEX(node, key)

    if idx < node.keyCount and node.keys[idx] == key:
        // ==== key在当前节点 ====
        if node.isLeaf:
            REMOVE_FROM_LEAF(node, idx)          // 叶子直接删
        else:
            DELETE_FROM_INTERNAL(node, idx)      // 内节点用前驱/后继替换再递归删
    else:
        // ==== key在子树 ====
        if node.isLeaf: return   // 没找到
        child = node.children[idx]
        if child.keyCount == t - 1:   // 子节点将下溢，先填充
            FILL_CHILD(node, idx)
        DELETE_BTREE(node.children[corrected_idx], key)


DELETE_FROM_INTERNAL(node, idx):
    key = node.keys[idx]
    // 优先左子借前驱
    if node.children[idx].keyCount >= t:
        pred = GET_MAX(node.children[idx])
        node.keys[idx] = pred
        DELETE_BTREE(node.children[idx], pred)
    // 否则右子借后继
    else if node.children[idx+1].keyCount >= t:
        succ = GET_MIN(node.children[idx+1])
        node.keys[idx] = succ
        DELETE_BTREE(node.children[idx+1], succ)
    // 都不够 → 合并key+左右子，从合并节点删
    else:
        MERGE_CHILDREN(node, idx)
        DELETE_BTREE(node.children[idx], key)


FILL_CHILD(node, idx):
    // 保证 children[idx] 有 ≥ t 个key
    if idx > 0 and node.children[idx-1].keyCount >= t:
        BORROW_FROM_LEFT(node, idx)                       // 左兄弟借
    else if idx < node.keyCount and node.children[idx+1].keyCount >= t:
        BORROW_FROM_RIGHT(node, idx)                      // 右兄弟借
    else:
        MERGE_CHILDREN(node, min(idx, node.keyCount-1))   // 合并


BORROW_FROM_LEFT(node, idx):
    child = node.children[idx]
    left  = node.children[idx-1]
    // child腾出第一位，父key下放，左兄弟尾key上升
    SHIFT_RIGHT(child.keys, 0, child.keyCount)
    if not child.isLeaf:
        SHIFT_RIGHT(child.children, 0, child.keyCount+1)
    child.keys[0] = node.keys[idx-1]
    if not child.isLeaf:
        child.children[0] = left.children[left.keyCount]
    node.keys[idx-1] = left.keys[left.keyCount-1]
    child.keyCount++
    left.keyCount--


MERGE_CHILDREN(node, idx):
    // 将 children[idx]、node.keys[idx]、children[idx+1] 合并到 children[idx]
    left  = node.children[idx]
    right = node.children[idx+1]
    left.keys[left.keyCount] = node.keys[idx]    // 父key下沉
    left.keyCount++
    COPY_ALL(right, left, left.keyCount)          // right全部拷入left
    left.keyCount += right.keyCount
    REMOVE_KEY_AND_CHILD(node, idx)               // 父节点删除idx处key和child
```

## 7. B+树 — 与B树的关键差异

### 结构差异

```
B+树内节点：仅存key+子指针（不存data）→ 扇出更大 → 树更矮
B+树叶子节点：存key+data（或指针），有next链表连接 → 支持范围扫描
```

### 插入差异

- 分裂叶子时：mid key **上升**到父节点，但叶子层**也保留**该key在右半（因为数据全在叶子）
- 分裂内节点：与B树相同

```
// B树叶子分裂:  左[t-1] | mid(上升) | 右[t-1]
// B+树叶子分裂: 左[t]   | mid(上升) | 右[t]   ← 叶子保留mid
```

### 删除差异

- 内节点的 key 删除后**可保留**作为路标（数据不在内节点，不影响正确性）
- 叶子删除触发下溢时，合并后需更新父节点索引

### B树 vs B+树 工程选择

| | B树 | B+树 |
|---|-----|------|
| 数据位置 | 每个节点都能存data | 仅叶子存data |
| 等值查询 | 可能在非叶层直接命中 | 必须走到叶子 |
| 范围查询 | 需中序遍历（跨层） | 叶子链表 O(1) 跨页扫描 |
| 扇出 | 低（节点含data） | 高（节点仅key）→ 树更矮 |
| 典型产品 | MongoDB | MySQL InnoDB, PostgreSQL |

## 8. 面试速记卡

### 旋转本质

```
左旋：右孩子上提，原根变成左孩子
右旋：左孩子上提，原根变成右孩子
旋转前后中序遍历不变！
```

### 各种树的工程实例

| 场景 | 使用的树 |
|------|---------|
| Java TreeMap / TreeSet | 红黑树 |
| Java HashMap (JDK8+，链表→树) | 红黑树 |
| Linux CFS 完全公平调度器 | 红黑树 |
| Linux epoll 事件管理 | 红黑树 |
| MySQL InnoDB 索引 | B+树 |
| PostgreSQL 索引 | B+树 |
| MongoDB 索引 | B树 |
| 查找多写入少（内存） | AVL |
| 读写混合（内存） | 红黑树 |
| 磁盘存储，需范围查询 | B+树 |
| 磁盘存储，等值查询为主 | B树/B+树均可 |
