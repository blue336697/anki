# Lombok相关

### **1、@RequiredArgsConstructor注解**

`@RequiredArgsConstructor`是Lombok库提供的一个注解，它会自动为类生成一个构造函数。这个构造函数的参数是类中所有需要初始化的字段，也就是说，所有final字段和所有被`@NonNull`注解的非final字段。`@RequiredArgsConstructor`可以帮助你减少编写构造函数的代码，特别是当你的类有很多需要初始化的字段时。

```java
//例如，考虑以下的Java类：
 
import lombok.RequiredArgsConstructor;
 
@RequiredArgsConstructor
public class MyClass {
    private final String field1;
    private final int field2;
    private String field3;
}
 
//在这个例子中，Lombok会为MyClass生成以下的构造函数：
//这个构造函数的参数是field1和field2，因为它们是final字段。field3不是final字段，所以它不在构造函数的参数列表中。
public MyClass(String field1, int field2) {
    this.field1 = field1;
    this.field2 = field2;
}
```

### **2、@Generated注解**

`@Generated`注解在Java中用于标识某些代码片段是由程序自动生成的，而不是由开发者手动编写的。这个注解主要有以下几个作用：

1. **文档目的**：为自动生成的代码提供文档说明。通过使用`@Generated`注解，开发者可以快速识别出哪些代码是自动生成的，这对于代码的阅读和维护非常有帮助。
2. **编译器优化**：某些情况下，编译器可能会对标有`@Generated`注解的代码进行特殊处理，例如跳过某些编译警告。
3. **代码分析工具**：代码分析工具或静态代码检查工具可能会忽略带有`@Generated`注解的代码块，因为这些代码块通常不需要人工审查代码质量或风格问题。
4. **辅助代码审查**：在代码审查过程中，审查者可以快速识别出哪些代码是自动生成的，从而将注意力集中在手写的代码上。

`@Generated`注解通常包含几个属性，如`value`用于指定生成代码的源（例如工具或插件的名称），`date`用于指定代码生成的日期，`comments`用于提供额外的说明。不过，具体支持哪些属性可能依赖于具体的JDK版本。

示例：

```java
import javax.annotation.Generated;
 
@Generated(value="CodeGenerator", date="2023-04-01", comments="自动生成的映射类")
public class AutoGeneratedClass {
    // 自动生成的代码
}
```

需要注意的是，`@Generated`注解可能不在所有Java版本中都可用，它在`javax.annotation`包中，这个包可能需要单独添加依赖（如Java EE或Jakarta EE环境中）。在某些Java版本中，可能需要使用`javax.annotation.processing.Generated`替代。

## 3、@SneakyThrows

@SneakyThrows 是 Lombok 提供的注解，用于**绕过 Java 的检查型异常处理机制**，让你不必显式地捕获或声明异常。

## **🎯 主要作用**

**解决的问题**

Java 中的检查型异常（如 IOException, SQLException 等）必须被显式处理，但有时这会让代码变得冗长。

```java
public class TraditionalExample {
    
    // 方式1：捕获异常
    public String readFile(String filePath) {
        try {
            return Files.readString(Paths.get(filePath));
        } catch (IOException e) {
            throw new RuntimeException("读取文件失败", e);
        }
    }
    
    // 方式2：声明异常
    public String readFileWithThrows(String filePath) throws IOException {
        return Files.readString(Paths.get(filePath));
    }
    
    // 方式3：多个异常处理
    public void databaseOperation() {
        try {
            Connection conn = DriverManager.getConnection("jdbc:mysql://...");
            PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users");
            ResultSet rs = stmt.executeQuery();
            // 处理结果...
        } catch (SQLException e) {
            throw new RuntimeException("数据库操作失败", e);
        }
    }
}
```

使用后

```java
import lombok.SneakyThrows;

public class SneakyThrowsExample {
    
    // 简洁的文件读取
    @SneakyThrows
    public String readFile(String filePath) {
        return Files.readString(Paths.get(filePath));
    }
    
    // 简洁的数据库操作
    @SneakyThrows
    public void databaseOperation() {
        Connection conn = DriverManager.getConnection("jdbc:mysql://...");
        PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users");
        ResultSet rs = stmt.executeQuery();
        // 处理结果...
    }
    
    // 多个操作组合
    @SneakyThrows
    public UserData processUser(String userId) {
        // 文件操作 - 可能抛出 IOException
        String config = Files.readString(Paths.get("config.json"));
        
        // 网络请求 - 可能抛出 IOException
        URL url = new URL("http://api.example.com/user/" + userId);
        String response = new String(url.openStream().readAllBytes());
        
        // JSON解析 - 可能抛出各种异常
        ObjectMapper mapper = new ObjectMapper();
        return mapper.readValue(response, UserData.class);
    }
}
```

避免滥用

```java
// ❌ 错误用法：隐藏重要的业务异常
@SneakyThrows
public void validateUser(User user) {
    if (user.getAge() < 18) {
        throw new IllegalArgumentException("用户年龄不能小于18岁");
    }
    // 这种业务异常应该被明确处理，而不是偷偷抛出
}

// ✅ 正确用法：只用于技术性异常
@SneakyThrows(IOException.class)
public UserConfig loadUserConfig(String userId) {
    String configJson = Files.readString(Paths.get("configs/" + userId + ".json"));
    return JsonUtils.fromJson(configJson, UserConfig.class);
}
```

## 4、@SuperBuilder注解

@SuperBuilder 是 Lombok 提供的注解，用于**解决继承关系中使用 Builder 模式的问题**。普通的 @Builder 在继承场景下有局限性，@SuperBuilder 可以完美处理继承链中的 Builder 模式。

## **🎯 主要作用**

**解决的问题**

当类存在继承关系时，普通的 @Builder 无法正确构建包含父类字段的对象，@SuperBuilder 解决了这个痛点。

```java
// 父类
public class Person {
    private String name;
    private int age;
    
    // 手写构造器和 Builder
    public static class PersonBuilder {
        private String name;
        private int age;
        
        public PersonBuilder name(String name) {
            this.name = name;
            return this;
        }
        
        public PersonBuilder age(int age) {
            this.age = age;
            return this;
        }
        
        public Person build() {
            Person person = new Person();
            person.name = this.name;
            person.age = this.age;
            return person;
        }
    }
    
    public static PersonBuilder builder() {
        return new PersonBuilder();
    }
}

// 子类
public class Employee extends Person {
    private String department;
    private double salary;
    
    // 手写复杂的 Builder，需要继承父类的 Builder
    public static class EmployeeBuilder extends PersonBuilder {
        private String department;
        private double salary;
        
        public EmployeeBuilder department(String department) {
            this.department = department;
            return this;
        }
        
        public EmployeeBuilder salary(double salary) {
            this.salary = salary;
            return this;
        }
        
        @Override
        public Employee build() {
            Employee employee = new Employee();
            // 需要手动设置父类字段
            employee.name = this.name;
            employee.age = this.age;
            employee.department = this.department;
            employee.salary = this.salary;
            return employee;
        }
    }
    
    public static EmployeeBuilder builder() {
        return new EmployeeBuilder();
    }
}
```

使用后

```java
import lombok.SuperBuilder;
import lombok.Data;

// 父类
@Data
@SuperBuilder
public class Person {
    private String name;
    private int age;
}

// 子类
@Data
@SuperBuilder
public class Employee extends Person {
    private String department;
    private double salary;
}

// 使用方式
Employee employee = Employee.builder()
    .name("张三")           // 父类字段
    .age(28)              // 父类字段
    .department("技术部")   // 子类字段
    .salary(15000.0)      // 子类字段
    .build();
```
