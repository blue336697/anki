# 关于分布式缓存中间件（Redis、Redisson、Lettuce、Jedis）的一些问题

## Lettuce

### **1、`.disconnectedBehavior(ClientOptions.DisconnectedBehavior.DEFAULT)和.disconnectedBehavior(ClientOptions.DisconnectedBehavior.REJECT_COMMANDS)`**

`ClientOptions.DisconnectedBehavior`是一个枚举，定义了当客户端与服务器断开连接时的行为。它有两个值：`REJECT_COMMANDS`和`DEFAULT`。

1. `REJECT_COMMANDS`：当客户端与服务器断开连接时，所有尝试发送的命令都会被立即拒绝，通常会抛出一个异常。这是一种保守的策略，可以防止在连接断开时发送无法处理的命令。
2. `DEFAULT`：当客户端与服务器断开连接时，客户端会尝试重新连接，并将命令缓存起来，等待连接恢复后再发送。这是一种更积极的策略，可以在连接恢复后继续处理命令。

你应该根据你的应用的需求和容错策略来选择合适的`DisconnectedBehavior`。如果你的应用不能容忍在连接断开时发送命令，你应该选择`REJECT_COMMANDS`。如果你的应用需要在连接恢复后继续处理命令，你应该选择`DEFAULT`。

## Redis

### **1、mget以及长尾延迟**

`mget`是一种常见的批量获取数据的操作，它可以一次性获取多个键（key）对应的值（value）。在分布式系统中，`mget`操作可以显著减少网络延迟，提高数据获取的效率。

然而，`mget`操作也可能会遇到长尾延迟（tail latency）的问题。长尾延迟是指在一组请求中，大部分请求的响应时间都很短，但是有少数请求的响应时间却异常长。这种情况下，即使大部分请求都很快完成，但是整个`mget`操作的完成时间仍然会被那些延迟高的请求所主导。

解决长尾延迟的一种常见策略是冗余请求（redundant requests）。也就是说，对于每个键，我们不只向一个节点发送请求，而是向多个节点发送请求。然后，我们使用第一个收到的响应，忽略后续的响应。这样，即使某个节点的响应延迟，也不会影响整个`mget`操作的完成时间。

另一种策略是使用更复杂的负载均衡算法，例如加权随机或者最少连接，以避免将所有请求都发送到一个可能已经过载的节点上。

这些策略可以单独使用，也可以结合使用，具体取决于系统的需求和环境。

tips：对于redis的mget命令，当获取的key过期了返回的集合会填充null

### **2、当使用mget时，如果获取的多个数据在一致性哈希的情况下分布在不同的节点，这时会发生什么，使用hashtag能够规避吗**

当使用`mget`操作获取多个数据时，如果这些数据在一致性哈希的情况下分布在不同的节点，那么会需要向多个节点发送请求并等待响应，这可能会增加网络延迟和处理复杂性。

在一些分布式存储系统中，例如Redis Cluster，提供了一种叫做`hashtag`的功能，可以将一组相关的键映射到同一个节点。这是通过在键名中包含一个特定的标记（例如`{}`）来实现的。系统会将标记内的字符串作为哈希的输入，因此包含相同标记的键会被映射到同一个节点。

如果你的`mget`操作主要涉及到一组相关的键，那么使用`hashtag`可以有效地减少需要查询的节点数量，从而减少网络延迟和处理复杂性。但是，这需要你在设计数据模型时就考虑到键的分布问题。

**需要注意的是，`hashtag`并不能解决所有问题。例如，如果你需要查询的键分布在多个`hashtag`，那么仍然需要向多个节点发送请求。**（原文在此处截断，后续内容已丢失）

### **3、redis incr命令**

### **这个命令在学习过程中用在生成唯一的计费单号（feeNum）中，可以保证流水号生成以及如何保证多节点部署时的顺序唯一性**

> Redis Incr 命令将 key 中储存的数字值增一。并返回这个新结果，这个过程是原子性的
> 
> - 如果 key 不存在，那么 key 的值会先被初始化为 0 ，然后再执行 INCR 操作。
> - 如果值包含错误的类型，或字符串类型的值不能表示为数字，那么返回一个错误。

```java
/**
 * 生成计费单号
 *
 * @return
 */
public static Long buildFeeNum(JedisCluster jedisCluster) {
    String datePrefix = getDatePrefix(new Date());
    String key = CommonConsts.JF_FEENUM_KEY + "_" + datePrefix;
  
    String feeNum = null;
    try {
        Long increment = jedisCluster.incr(key);
  
        Long datePrefixLong = Long.valueOf(datePrefix + "000");
  
        feeNum = datePrefixLong + increment + "";
    } catch (Exception e) {
        log.error("生成信息试算计费单失败:{}", ExceptionUtils.getStackTrace(e));
    }
    return Long.valueOf(feeNum);
}
```

### **4、redis 管道**

redis的管道本质上就是将命令打包发给服务器处理。在 Redis 集群模式下使用管道（pipeline）批量查询键时，需要注意以下几点：

### **键的分布**

- **哈希槽分布**：在 Redis 集群模式下，键被分布在不同的哈希槽中。管道中的命令必须发送到相同的节点才能有效执行。因此，确保所有键都位于同一个哈希槽中是非常重要的。

### **使用哈希标签**

- **哈希标签**：可以使用哈希标签（hash tags）来确保多个键位于同一个哈希槽中。哈希标签是指在键名中使用 `{}` 包裹的一部分字符串，Redis 集群会根据这个部分字符串计算哈希槽。例如，`{user}:1` 和 `{user}:2` 会被分配到同一个哈希槽。

### **客户端支持**

- **客户端支持**：确保你使用的 Redis 客户端支持集群模式，并且能够正确处理管道命令。大多数现代 Redis 客户端都支持集群模式，但具体实现可能有所不同。

### **错误处理**

- **错误处理**：在管道执行过程中，如果某些键不在同一个哈希槽中，可能会导致部分命令失败。需要在代码中处理这些错误情况。

```java
/**
 * 跳跃表节点
 */
public class SkipListNode {
    
    /** 节点存储的分值，用于排序 */
    private double score;
    
    /** 节点存储的对象值 */
    private String value;
    
    /** 后退指针，指向前一个节点 */
    private SkipListNode backward;
    
    /** 层级数组，每层包含前进指针和跨度 */
    private Level[] levels;
    
    /**
     * 层级结构
     */
    public static class Level {
        /** 前进指针，指向下一个节点 */
        SkipListNode forward;
        
        /** 跨度，记录两个节点之间的距离 */
        int span;
        
        public Level() {
            this.forward = null;
            this.span = 0;
        }
    }
    
    /**
     * 构造函数
     * @param level 节点层数
     * @param score 分值
     * @param value 值
     */
    public SkipListNode(int level, double score, String value) {
        this.score = score;
        this.value = value;
        this.backward = null;
        this.levels = new Level[level];
        
        // 初始化所有层级
        for (int i = 0; i < level; i++) {
            this.levels[i] = new Level();
        }
    }
    
    // Getters and Setters
    public double getScore() { return score; }
    public void setScore(double score) { this.score = score; }
    
    public String getValue() { return value; }
    public void setValue(String value) { this.value = value; }
    
    public SkipListNode getBackward() { return backward; }
    public void setBackward(SkipListNode backward) { this.backward = backward; }
    
    public Level[] getLevels() { return levels; }
    public Level getLevel(int index) { return levels[index]; }
}

/**
 * Redis跳跃表实现
 */
public class RedisSkipList {
    
    /** 最大层数 */
    private static final int MAX_LEVEL = 32;
    
    /** 层数增长概率 */
    private static final double PROBABILITY = 0.25;
    
    /** 头节点 */
    private SkipListNode header;
    
    /** 尾节点 */
    private SkipListNode tail;
    
    /** 跳跃表长度（节点数量，不包括头节点） */
    private long length;
    
    /** 当前跳跃表的最高层数 */
    private int level;
    
    /** 随机数生成器 */
    private Random random;
    
    /**
     * 构造函数
     */
    public RedisSkipList() {
        this.level = 1;
        this.length = 0;
        this.random = new Random();
        
        // 创建头节点，层数为最大层数
        this.header = new SkipListNode(MAX_LEVEL, 0, null);
        this.tail = null;
        
        // 初始化头节点的所有层级
        for (int i = 0; i < MAX_LEVEL; i++) {
            this.header.getLevel(i).forward = null;
            this.header.getLevel(i).span = 0;
        }
        
        this.header.setBackward(null);
    }
    
    /**
     * 随机生成层数
     * @return 随机层数——其实每次都单次掷硬币，正面就层数+1
     */
    private int randomLevel() {
        int level = 1;
        while (random.nextDouble() < PROBABILITY && level < MAX_LEVEL) {
            level++;
        }
        return level;
    }
    
    // Getters
    public SkipListNode getHeader() { return header; }
    public SkipListNode getTail() { return tail; }
    public long getLength() { return length; }
    public int getLevel() { return level; }
}

/**
 * 插入节点到跳跃表
 * @param score 分值
 * @param value 值
 * @return 插入的节点
 */
public SkipListNode insert(double score, String value) {
    // 用于记录每层的前驱节点
    SkipListNode[] update = new SkipListNode[MAX_LEVEL];
    
    // 用于记录每层前驱节点到插入位置的跨度
    int[] rank = new int[MAX_LEVEL];
    
    SkipListNode current = this.header;
    
    // 1. 从最高层开始，寻找插入位置
    for (int i = this.level - 1; i >= 0; i--) {
        // 如果不是最高层，继承上一层的rank值
        rank[i] = (i == this.level - 1) ? 0 : rank[i + 1];
        
        // 在当前层寻找插入位置
        while (current.getLevel(i).forward != null &&
               (current.getLevel(i).forward.getScore() < score ||
                (current.getLevel(i).forward.getScore() == score &&
                 current.getLevel(i).forward.getValue().compareTo(value) < 0))) {
            
            // 累加跨度
            rank[i] += current.getLevel(i).span;
            // 移动到下一个节点
            current = current.getLevel(i).forward;
        }
        
        // 记录每层的前驱节点
        update[i] = current;
    }
    
    // 2. 随机生成新节点的层数
    int newLevel = randomLevel();
    
    // 3. 如果新层数大于当前最大层数，需要更新
    if (newLevel > this.level) {
        for (int i = this.level; i < newLevel; i++) {
            rank[i] = 0;
            update[i] = this.header;
            update[i].getLevel(i).span = (int) this.length;
        }
        this.level = newLevel;
    }
    
    // 4. 创建新节点
    SkipListNode newNode = new SkipListNode(newLevel, score, value);
    
    // 5. 更新各层的指针和跨度
    for (int i = 0; i < newLevel; i++) {
        // 设置新节点的前进指针
        newNode.getLevel(i).forward = update[i].getLevel(i).forward;
        update[i].getLevel(i).forward = newNode;
        
        // 更新跨度
        newNode.getLevel(i).span = update[i].getLevel(i).span - (rank[0] - rank[i]);
        update[i].getLevel(i).span = (rank[0] - rank[i]) + 1;
    }
    
    // 6. 更新未涉及的层的跨度
    for (int i = newLevel; i < this.level; i++) {
        update[i].getLevel(i).span++;
    }
    
    // 7. 设置后退指针
    newNode.setBackward((update[0] == this.header) ? null : update[0]);
    
    if (newNode.getLevel(0).forward != null) {
        newNode.getLevel(0).forward.setBackward(newNode);
    } else {
        // 新节点是尾节点
        this.tail = newNode;
    }
    
    // 8. 增加跳跃表长度
    this.length++;
    
    return newNode;
}

/**
 * 查找指定分值和值的节点
 * @param score 分值
 * @param value 值
 * @return 找到的节点，未找到返回null
 */
public SkipListNode search(double score, String value) {
    SkipListNode current = this.header;
    
    // 从最高层开始搜索
    for (int i = this.level - 1; i >= 0; i--) {
        while (current.getLevel(i).forward != null &&
               (current.getLevel(i).forward.getScore() < score ||
                (current.getLevel(i).forward.getScore() == score &&
                 current.getLevel(i).forward.getValue().compareTo(value) < 0))) {
            current = current.getLevel(i).forward;
        }
    }
    
    // 检查找到的节点是否匹配
    current = current.getLevel(0).forward;
    if (current != null && current.getScore() == score && 
        current.getValue().equals(value)) {
        return current;
    }
    
    return null;
}

/**
 * 获取指定排名的节点（从1开始）
 * @param rank 排名
 * @return 节点
 */
public SkipListNode getByRank(long rank) {
    if (rank <= 0 || rank > this.length) {
        return null;
    }
    
    SkipListNode current = this.header;
    long traversed = 0;
    
    // 从最高层开始
    for (int i = this.level - 1; i >= 0; i--) {
        while (current.getLevel(i).forward != null &&
               (traversed + current.getLevel(i).span) <= rank) {
            traversed += current.getLevel(i).span;
            current = current.getLevel(i).forward;
        }
        
        if (traversed == rank) {
            return current;
        }
    }
    
    return null;
}

/**
 * 获取节点的排名
 * @param score 分值
 * @param value 值
 * @return 排名（从1开始），未找到返回0
 */
public long getRank(double score, String value) {
    SkipListNode current = this.header;
    long rank = 0;
    
    for (int i = this.level - 1; i >= 0; i--) {
        while (current.getLevel(i).forward != null &&
               (current.getLevel(i).forward.getScore() < score ||
                (current.getLevel(i).forward.getScore() == score &&
                 current.getLevel(i).forward.getValue().compareTo(value) <= 0))) {
            
            rank += current.getLevel(i).span;
            current = current.getLevel(i).forward;
        }
        
        // 如果找到了目标节点
        if (current.getValue() != null && current.getValue().equals(value) && 
            current.getScore() == score) {
            return rank;
        }
    }
    
    return 0;
}
```
