## 线性回归模型

定义：算法从数据中学习并生成一条最佳拟合线（直线或曲线）

举例：上面的房价与面积的关系就是一个很典型的线性回归，通过提前输入数据训练，获取一条回归线，然后通过输入面积在线上得出售价

训练集：线性回归描绘出来的二维折线图可以直接转化成表格，表格中的X和Y组成的N条数据其实就是训练集，而每一条训练数据称为训练样本——(x^(i), y^(i))，i表示第几个训练样本

> 注意：x^(i) ≠x^i
> 

函数定义：fw,b(x) = wx+b 或 f(x) = wx+b

> 注意：如果只有一个入参，则称为【单变量线性回归】
>

### 成本函数（损失函数）

实际上w和b，就是我们要调整的模型参数，w也可以称为系数，b称为权重，根据不同的w和b就能生成不同的拟合线

如何计算出w、b来让线更加拟合呢

预期值： $\hat{y}^{(i)}$ = $\int_{w,b}(x^{(i)})$ = $wx^{(i)}+b$

**平方误差代价函数**：$J(w,b)=\frac 1 {2m}\sum_{i=1}^m(\hat{y}^{(i)} - y^{(i)})^2$       

> 预估值（拟合线上的）与真实值之差，m表达样本数量
> 

训练过程：实际上就是让代价函数尽可能小时w和b的值

**二维：**

举例——J(w)：

- 忽略权重(b)后只考虑模型为$\int_w(x^{(i)}) = wx^{(i)}$ 的情况，
- 损失函数为 $J(w)=\frac 1 {2m}\sum_{i=1}^m(wx^{(i)}- y^{(i)})^2$

当w等于1时，假设样本集为(1,1) (2,2) (3,3)，点正好都落在了拟合线上，这是计算代价函数时需要忽略b，最后算出来是：

- $J(1)=\frac 1 {2 * 3}(0^2+0^2+0^2)=0$
- $J(0.5)=\frac 1 {2*3}({(0.5-1)}^2+{(1-2)}^2+{(1.5-3)}^2)\approx 0.58$

实际上根据不同的w得出的值绘制成的损失函数图像是与函数一一对应的，将这些点绘制出来，可以发现是一个U型

> 下图只是举例样子，数据不是上面公式算的
> 

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/image%203.png)

**三维——横轴为w，纵轴为b，竖轴为J(w,b)：**

举例——J(w,b)，这时由于新加入的权值，函数图从二维会变成三维，如果依旧保留二维（等高线图），横轴为w，纵轴为b，那么平面图的点就是J(w,b)，你就会发现不同的w和b有时会得出相同的J(w,b)

那么绘制出来的图边靠近平面的环，代表效果越好，即J(w,b)越小，椭圆形的中央环

> 在举例模型中，形成一个三维的**弓形图**，类似于一座山，不同高度的环，相同高度的上环上的点就相当于J(w,b)了，如果再俯视看，就会变成这种二维图了，下图的弓形就是一个山环倒过来了

### （批量）梯度下降算法

作用：快速找到最适合模型的w和b

定义： $Min_{(w0...wn, b)}J(w0,...wn,b)$

局部最小值：在某些模型中，例如不是弓形图，可能是多个绵延起伏的弓形图，最小值可能存在多个

数学定义：

$temp_w=w-\alpha
\frac {\partial} {\partial w}J(w,b)$

$temp_b=b-\alpha
\frac {\partial} {\partial b}J(w,b)$

$w=temp_w$

$b=temp_b$

收敛：即w和b随着算法的进行达到局部最小值不在变化

**$\alpha$：学习率**

步长。含义就是梯度下降方向所走的步幅大小，总是一个正数

- 如果太短则会走很多步，算法会进行很多轮
- 如果太长则有可能直接越过最低点，越来越远离最低点，即没有收敛，你会发现w在左右横跳，一会为正数，一会为负数——**发散**

> 1e9 = 1 × 10^9 = 1,000,000,000
> 

![Figure_5.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/Figure_5.png)

当到达局部最小值时，损失函数这个点的斜率实际上是0，那么w和b都会减去0从而不变，这时就知道到达了局部最小值

梯度自动下降：当越来越靠近最小值时导数部分也会越来越小，因为斜率会变小，所以尽管学习率不变也不会影响问题

**$\frac {\partial} {\partial b}J(w,b)|\frac {\partial} {\partial w}J(w,b)$：即对成本的导数**

求导后就变成：

- $\frac {\partial} {\partial w}J(w,b)=\frac 1 {m}\sum_{i=1}^m(f_{w,b}(x^{(i)})- y^{(i)})x^{(i)}$
- $\frac {\partial} {\partial b}J(w,b)=\frac 1 {m}\sum_{i=1}^m(f_{w,b}(x^{(i)})- y^{(i)})$

> 后者没有x的第i个样本数是因为在模型函数中b是一个常数，求导就变成1了
> 
> 
> ![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/image%204.png)
> 

可以理解为对某点的切线，这个切线的斜率就是导数的结果

> 举例： $\frac {\partial} {\partial w}J(w)$，以上面的U型二维图举例，斜率为 $\frac y x$
> 
> - 当点在最小值的左边，导数的结果是一个负数
> - 而在最小值的右边则是一个正数，所以w永远再向最小值靠拢

![Figure_2.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/Figure_2.png)

`右图实际上就是高线图，只不过换了一种画法`

**批量：**

批量在这里的含义是因为我们每次在换新的w时，J(w)都是根据所有的（m个）训练样本得出的，而不是单个

**迭代次数：**

实际上观察过程下降算法是有迭代的逻辑在的，那么迭代其实要有一定的次数，即最多走多少步，完成后找最小，随着次数越来越多，相对应代价也越来越低，那么w与cost的斜率也就越来越小，新w逐渐趋近于稳定

![Figure_3.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/Figure_3.png)

### 线性回归算法

定义：监督学习（回归）模型+成本函数+梯度下降算法

在回归模型下的成本函数不会出现多个局部最小值，只会有一个最小值，这时成本函数展示为一个下凸函数，弓形样貌，那么在此基础上使用梯度下降算法并选用合适的学习率总会找到全局最小值

举例：

模型： $\hat{y}^{(i)} = f(w,b)=wx^{(i)}+b$

成本函数： $J(w,b)=\frac 1 {2m}\sum_{i=1}^m(\hat{y}^{(i)} - y^{(i)})^2$

梯度下降算法：

- $temp_w=w-\alpha\frac {\partial} {\partial w}J(w,b)$
- $temp_b=b-\alpha\frac {\partial} {\partial b}J(w,b)$

假设

- 样本集为：

| x | f(w,b) |
| --- | --- |
| 1 | 300 |
| 2 | 500 |
- w起始值为0
- b起始值为0
- 迭代次数为10000
- 学习率为0.01

可以得到这样的高线图

## 多特征（多元线性回归）

那么原始的模型函数就变为了：

$\int_{\overrightarrow{w},b}(\overrightarrow{x})=\overrightarrow{w}\cdot\overrightarrow{x}+b$

> 下面两个向量被称为行向量
> 
> - $\overrightarrow{x}=[x_1,x_2\cdots,x_n]$
> - $\overrightarrow{w}=[w_1,w_2\cdots,w_n]$
> 
> 符号【·】是点积，即 $x_1w_1+x_2w_2\cdots+x_nw_n$
> 

提示：在python中点积除了下面用现成的函数，还可以用【@】符号来表示

### 向量化

编程与数学：下面展示了代码层面用与不用API的区别，numpy使用了大量并行的逻辑去提供运算加速

> np.dot(a, b) =  2501072.5817
Vectorized version duration: 3.9988 ms
my_dot(a, b) =  2501072.5817
loop version duration: 1625.0582 ms
> 

```python
np.random.seed(1)
a = np.random.rand(10000000)  # very large arrays
b = np.random.rand(10000000)

tic = time.time()  # capture start time
c = np.dot(a, b)
toc = time.time()  # capture end time

print(f"np.dot(a, b) =  {c:.4f}")
print(f"Vectorized version duration: {1000 * (toc - tic):.4f} ms ")

tic = time.time()  # capture start time
c = my_dot(a, b)
toc = time.time()  # capture end time

print(f"my_dot(a, b) =  {c:.4f}")
print(f"loop version duration: {1000 * (toc - tic):.4f} ms ")

def my_dot(a, b):
    """
   Compute the dot product of two vectors

    Args:
      a (ndarray (n,)):  input vector
      b (ndarray (n,)):  input vector with same dimension as a

    Returns:
      x (scalar):
    """
    x = 0
    for i in range(a.shape[0]):
        x = x + a[i] * b[i]
    return x
```

### 多元线性回归的梯度下降算法

公式演变：

梯度下降算法：

- $temp_{w_n}=w_n-\alpha\frac {\partial} {\partial w}J(\overrightarrow{w},b)=w_n-\alpha\frac 1 {m}\sum_{i=1}^m(f_{\overrightarrow{w},b}(\overrightarrow{x}^{(i)})- y^{(i)})x^{(i)}_n$
- $temp_b=b-\alpha\frac {\partial} {\partial b}J(\overrightarrow{w},b)=b-\frac 1 {m}\sum_{i=1}^m(f_{\overrightarrow{w},b}(\overrightarrow{x}^{(i)})- y^{(i)})$

### 正规方程算法

与梯度下降的作用一致，寻找最佳w和b的算法

局限：

- 仅适用于线性回归的算法中，不适用于逻辑回归算法或神经网络
- 如果特征的数量很多，计算的也很慢

优势：通过高级线性库（机器学习库）一次性求解出w和b，而不用迭代

### 特征缩放

假设模型为： $\int_{\overrightarrow{w},b}(\overrightarrow{x})=\overrightarrow{w}\cdot\overrightarrow{x}+b$，n等2

- 一个是房子的面积，范围是100~2000
- 一个是卧室的数量，范围是1~5

这时会发现w1的变动幅度会成倍放大到最后的预测结果，导致不准，而w2的变动幅度就没有向前者那么敏感，所以一般w1会取小，w2会取大

> 对于图2，可以发现w1的放大与缩小就会非常影响下降算法的大小，可能就会出现左右横跨的现象
> 

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/image%205.png)

归一化

将两个轴的范围缩小，这样分布会更加均匀

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/image%206.png)

总结：当你不同特征的取值差异很大时，梯度下降的效率会降低，同时也会导致步幅一会大一会小不稳定，这时通过特征缩放就能使样本和模型更加拟合，来让成本容易计算且稳定；同时需要注意的是如果缩放后的范围还是太大或者太小，不是个位数就需要注意了，最好接近【-1~1】这个范围

**缩放常用方法：**

1. 按最大值同比缩放：
    - 300~2000——>0.15~1
    - 0~5——>0~1
2. 均值归一化：引入正负四个象限，横纵轴都是-1~1
    - $x_n=\frac {x_n-\mu_n} {max-min}$：公式含义就是把特征的最大值和最小值代入到x中，得到左区间和右区间
    - 每个特征的均值：使用mu符号，U的含义就是x特征的平均值
    - 均值: $\mu_n=\frac 1 {m}\sum_{i=1}^mx^{(i)}_n$
    
    > python中用mean来计算
    > 
3. Z分数归一化：
    - 每个特征的标准差，使用sigma符号来表示
    - $x_1=\frac {x_1-\mu_1} {\sigma_1}$
    - 总体标准差(ML常用): $σ_n = \sqrt{\frac 1 m \sum_{i=1}^m (x^{(i)}_n-μ_n)^2}$
    
    > python中用std来计算
    > 
    > - axis: 按维度计算（None 为整体；0 按列，1 按行）
    > - ddof: 自由度修正，0=总体，1=样本
    > - keepdims: 保持维度
    > - dtype: 计算时的类型
    > - where: 条件掩码（True 的元素参与）
    > 
    > ```python
    > import numpy as np
    > a = np.array([[1,2,3],[4,5,6]])
    > 
    > np.std(a)                 # 1.707..., 总体
    > np.std(a, ddof=1)         # 1.870..., 样本
    > np.std(a, axis=0)         # 按列: [1.5, 1.5, 1.5]
    > np.std(a, axis=1, keepdims=True)  # 按行，保留维度: [[0.816...],[0.816...]]
    > np.nanstd([1., np.nan, 3.])  # 1.0
    > ```
    > 
    - 样本标准差(无偏): $s_j = \sqrt{\frac 1 {m-1} \sum_{i=1}^m (x^{(i)}_n-μ_n)^2}$

**如何判断缩放后是否收敛：**

注意：在某些模型中迭代100次就可能找到了最优解，在别的模型可能就要迭代几万次

1. 绘制J(w,b)和迭代次数的二维图，如果发现成本随着迭代次数一直下降则代表在收敛

![Figure_6.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92/Figure_6.png)

1. 定义一个差值，当迭代前和迭代后的成本值小于这个则代表收敛，但是这个差值很难定义一个出来

### 选择学习率

就是通过绘制不同学习率下迭代次数和成本的二维图，看趋势

一般学习率是从0.001开始使用，每次乘3去迭代下降算法

### 特征工程（特征衍生）

定义：即选择什么样的特征能够更好的训练模型

总结：通过计算得到一个或多个特征，将其将如到模型，提高或降低新特征的权重（w）来使其模型更加健壮

### 解决过拟合

什么会造成过拟合

- 多特征，少样本

解决方式

- 更多的样本量
- 特征选择（简化特征量）——后续：自动挑选合适特征集的算法
- 正则化

**正则化：通过改变参数（**$w_n$**）大小，不改变特征大小，从而更温和的调整模型，而不是暴力直接去掉某个特征**

### 带正则化的成本函数

对某个特征的参数正则化，实际上就是在【惩罚某个特征】

### 正则化线性回归

模型： $\hat{y}^{(i)} = f(w,b)=wx^{(i)}+b$

成本函数： $J(w,b)=\frac 1 {2m}\sum_{i=1}^m(\hat{y}^{(i)} - y^{(i)})^2+\frac \lambda {2m}\sum_{j=1}^nw_j^2$

梯度下降算法：

- $temp_w=w-\alpha\frac {\partial} {\partial w}J(w,b)$
- $temp_b=b-\alpha\frac {\partial} {\partial b}J(w,b)$

导数部分：

- $\frac {\partial} {\partial w}J(w,b)=\frac 1 {m}\sum_{i=1}^m(f_{w,b}(x^{(i)})- y^{(i)})x^{(i)}+\frac \lambda mw_j$

> 为什么后者的求和公式消失了：
> 
> 
> 在优化问题里，参数向量 w=[w_1,...,w_n] 本身就是自变量，损失函数 J(w,b) 对 w 的每个分量都“依赖”。当你对某一分量 w_j 求偏导时，约定是“把其他分量 w_k(k≠j) 当常数不动，只让 w_j 变化”，所以：
> 
> - w_j 是当前求导的自变量，绝不是常数；
> - 只有 w_j 那一项对偏导有贡献，其它项因为被当作常数，导数为 0。
> 
> 直观例子： $f(w_1,w_2)=w_1^2 + w_2^2$ ，对 w_1 求偏导：
> 
> - 把 w_2 固定（常数）， $∂f/∂w_1 = 2w_1 + 0$
> 
> 同理，带正则  $λ/(2m)∑_k w_k^2 对 w_j$的偏导为  $(λ/2m)*2w_j = (λ/m)w_j$。如果把 w_j 也当常数，梯度就恒为 0，梯度下降也就无法更新参数了。
> 
- $\frac {\partial} {\partial b}J(w,b)=\frac 1 {m}\sum_{i=1}^m(f_{w,b}(x^{(i)})- y^{(i)})$

讨论正则化对梯度下降的影响，当把模型带入进去后并且提取多项式就会变为如下

$w_j=w_j-\alpha\frac \lambda mw_j-\alpha\frac 1 m\sum_{i=1}^m(f_{w,b}(x^{(i)})- y^{(i)})x^{(i)}_j$

根据下面的公式，实际上在合理范围内这一项带有正则的参数就是给w乘一个小于1的数去缩小w的值

$w_j-\alpha\frac \lambda mw_j=w_j(1-\alpha\frac \lambda m)$
