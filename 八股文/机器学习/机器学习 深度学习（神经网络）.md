### 需求预测

假设现在有四个特征去预测，某个衣服会不会成为爆款，对于神经学习中就会是这样

$x=价格、运费、销售量、材料质量$

$a=f(x)=\frac 1 {1+e^{-(wx+b)}}=性价比、知名度、质量好坏$

a在这里被称为：激活值

注意：中间层的每个激活值都能访问前一层的任何特征，他会自己选择使用哪些特征会生成激活值

**简而言之：** $\overrightarrow{x}→\overrightarrow{a}→a$

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%EF%BC%88%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%EF%BC%89/image%201.png)

总结：如果将输入层忽略，只看隐藏层和输出层，实际上就是一个逻辑回归的模型，只不过用的不是原始特征，而是加工好的特征【激活向量】，那么神经学习实际上就是能自我学习的逻辑回归

**神经学习框架：即不同的隐藏层数，以及隐藏层中包含多少个神经元，每个神经元在不需要指定的前提下自己提取相似的特征以供输出**

再来有个示例：例如一个1000*1000像素的人像图片，那么输入到网络中的特征总数为100万个，假设有三层，第一层负责找最小元素的相似处，第二层负责找感官器官，第三层负责找脸，每一层的每一个神经元都各司其职，最后输出这个人的身份

### 神经网络中隐藏层的运作

明确下面的模型实际上就是逻辑回归

名词名义：

- 输入层：0层
- 隐藏层：1~n层
- 输出层：n+1层
- 四层神经网络：指的是隐藏层+输出层的总和
- **隐藏层输入值：即可以是原始特征向量，也可以是激活值向量**
- 隐藏单元：隐藏层中的神经单元

数学符号：

- 某一层： $[i],i \in [0,n]$
- 某一层的某个神经元： $\overrightarrow{w}^{[i]}_j,b^{[i]}_j,j \in [1,n]$
- 激活值： $a^{[i]}_j=g(\overrightarrow{w}^{[i]}_j \cdot \overrightarrow{x} +b^{[i]}_j)$
- 激活函数： $g(\overrightarrow{w}^{[i]}_j \cdot \overrightarrow{x} +b^{[i]}_j)$

> 注意：函数可以是任何学习函数，例如逻辑回归中的sigma函数
> 
- 激活值向量： $\overrightarrow{a}^{[i]}=[a^{[i]}_j, a^{[i]}_{j+1}, a^{[i]}_{j+2}]$，就是多个激活值组成数组
- 第0层激活值：实际上就是输入层的所有特征 $\overrightarrow{x} =\overrightarrow a^{[0]}$
- 【i-1】的激活值作为入参后的【i】激活值向量： $a^{[i]}_j=g(\overrightarrow{w}^{[i]}_j \cdot \overrightarrow{a} ^{[i-1]}+b^{[i]}_j)$

### 其他类型的层

- 卷积层：选择性的计算前一层的某几个入参或是激活值，不同的卷积激活值的来源可以重叠
    - 卷积神经网络：一个神经网络中有很多卷积层
    - 更快的计算
    - 需要的训练数据更少，减少过拟合

### 点积与矩阵乘法

首先明确，两个矩阵的乘法的结果仍是一个矩阵，而两个矩阵的点积实际上是行向量与列向量的标量计算，结果是一个数值，是构成矩阵元素的一个数值

**矩阵乘法**

实际上就是行列向量做点积，只不过每个值都需要点积最后得出一个矩阵

$A=\begin{bmatrix} 1 &2 \\ 3&4 \end{bmatrix}  B= \begin{bmatrix} 5  &6\\ 7&8 \end{bmatrix}$

$C=\begin{bmatrix} C11=1*5+2*7  &C12=1*6+2*8\\ C21=3*5+4*7&C22=3*6+4*8 \end{bmatrix} =\begin{bmatrix} 19  &22\\ 43&50 \end{bmatrix}$

两个向量的**点积**实际上等于某一个向量的倒置向量**乘**

**点积**

$\begin{bmatrix} 1  \\ 2 \end{bmatrix} \cdot \begin{bmatrix} 3  \\ 4 \end{bmatrix} = \begin{bmatrix} \overrightarrow{a} \end{bmatrix} \cdot \begin{bmatrix} \overrightarrow{w}\end{bmatrix}$ 

$z = \overrightarrow{a} \cdot \overrightarrow{w} = 1 *3 + 2* 4 = 11$

**倒置乘法**

$\overrightarrow{a} = \begin{bmatrix} 1  \\ 2 \end{bmatrix}$

$\overrightarrow{a}^T=\begin{bmatrix} 1  & 2 \end{bmatrix}$

$z = \overrightarrow{a}^T  \overrightarrow{w} = \begin{bmatrix} 1&2   \end{bmatrix} \begin{bmatrix} 3  \\ 4 \end{bmatrix} = \begin{bmatrix} 11 \end{bmatrix}$

**向量矩阵乘法转化为矩阵乘法**

原理：就是利用向量的点积与向量倒置后的乘法相同

多维矩阵的倒置，就是行变列，列变行

$A=\begin{bmatrix} 1 &2 \\ 3&4 \end{bmatrix}$

$A^T=\begin{bmatrix} 1 &3 \\ 2&4 \end{bmatrix}$

总结：**为什么需要这样呢，考虑特征的加载形式，一个是M,N，也就是关系型数据库的行列，M代表有多少个数据样本，N代表特征数量，那么带入到每一层的特征输入，或者说是激活值的输入，实际上对应矩阵就是每一行都是一个样本，每一列都是一个特征，但是每一层神经元的计算用到的是这一特征的相关值，即计算某一特征的激活值，那么把这个矩阵倒置后，M,N就能符合计算的直觉，M变为特征的数量，N代表样本数，跟神经元刚好能一一对应，同时由于矩阵乘法的特征，行与列做点积，那么参数W的矩阵也就不用倒置了**

注意：在TF中，有个默认的约定，A的输入本身就是一个倒置矩阵了，而不用AT来表示

**矩阵乘法的行列转化**

- A 的列数 = B 的行数（必须相等，这里是 n）

```python
矩阵 A (m×n)         矩阵 B (n×p)         结果 C (m×p)
┌─────────┐          ┌─────────┐          ┌─────────┐
│         │          │         │          │         │
│   m行   │    ×     │   n行   │    =     │   m行   │
│         │          │         │          │         │
│   n列   │          │   p列   │          │   p列   │
└─────────┘          └─────────┘          └─────────┘
     ↑                    ↑                    ↑
   必须相等           结果的行数           结果的列数
```

### 四种常用的激活函数

**线性激活（Linear/Identity）**

- 公式：f(x) = x
- 特点：不做非线性变换，梯度恒为 1，适合输出回归值；但层数再多仍等价于单层，不具备表示复杂关系的能力。**也被称之为没有激活函数**
- 示意：

```python
		y
		│   /
		│  /
		│ /
	  └──────── x
   /
	/
```

注意：在神经网络中，不能每层的激活函数都用线性激活函数（尤其是隐藏层），这样会导致回归到线性回归上面，而不是神经网络了，所以与其使用神经网络解决线性问题，为什么不直接使用线性回归呢；如果隐藏层都用线性函数，对于输出层来说，输出层的激活函数是什么，那么最终结果也是遵循输出层的激活函数的，这样相当于没有神经网络的概念了

**Sigmoid（S 型）**

- 公式：f(x) = 1 / (1 + e^-x)
- 特点：输出范围 (0,1)，适合二分类；对极大/极小输入会饱和，梯度趋近 0，易梯度消失；对称中心在 0，对 0 附近最敏感。
- 示意：

```python
		y
		│ ___
		│/
	 /│ 
———	└──────── x
```

**ReLU（Rectified Linear Unit）**

- 公式：f(x) = max(0, x)
- 特点：x<0 时输出 0，x≥0 时保持线性；计算简单，缓解梯度消失（平坦的地方较少，那么出现局部最小点的概率也就小）；但负半轴梯度为 0 可能导致“神经元死亡”。
- 示意：

```python
		y
		│  /
		│ /
		│/
	——└──────── x
```

**Softmax**

- 公式：softmax(z_i) = e^{z_i} / Σ e^{z_j}（作用于向量）
- 特点：把一组实数映射成和为 1 的概率分布，常用于多分类输出层；对各个分量的相对大小敏感。
- 示意（以二维输入为例，展示概率随输入变化趋势）：

```python
p1
│  \       /
│   \ ___ /
│    \   /
└──────── p2
```

（Softmax 是多维函数，示意图仅表示随着某一分量增大，其对应概率上升、其他下降）

## 多分类问题

### softmax算法

将输出层的激活函数设置为softmax算法

注意其他激活函数中，激活函数的结果a实际上就是g(z)，z仅仅代表当前神经元的模型函数，但是如果是softmax，z代表输出层的所有神经元的模型函数

如何在tensorflow中优化计算误差，举个例子

```java
# 0.00002
x = 2 / 10000

# 0.0000199999999999998
x = 1 + (1 / 10000) - (1 - 1 / 10000)
```

由于多分类需要计算的神经元需要用到其他别的神经元，会导致误差很大，在二分类不明显。通过设置损失函数的一个参数，可以优化误差

```java
model.compile(loss=xxx(from_logits=True))
```

本质上就是sigmoid函数模型中g(z)中这个z（逻辑值）的值会影响，过大过小都会影响，在图像上就是无限接近于0

### 反向传播算法

计算代价函数相对于参数的导数

## 计算图（向前传播与反向传播）

使用线性回归举例子： $a=wx+b$

前向传播：w → c → a → d → J
反向传播：J ← d ← a ← c ← w

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%EF%BC%88%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%EF%BC%89/image%203.png)

意义：在一般的深度学习过程中，如果没有反向传播的存在，就会发现，每个参数都会独立计算梯度导数，同时叠加到代价函数，N个节点，P个参数，总步数就会为N * P

而反向传播则复用中间结果和链式法则简化步数，即 N + P

导数计算有个重要的法则即

$\frac a b = \frac a c * \frac c b$

举个计算图的例子

![image.png](%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%20%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%EF%BC%88%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%EF%BC%89/image%204.png)

开始反向传播的推导

- 第一步
    - **∂J/∂a^[2]= (a^[2] - y) = 7 - 5 = 2**
- 第二步
    - ∂J/∂z^[2] = **∂J/∂a^[2]** × ∂a^[2]/∂z^[2] = **∂J/∂a^[2]** × g'(z^[2]) = **2** × g'(7) = 2
    
    > $函数：y=f(x)
    导数：\frac {\partial y} {\partial x}=f'(x)：即f在x处的导数$
    > 
- 第三步
    - ∂J/∂b^[2] = **∂J/∂z^[2]** × ∂z^[2]/∂b^[2] = 2 × 1 = 2
        
        > ∂z^[2]/∂b^[2]：z第二层的激活值对b第二层的激活值求导，z = t + b = 0 + 1 = 1，对b求导，那么t就是常数，b是一阶结果为1
        > 
    - ∂J/∂t^[2] = **∂J/∂z^[2]** × ∂z^[2]/∂t^[2] = 2 × 1 = 2
        
        > ∂z^[2]/∂t^[2]：z第二层的激活值对b第二层的激活值求导，同上
        > 
- 第四步
    - ∂J/∂w^[2] = **∂J/∂t^[2]** × ∂t^[2]/∂w^[2] = 2 × 2 = 4
        
        > ∂t^[2]/∂w^[2]：t对w的导数，t = w × a，a是2，w的一阶结果为1，结果为2
        > 
- 第五步
    - ∂J/∂a^[1] = **∂J/∂t^[2]** × ∂t^[2]/∂a^[2] = 2 × 3 = 6
        
        > 同上
        > 
- 第六步
    - ∂J/∂z^[1] = **∂J/∂a^[1]** × ∂a^[1]/∂z^[1] = 6 × 1 = 6
        
        > ∂a^[1]/∂z^[1]：a对z的导数，a = g(z) = g’(z) = g’(2) = 1
        > 
- 第七步
    
    > z = b + t，z对b或者z对t的导数都是变量+常数，变量为1，常数为0，所以结果为1
    > 
    - ∂J/∂b^[1] = **∂J/∂z^[1]** × ∂z^[1]/∂b^[1] = 6 × 1 = 6
    - ∂J/∂t^[1] = **∂J/∂z^[1]** × ∂z^[1]/∂t^[1] = 6 × 1 = 6
- 第八步
    
    > t = w * x，t对w的导数w为1，则为x
    > 
    - **∂J/∂w^[1] =** ∂J/∂t^[1] × ∂t^[1]/**∂w^[1] = 6** × 1 = 6
