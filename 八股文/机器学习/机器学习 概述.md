# 机器学习

定义：一种没有明确编程的情况下学习和研究的领域

常用符号定义

- m：训练集中训练样本数量
- $x_j$：第j个特征
- $x^{(i)}$：第i个训练样本
- n：特征的数量
- $\overrightarrow{x^{(i)}}$：第i个训练样本的所有特征，可以简化为第i个特征向量
- ${x^{(i)}_j}$：第i个训练样本的第j个特征
- W：矩阵
- w：向量和标量

## 有监督学习

定义：给出X（输入）——》Y（预期输出或标签）映射关系进行学习，经过学习后给一个从来没有见过的X，来尝试获取正确的Y

例如：

- 输入：邮件
- 输出：是否垃圾邮件
- 应用：垃圾邮件过滤器

### 回归

定义：我们把从一部分已知的映射个关系中输入新的X获取Y的行为

拟合直线和曲线——如何选择合适描述数据的函数

在例如：下面的这个图，实际上100-1000这类的数据就是输入进去，让机器学习的，那么下次可以输入一个150，则机器就能得出1500，符合这些x-y映射关系的实际上就是符合这个函数，当然这个函数可能是直线，也可能是曲线，看哪个线更加符合你输入进去的数据

### 分类

定义：有限输出的结果分类只有两种或以上，即输出两个类别（分类）或输出**全集**中的多个子集（离散分类）

- 预测是否是肿瘤，是或不是
- 预测是猫还是狗，猫或狗

**两个即以上变量的输入（线性支持向量机）**

即在分类的基础下，输入值变为多个，即多维后，会存在分界的边界线。

例如前面判断肿瘤的输入是肿瘤的大小，现在改为大小和患者年龄，当然可能还有很多很多输入

## 无监督学习

定义：定义：给出X（输入），没有告诉算法有哪些特征，让其自己进行聚集分组，即将得出的Y进行归类，而不是提前给Y打一个结果标签；

### 聚集算法

定义：输出的结果只强调聚集分布，不存在分类好坏之分，聚集起来是一个一个的组

举例：每天的类似新闻算法，就是将爬取到的信息对关键词进行聚集后推荐，即推荐一个组里面的

## 损失函数和成本函数

- **损失函数（Loss Function）**：衡量“单个样本”预测结果与真实标签之间误差的函数，比如均方误差、交叉熵等。它告诉你当前这条样本预测得好不好。
- **成本函数（Cost Function）**：通常指对“整个训练集或批次”上的损失进行聚合（求均值、求和等）后得到的目标函数，有时还加上正则化项等。优化算法（梯度下降等）真正最小化的是成本函数。

简言之：损失函数关注单一样本的误差，成本函数将所有样本（或一个批次）的损失汇总，用于整体训练优化。

### 导数

可以简单理解为对某个变量施加了一些改变的过程，**对于一般导数的表达我们读作分子对分母的求导**

| 变量 | 函数 | 变化幅度 | 变化结果 | 导数（k） |
| --- | --- | --- | --- | --- |
| w=3 | $J(w)=w^2=9$ | w增加0.001 | $J(w)=J(3.001)=9.006001$
$J(w)增加6 * 0.001$ | $\frac {\partial} {\partial w}J(w)=6$ |
| w=2 | $J(w)=w^2=4$ | w增加0.001 | $J(w)=J(3.001)=9.006001$
$J(w)增加4 * 0.001$ | $\frac {\partial} {\partial w}J(w)=2w=4$ |
| w=-3 | $J(w)=w^2=9$ | w增加0.001 | $J(w)=J(-2.999)=8.994001$
$J(w)下降6 * 0.001$ | $\frac {\partial} {\partial w}J(w)=-6$ |
| w=2 | $J(w)=w^3=8$ | w增加0.001 | $J(w)=J(2.001)=8.012006001$
$J(w)增加12 * 0.001$ | $\frac {\partial} {\partial w}J(w)=3w^2=12$ |
| w=2 | $J(w)=\frac 1 w=0.5$ | w增加0.001 | $J(w)=J(2.001)=0.49975$
$J(w)增加 - \frac 1 4 * 0.001$ | $\frac {\partial} {\partial w}J(w)=- \frac 1 {w^2}=- \frac 1 4$ |
|  |  |  |  |  |

一些历史原因

$\partial$和d这两个符号都能代表导数，而前者代表多变量函数，后者代表单变量函数

说谁是谁的导数时：是从分子对分母的导数
