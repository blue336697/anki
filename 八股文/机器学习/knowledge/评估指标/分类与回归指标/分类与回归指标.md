# 分类与回归指标

## 混淆矩阵卡
Q: 二分类混淆矩阵中的 TP、FP、TN、FN 分别是什么？
A:
- TP：真实为正，预测为正
- FP：真实为负，预测为正，也叫误报
- TN：真实为负，预测为负
- FN：真实为正，预测为负，也叫漏报
- 面试表达：分类指标本质都是从这四个数量派生出来的，要先说清正类定义

## Precision/Recall/F1 卡
Q: Precision、Recall、F1 分别适合关注什么问题？
A:
- Precision = TP / (TP + FP)，关注预测为正的样本中有多少是真的
- Recall = TP / (TP + FN)，关注真实正样本中有多少被找出来
- F1 是 Precision 和 Recall 的调和平均，适合二者都重要且类别不均衡时
- 反欺诈/风控更常关注 Recall 与 Precision 的业务权衡：漏掉坏样本还是误伤好样本哪个代价更高
- 面试注意：Accuracy 在类别极不均衡时可能非常误导

## ROC/AUC 卡
Q: ROC-AUC 和 PR-AUC 有什么区别？什么时候 PR-AUC 更有用？
A:
- ROC 曲线横轴 FPR、纵轴 TPR，AUC 衡量模型把正样本排在负样本前面的能力
- PR 曲线横轴 Recall、纵轴 Precision，更直接体现正类检出质量
- 类别极不均衡时，ROC-AUC 可能看起来不错，但 Precision 很低
- 稀有正类任务如欺诈、故障、疾病检测，PR-AUC 往往更敏感
- 面试表达：AUC 看排序能力，不直接告诉你某个阈值下能赚多少钱或误伤多少人

## 阈值卡
Q: 分类阈值为什么不能固定看 0.5？如何选阈值？
A:
- 模型输出概率或分数后，阈值决定 Precision/Recall 的权衡
- 类别不均衡或业务成本不对称时，0.5 往往不是最优阈值
- 可根据业务成本、召回要求、误伤率上限、F1、Youden index 或验证集收益最大化选择阈值
- 阈值选择应在验证集完成，测试集只做最终评估
- 上线后阈值还可能根据流量、风险偏好和模型漂移动态调整

## 回归指标卡
Q: MSE、RMSE、MAE、R2 分别如何理解？
A:
- MSE 是误差平方平均，对大误差惩罚重
- RMSE 是 MSE 开根号，单位与目标变量一致，更易解释
- MAE 是绝对误差平均，对异常值更稳健
- R2 衡量模型相对用均值预测解释了多少方差，可能为负
- 选择指标要看业务：是否更怕大误差、是否需要可解释单位、是否有异常值

## 正确性审查卡
Q: 评估指标有哪些常见误区？
A:
- “Accuracy 高就是模型好”：类别不均衡时可能完全误导
- “AUC 高就可以上线”：不够。还要看阈值下业务指标、延迟、稳定性和校准
- “Precision 和 Recall 可以同时随便提高”：通常存在 trade-off，需要业务取舍
- “测试集可以用来调阈值”：错误。调阈值应使用验证集
- “R2 一定在 0 到 1 之间”：错误。模型比均值预测还差时 R2 可以为负
