# 验真

## 1. 项目背景与目标

*   **背景**：在信贷审批、担保评估等业务中，银行流水是核实客户收入与经营状况的核心依据。目前市场上存在大量经过篡改或伪造的银行流水，传统的肉眼审核效率低且难以识别高仿真造假。
    
*   **目标**：具体采用四种验真方式：
    
    *   **余额连续性验证**检查逐笔余额与收支金额是否逻辑自洽，识别余额倒挂、无交易跳变等篡改痕迹；
        
    *   **结息验真**通过理论结息公式反推实际利息是否与账单一致，偏差过大则疑似篡改；
        
    *   **日期规律性验证**检查交易时间序列是否符合正常行为特征，识别批量伪造和程序化刷单；
        
    *   **电子签章验证**核查账单文件的数字签名和元数据是否来自官方渠道，防止文件替换和PDF伪造。四种方式相互补充，从数学逻辑、统计规律、文件底层三个层面共同构建流水真实性的验证体系。
        

## 2. 验真能力

| **验真** | **账单类型** | **说明** | **权限** |
| --- | --- | --- | --- |
| 结息验真 | 银行卡 | 通过计算流水期间日均余额反推理论结息金额，与实际结息金额比对，验证账户余额规模的真实性。 | 可按租户级配置 |
| 余额连续性验真 | 银行卡 | 逐笔校验"上笔余额 ± 交易金额 = 本笔余额"，验证流水是否存在篡改或伪造条目。 | 可按租户级配置 |
| 交易日期验真 | 银行卡 | 分析交易日期的分布规律，验证结息日期、交易频率、定期扣款周期是否符合真实账户的自然行为特征。 | 可按租户级配置 |
| 电子签章 | 支付宝/微信/银行卡 |  | 可按租户级配置 |

## 结息验真

### 术语表

| **术语** | **说明** |
| --- | --- |
| **结息** | 银行按照约定周期（月/季/年）计算并记入账户的利息，体现在账户流水中， |
| **结息周期** | 银行通常按季度（为3、6、9、12月的21日）为客户结算的活期存款利息。 |
| **验真** | 通过算法模型对提交的银行流水中结息数据的真实性、合规性进行核验 |
| **日均余额** | 统计周期内sum（每日账户余额\*持续天数）/统计天数，是计算利息的基准 |
| **活期利率** | 银行对活期存款账户适用的基准利率，各行标准不同 |
| **偏差率** | 计算理论结息同实际结息金额的可接受偏差范围，超出则触发预警 |

### 功能需求详情

#### 场景判定

| **结息场景** | **条件** | 输出风险提示 |
| --- | --- | --- |
| 流水未含结息日 | 流水区间不含任何季末月（3/6/9/12月的21号） | 流水周期未覆盖结息日，无法验真 |
| 覆盖结息日但无结息记录 | 流水周期覆盖结息日（3、6、9、12月的21日）但无结息记录 | 流水覆盖结息日缺失结息记录{ 0 }笔 |
| 有结息记录但无完整季度 | 流水中有结息，但不存在一个结息完整季度（当前季度21日至上季21日），无法反推理论利息 | 有结息记录但无完整季度,无法执行计算验真 |
| 偏差率 | 计算出来的理论利息同实际利息偏差,<br>偏差率 = round(\|理论结息 - 实际结息\| ÷ 理论结息 × 100%, 2) | ≤ 5%为通过<br>5% ~ 15%（含15%）为预警<br>\> 15%为拒绝 |

#### 提取结息记录

流水中交易备注/摘要=“结息”、“利息”关键词(可配置) 且交易日期=21日的记录

#### 理论结息计算

| **序号** | **计算** | **方法** |
| --- | --- | --- |
| 1 | 理论结息 | **1）计算季度理论结息**<br>\=round（日均余额\*（年利率/365）\*统计天数，2）<br>**1.1）日均余额**\=∑(每日余额\*持续天数)​/统计天数<br>统计天数=取（每季度21号-1）-上季度21号（示例：\[ 2025.12.20-2025.9.21）<br>日均余额计算示例<br>![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/54Lq35oz8Ra9Xl7E/img/47d3a3ac-5892-491b-9a2b-080388b15d28.png)<br>**从流水账单计算时：**<br>1.  列出每一行的**余额**和**该余额维持的天数**<br>    <br>2.  积数=每日余额 × 持续天数 （`下一笔交易日期 − 本次交易日期`）<br>    <br>3.  所有积数求和 /总天数 = 日均余额<br>    <br>特殊说明**：**<br>每日余额 = 当天发生所有交易后的期末余额（不是交易金额），如果一天内有多笔交易，取当天最后一笔交易后的余额<br>节假日没有交易，沿用前一天余额 |
